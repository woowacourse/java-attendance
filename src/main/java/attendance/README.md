## 기능 목록
- [x] 파일로부터 기존 출석 기록을 읽어온다.
  - 파일의 내용을 읽어온다.
  - 읽은 파일 내용으로부터 기존 출석 정보를 초기화한다.
  - 예외) 해당 경로에 파일이 존재하지 않는 경우.
  - 예외) `nickname,datetime` 형식이 아닌 경우
- [ ] 사용자로부터 기능을 입력받는다.
  - 예외) 입력된 기능이 ``1, 2, 3, 4, Q(q)``가 아닌 경우
- [x] 크루의 오늘 출석을 등록한다.
  - 출석을 등록하려는 크루의 닉네임을 입력받는다.
  - 등교 시간을 입력받는다.
  - 등교 시간으로 출석 상태를 검사한다.
  - 출석 정보를 출력한다.
  - 예외) 등록되지 않은 크루인 경우
  - 예외) HH:mm 형식으로 시간이 입력되지 않은 경우
  - 예외) 이미 오늘 출석한 경우
- [x] 출석을 수정한다.
  - 출석을 수정하려는 크루의 닉네임을 입력받는다.
  - 수정하고자 하는 날짜를 입력한다.
  - 수정하려는 시간을 입력한다.
  - 수정 이전, 이후 출석 정보와 출석 상태를 출력한다.
  - 예외) 오늘 출석을 수정하는데 아직 오늘 출석을 하지 않은 경우
- [ ] 크루별 출석 기록을 확인한다.
  - 출석 기록을 확인하려는 크루의 닉네임을 입력받는다.
  - 현재 월(month)에 등록된 모든 출석 정보 및 출석 상태를 출력한다.
  - 각 출석 상태 별 횟수를 출력한다.
  - 제적 위험자에 해당하는 경우, 이를 출력한다.
- [ ] 모든 제적 위험자를 확인하는 기능
  - 전날까지를 기준으로, 모든 제적 위험자를 출력한다.
  - 각 제적 위험자들 별 결석 및 지각 횟수를 출력한다.
- [ ] 프로그램은 사용자가 종료하기 전까지 계속 반복된다.

## 도메인 목록
* 크루
  * 예외) 2~5글자 닉네임이 아닌 경우
* 출석 시간
  * 예외) 주말 및 공휴일으로 생성하는 경우
  * 예외) 캠퍼스 운영시간 이외의 시간으로 생성하는 경우
  * 예외) 미래의 시간으로 생성하는 경우
* 출석부
  * 크루, 출석 시간 리스트롤 필드로 가진다.


## 시나리오 설정
* 캠퍼스 운영시간
  * 08:00 ~ 23:00
  * 주말 및 공휴일은 출석 불가
* 교육시간
  * 월요일: 13:00 ~ 18:00
  * 화~금요일: 10:00 ~ 18:00
* 출석 상태
  * 5분 이하: 출석
  * 30분 이하: 지각
  * 30분 초과: 결석
* 제적 위험자
  * 경고 대상자: 결석 2회 이상
  * 면담 대상자: 결석 3회 이상
  * 제적 대상자: 결석 5회 초과   
  (지각 3회 = 결석 1회)
