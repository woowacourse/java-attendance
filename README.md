# java-attendance

출석 미션 저장소

## 도메인 정보

* 24시간 형식을 사용한다.
* 교육 시간
  * 월요일: 13:00~18:00
  * 화~금요일: 10:00~18:00
* 출석 상태 기준
  * 지각: 5분 초과
  * 결석: 30분 초과 또는 미출석
* 관리 대상자 기준
  * 지각 3회는 결석 1회로 취급
    * 경고: 결석 2회 이상
    * 면담: 결석 3회 이상
    * 제적: 결석 6회 이상
* 캠퍼스 운영 시간: 매일 08:00~23:00
  * 운영 시간이 아니면 출석을 받지 않는다.
* 주말 및 공휴일에는 출석을 받지 않는다.

## 기능 설계

- [ ] 메뉴 선택창

```
오늘은 12월 14일 토요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
```

- [x] 출석 확인
  - [x] 닉네임과 등교 시간을 입력하여 출석한다.
  - [x] 이미 출석한 경우, 수정 기능을 이용하도록 안내한다. (출석 처리 x)
  - [x] 출력 요구사항
    - [x] 출석 후 출석 기록을 확인할 수 있다.

```
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 05일 화요일 09:59 (출석)
```

- [x] 출석 수정
  - [x] 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정할 수 있다.
  - [x] 출력 요구사항
    - [x] 수정 후에는 변경 전과 변경 후의 기록을 확인할 수 있다.

```
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

- [x] 크루별 출석 기록 확인
    - [x] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인할 수 있다.
      - [x] 날짜, 시간으로 출석 상태를 계산한다.
      - [x] 출석 상태별 횟수를 계산한다.
      - [x] 관리 대상자 여부를 계산한다. (경고, 면담, 제적)

```
닉네임을 입력해 주세요.
빙티

이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 10:07 (지각)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:03 (출석)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)
12월 13일 금요일 10:02 (출석)

출석: 3회
지각: 0회
결석: 3회

면담 대상자입니다.
```

- [ ] 제적 위험자 확인
  - [ ] 출력 요구사항
    - [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
    - [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자 순으로 출력한다.
    - [ ] 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순 정렬한다.
    - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

```
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 4회 (면담)
- 이든: 결석 2회, 지각 5회 (면담)
- 빙봉: 결석 1회, 지각 6회 (면담)
- 쿠키: 결석 2회, 지각 3회 (면담)
- 짱수: 결석 0회, 지각 6회 (경고)
```

- [ ] 기타
  - [x] `attendances.csv`를 통해 2월 출석 기록을 불러온다.
  - [ ] 캠퍼스 운영시간이 아닌 경우 출석 확인, 출석 수정 기능을 이용할 수 없다.   
  - [ ] 프로그램이 특정 기능을 수행한 뒤에는 초기 화면으로 돌아간다.
