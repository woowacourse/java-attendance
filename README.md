# java-attendance

## ✅ 출석 정책
- 시간은 24시간 형식만 사용한다.
- 캠퍼스 운영 시간은 매일 08:00 ~ 23:00
- 교육 시간은 월요일 13:00 ~ 18:00, 화요일 ~ 금요일 10:00 ~ 18:00이다.
- 교육 시작 시간으로부터 5분 초과는 지각으로 간주한다.
- 교육 시작 시간으로부터 30분 초과는 결석으로 간주한다.
- 주말 및 공휴일을 제외한 날에 등교하지 않아 출석 기록이 없을 경우 결석으로 간주한다.
- 누적 지각 및 결석 횟수에 따라 경고 또는 면담을 시행한다.
    - 경고 : 결석 2회 이상
    - 면담 : 결석 3회 이상
    - 제적 : 결석 5회 초과
- 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.
