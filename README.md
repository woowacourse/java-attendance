# java-attendance

## 구현 목록

### 메뉴 관련 기능

- [x] 프로그램 가동 시 5가지 메뉴를 제공한다: 출석 확인, 출석 수정, 크루별 출석 기록 확인, 제적 위험자 확인, 종료
- [ ] 사용자가 프로그램 종료를 선택하지 않으면 프로그램을 종료시키지 않는다
- [x] 사용자가 선택지에 없는 메뉴를 입력하면 예외를 발생시킨다
- [x] 프로그램 가동 시 attendances.csv 파일로부터 출석 기록을 읽어 저장한다

### 출석 확인 관련 기능

- [x] 출석을 기록할 크루의 닉네임을 입력 받는다
    - [x] 존재하지 않을 닉네임을 입력한 경우 예외를 발생시킨다
- [x] 등교 시간을 입력 받는다
    - [x] 유효하지 않은 시간을 입력한 경우 예외를 발생시킨다
- [x] 등교일과 등교 시간에 따른 출석 기록을 생성한다
    - [x] 이미 출석한 기록이 있을 경우 예외를 발생시킨다
    - [x] 등교일이 주말 또는 휴일일 경우 예외를 발생시킨다
- [x] 출석이 정상적으로 기록되면 출석 날짜, 시간, 출결 상태를 출력한다

### 출석 수정 관련 기능

- [x] 기록을 수정할 크루의 닉네임을 입력 받는다
    - [x] 존재하지 않을 닉네임을 입력한 경우 예외를 발생시킨다
- [x] 수정할 날짜를 입력 받는다
    - [x] 유효하지 않은 날짜를 입력한 경우 예외를 발생시킨다
- [x] 수정할 시간을 입력 받는다
    - [x] 유효하지 않은 시간을 입력한 경우 예외를 발생시킨다
- [x] 수정을 완료하면 수정 전후의 날짜, 시간, 출결 상태를 출력한다

### 크루별 출석 기록 확인 기능

- [ ] 기록을 확인할 크루의 닉네임을 입력 받는다
    - [ ] 존재하지 않을 닉네임을 입력한 경우 예외를 발생시킨다
- [ ] 입력한 닉네임의 출석 기록을 출력한다
- [ ] 출석 기록에 따른 출석, 지각, 결석 횟수를 출력한다
- [ ] 제적 대상자 여부를 출력한다

### 제적 위험자 확인 기능

- [ ] 전날까지의 출석 기록을 기준으로 제적 위험자를 반환한다
- [ ] 제적 위험자를 항목, 결석 횟수 내림차, 이름 오름차 순으로 정렬해 출력한다
- [ ] 위험자 정렬 시 지각 3회를 결석 1회로 전환해 계산한다
