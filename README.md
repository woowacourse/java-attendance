# java-attendance


### 출석 관리 규칙 및 시스템 설계 정책

--- 

# 입력 기능
- [ ] 기능 선택 입력
- [ ] 닉네임 입력
- [ ] 출석 날짜 입력 
- [ ] 시간 입력


# 출력 기능
- [ ] 기능 선택 화면
- [ ] 출석 확인 화면  
- [ ] 출석 수정 완료 화면
- [ ] 출석 기록 화면
- [ ] 제적 위험자 확인 화면

# 파일 입력 기능
- [ ] 파일 입력 기능


# 기능 요구사항
- [ ] 공통 요구사항
  - [ ] 시간 형식은 24시간으로 한다. 
  - [ ] 예외 발생시 재입력을 한다.
  - [ ] 예외 메시지는 [ERROR]로 시작한다.
  - [ ] 캠퍼스 운영 시간은 매일 08:00 ~ 23:00 
  - [ ] 월요일은 13시부터 18시, 화~금은 10시부터 18시
  
- [ ] 기능 선택 
  - [ ] 출석 확인 기능
    - [ ] 5분 초과시 지각, 30분 초과시 결석, 출석 기록이 없을 시 결석
    - [ ] 주말 및 공휴일에는 출석을 받지 않는다.
  - [ ] 출석 수정 기능
  - [ ] 출석 기록 기능 
    - [ ] 지각 3회는 결석 1회로 간주한다.
    - [ ] 결석 2회 이상 경고, 3회 이상 면담, 5회 초과 제적
  - [ ] 제적 위험자 조회 기능
  - [ ] 종료 기능


# 예외 처리
- [ ] 기능 선택 입력
  - [ ] 지정된 기능 (1,2,3,4,Q) 이외의 입력 시 "없는 기능입니다."
- [ ] 닉네임 입력
  - [ ] 없는 닉네임 입력할 시 "존재하지 않는 크루입니다."
- [ ] 출석 날짜 입력
  - [ ] 숫자가 아닌 값을 입력 하였을 때 "숫자를 입력하셔야 합니다."
  - [ ] 1부터 31까지 범위를 벗어난 값을 입력 하였을 때 "1~31 사이의 수를 입력하셔야 합니다."
  - [ ] 주말 및 공휴일 입력 시 "공휴일은 출석을 받지 않습니다."
- [ ] 시간 입력
  - [ ] 숫자가 아닌 값을 입력 하였을 때 "숫자를 입력하셔야 합니다."
  - [ ] 콜론(:) 이외의 구분자를 입력하지 않을 시 "콜론(:)으로 시,분을 구분해 주세요."
  - [ ] 콜론으로 분리를 하였을 때 길이가 2가 아닐 경우 "콜론을 하나만 입력해 주세요."
