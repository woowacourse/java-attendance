# java-attendance

## 기능 목록

1. 메뉴 선택 기능
   - [ ] 1, 2, 3, 4, Q에 따라 각 기능으로 이동해야 한다.
   - [ ] 이외의 값이 입력되면 예외가 발생한다.
2. 파일 입력 기능
   - [ ] attendances.csv로부터 출석 기록을 불러온다.
3. 출석 기능
   - [ ] 캠퍼스 운영 시간은 매일 08:00 ~ 23:00이다.
   - [x] 교육 시간은 월요일 13:00 ~ 18:00 / 화요일 ~ 금요일 10:00 ~ 18:00이다.
   - [x] 5분 초과는 지각, 30분 초과는 결석이다.
   - [ ] 주말과 공휴일에는 출석을 받지 않는다.
4. 제적 위험도 판별 기능
   - [ ] 경고 대상자는 결석 2회 이상인 경우
   - [ ] 면담 대상자는 결석 3회 이상인 경우
   - [ ] 제적 대상자는 결석 5회 초과인 경우
   - [ ] 지각 3회당 결석 1회로 가정한다.
5. 닉네임 입력 기능
   - [ ] 닉네임 입력 안내 메시지를 출력한다.
   - [ ] 닉네임을 입력받는다.
   - [ ] 크루 존재 여부를 확인해 존재하지 않을 경우 예외가 발생한다.
6. 출석 확인 기능 (1)
   - [ ] 캠퍼스 운영 시간이 아닐 경우 예외가 발생한다.
   - 닉네임 입력 기능
   - [ ] 이미 출석한 경우 예외가 발생한다. (다시 출석하도록 안내한다.)
   - [ ] 등교 시간 입력 안내 메시지를 출력한다.
   - [ ] 등교 시간을 입력받는다.
   - 출석 기능
7. 출석 수정 기능 (2)
   - 닉네임 입력 기능
   - [ ] 수정 희망 날짜를 입력받는다.
   - [ ] 수정 가능한 날짜가 아닐 경우 예외가 발생한다. (해당 달의 날짜가 아닐 경우, 주말이나 공휴일, 기록이 없는 경우)
   - [ ] 등교 시간 입력 안내 메시지를 출력한다.
   - [ ] 등교 시간을 입력받는다. 
   - 출석 기능 (수정)
   - [ ] 수정 결과를 출력한다.
8. 크루별 출석 기록 확인 기능
   - 닉네임 입력 기능
   - [ ] 전날까지의 출석 기록을 출력한다.
9. 제적 위험자 확인 기능
   - [ ] 제적, 면담, 경고 대상자 순으로 출력한다.
   - [ ] 지각을 결석으로 간주하여 내림차순, 같을 경우 닉네임 오름차순으로 정렬한다.
