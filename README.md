# java-attendance

## 기능 요구사항

### 출석 관리 규칙 및 시스템 설계 정책

- [x] 시간은 24시간 형식만 사용한다. 예를 들어, "22:30"은 오후 10시 30분을 의미한다.
- [x] 교육 시간
    - [x] 월요일 13:00 ~ 18:00
    - [x] 화요일~금요일은 10:00 ~ 18:00
- [x] 출석, 지각, 결석 정책
    - [x] 시작 시각으로부터 5분 초과는 지각
    - [x] 시작 시각으로부터 30분 초과는 결석
    - [x] 등교하지 않아 출석 기록이 없는 날은 결석
- [x] 경고, 면담, 제적 정책
    - [x] 지각 3회는 결석 1회로 간주한다.
    - [x] 경고 대상자: 결석 2회 이상
    - [x] 면담 대상자: 결석 3회 이상
    - [x] 제적 대상자: 결석 5회 초과
- [x] 캠퍼스 운영 정책
    - [x] 운영 시간 08:00~23:00
    - [x] 주말에는 출석을 받지 않는다.
    - [x] 공휴일에는 출석을 받지 않는다.
- [x] 등록된 크루와 출석 기록
    - [x] 제공된 파일(attendances.csv)에서 등록된 크루와 12월 출석 기록을 확인할 수 있다.
- [x] 프로그램 종료 정책
    - [x] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

### 출석 확인 기능

- [x] 닉네임과 등교 시간을 입력받는다.
    - [x] 등록되지 않은 닉네임의 경우 예외 처리한다.
- [x] 출석 후 출석 기록을 확인할 수 있다.
- [x] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.
    - [x] 출석하는 날짜에 해당하는 크루의 출석 데이터가 있는지 확인한다.

~~~
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 05일 화요일 09:59 (출석)
~~~

### 출석 수정

- [x] 닉네임, 수정하려는 날짜, 등교 시간을 입력받는다.
- [x] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인할 수 있다.
    - [x] 변경 전 해당 날짜의 기록이 존재하는지 확인한다.

~~~
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
~~~

### 크루별 출석 기록 확인

- [ ] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인할 수 있다.
    - [ ] 주말은 출력하지 않는다
    - [x] 출석 기록이 없는 날은 결석 처리한다.
    - [x] 출석, 지각, 결석 횟수를 구한다.
    - [x] 위험 대상자인지 확인한다.

~~~  
닉네임을 입력해 주세요.
빙티

이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 10:07 (지각)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:03 (출석)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)
12월 13일 금요일 10:02 (출석)

출석: 5회
지각: 2회
결석: 3회

면담 대상자입니다.
~~~

### 제적 위험자 확인

- [x] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력
- [x] 항목별 정렬 순서는 지각을 결석(3:1)으로 간주하여 내림차순한다.
- [x] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

~~~
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 4회 (면담)
- 이든: 결석 2회, 지각 5회 (면담)
- 빙봉: 결석 1회, 지각 6회 (면담)
- 쿠키: 결석 2회, 지각 3회 (면담)
- 짱수: 결석 0회, 지각 6회 (경고)
~~~
