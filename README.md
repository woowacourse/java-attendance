# java-attendance

## 패키지, 클래스 목록
- [x] util
    - [x] FileInput : file 을 읽는 클래스입니다. File 객체와 BufferedReader 객체를 통해 파일을 읽는 메서드가 있습니다.
    - [x] LocalDateTimePrintFormatter : 출력을 위해 LocalDateTime 을 포맷하는 클래스입니다.
- [x] controller
    - [x] Controller : model 간의 연결, model 과 view 와의 연결하는 로직을 담당합니다.
- [x] model
    - [x] AttendanceCalculatorByDay : 요일 별 지각 시간, 결석 시간, dayOfWeekValue 을 담고 있는 Enum 클래스입니다.
날짜를 입력받아 출석, 지각, 결석을 판단하는 메서드가 있습니다.
    - [x] AttendanceStatus : 학생이 가질 수 있는 지각, 출석, 결석을 담고 있는 Enum 클래스입니다.
    - [x] Student : 요일 별 결과를 담고 있는 Map 과 지각, 출석, 결석의 횟수를 멤버 변수를 가지고 있는 클래스입니다. LocalDateTime 을 통해 상태를 업데이트하고, 저장하는 메서드를 가지고 있습니다.
    - [x] StudentRepository : Student 들을 List 를 통해 멤버 변수를 가지고 있습니다. 파일을 읽고, 학생 객체를 생성합니다.
    - [x] StudentPunishment : 각 처벌의 기준과 이름을 가지고 있는 Enum 클래스입니다.
    - [x] TodayDate : 오늘 날짜를 가지고 있는 클래스입니다.
- [x] view
    - [x] InputView : 사용자에게 입력을 요구하는 안내 메세지를 출력하고, 입력을 받는 클래스입니다. 사용자 입력으로부터 간단한 검증을 합니다.
    - [x] OutputView : 사용자에게 결과에 해당하는 메세지를 출력하는 클래스입니다.
---
## 기능 목록
- [x] 1번을 눌렀을 경우
    - [x] 닉네임을 입력받는다.
    - [x] 등교 시간을 입력받는다.
    - [x] 정보를 업데이트 하고, 출력한다.
- [x] 2번을 눌렀을 경우
    - [x] 닉네임을 입력받는다. 
    - [x] 날짜를 입력받는다.
    - [x] 변경할 시간을 입력받는다.
    - [x] 정보를 업데이트 하고, 출력한다.
- [x] 3번을 눌렀을 경우
    - [x] 닉네임을 입력받는다.
    - [x] 출석 기록을 출력한다.
- [x] 4번을 눌렀을 경우
    - [x] 제적 위험자를 출력한다.
- [x] 5번을 눌렀을 경우
    - [x] 프로그램을 종료한다.
---
## 요구 사항
- [x] 교육 시작 시간으로부터 5분 초과 시 지각
- [x] 교육 시작 시간으로부터 30분 초과 시 결석
- [x] 지각 3회는 결석 1회로 간주한다.
- [x] 결석 5회 초과는 제적 대상자.
---
## 예외 처리
- [x] 존재하지 않는 닉네임을 입력한 경우 - [ERROR] 등록되지 않은 닉네임입니다. 를 출력 후 재입력 받습니다.
- [x] 등교 시간을 잘못 적은 경우 
    - [x] 잘못된 형식으로 입력한 경우 - [ERROR] 시간 형식에 맞지 않습니다. 를 출력 후 재입력 받습니다.
    - [x] 캠퍼스 운영 시간이 아닌 경우 - "[ERROR] 캠퍼스 운영 시간이 아닙니다." 를 출력 후 재입력 받습니다.
