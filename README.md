# java-attendance

---

### 운영 시간
- [x] 평일 08:00 ~ 23:00 (주말, 공휴일 제외)

### 교육 시간
- [x] 월 -> 13:00 ~ 18:00
- [x] 화 ~ 금 -> 10:00 ~ 18:00

### 출석
- [x] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
    - [x] 등교 시간 -> 출석 상태
      - [x] 5분 초과 -> 지각
      - [x] 30분 초과 -> 결석
    - [x] 닉네임 -> 출석 기록 관리
- [x] 출석 기록이 없는 날 -> 결석
- [x] 이미 출석한 경우 -> 출석 불가

### 출석 수정
- [x] 닉네임, 수정하려는 날짜, 등교 시간 -> 수정
- [x] 출석 기록이 없는 경우 -> 수정 불가

### 크루별 출석 기록 확인
- [x] 닉네임 -> 전날까지의 크루 출석 기록

### 제적 위험자 확인
- [x] 전날까지의 크루 출석 기록들 -> 제적 위험자
- [x] 정렬  
  - [x] (1) 위험도 내림차순 
  - [x] (2) 닉네임 오름차순  

### 결석
- [x] 지각 3회 -> 결석 1회
- [x] 경고 -> 결석 2회 이상
- [x] 면담 -> 결석 3회 이상
- [x] 제적 -> 결석 6회 이상

### 기타
- [x] 시간은 24시간 형식만 사용한다.
- [x] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.
- [x] 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(attendances.csv)에서 확인할 수 있다.
