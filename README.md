# java-attendance
> 최소한의 기능을 갖춘 12월 출석 시스템

## 시스템 기능
### 1. 출석 확인
- [ ] 닉네임, 시간을 입력한다
- [ ] 존재하지 않은 닉네임인 경우 예외를 발생시킨다
- [ ] 이미 출석했다면 출석 수정(2번) 으로 안내한다
- [x] 휴일이거나, 캠퍼스가 열지 않은 시간이라면 예외를 발생시킨다
- [x] 출석을 저장한다
- [x] 출석 상태(지각, 결석, 출석)를 계산한다
- [ ] 결과를 출력한다

### 2. 출석 수정
- [ ] 닉네임, 날짜, 시간을 입력한다
- [ ] 존재하지 않은 닉네임인 경우 예외를 발생시킨다
- [ ] 미래이거나, 휴일이거나, 캠퍼스가 열지 않은 시간이라면 예외를 발생시킨다
- [ ] 기존 출석을 삭제하고 새로운 출석을 저장한다
- [ ] 변경 전과 변경 후의 출석 기록을 출력한다

### 3. 크루 별 출석 기록 확인
- [ ] 닉네임을 입력한다
- [ ] 존재하지 않은 닉네임인 경우 예외를 발생시킨다
- [ ] 전날 까지의 크루의 출석 기록을 출력한다

### 4. 제적 위험자 확인
- [ ] 전날 까지의 기록을 기준으로 제적 위험자를 출력한다
  - [ ] 제적 위험자는 제적, 면담, 경고 순으로 출력하며, 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다. 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

### Q. 종료
- [ ] 시스템을 종료한다

### ETC
- [ ] `attendances.csv`에서 파일을 불러와 초기 출석 상태를 저장한다
- [ ] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.
- [ ] 올바른 입력 형식이 아니라면 예외를 발생시킨다
  - [ ] 시간(HH:mm)
  - [ ] 날짜(DD)
  - [ ] 기능 선택(1,2,3,4,Q)
