# java-attendance

출석 미션 저장소

---

# 구현할 기능 목록

## 🗂️ Domain

### Crew
- [x] 크루 이름 저장
- [x] 크루 이름 일치 확인

### CrewStatus
- [x] 크루의 경고, 면담, 제적 상태 및 결석 횟수 조건
  - [x] 지각 3회는 결석 1회로 간주
  - [x] 경고 대상자는 2회 이상, 면담 대상자는 3회 이상, 제적 대상자는 5회 초과 결석

### AttendanceLog
- [x] 일별 출결 기록
  - [x] 출결 기록 날짜
  - [x] 출결 기록 시간
  - [x] 출결 기록 상태
- [x] 출결 기록 생성
  - [x] 월요일은 13:00-18:00, 화-금요일은 10:00-18:00 출석 처리 (5분 초과 지각, 30분 초과 결석 처리)
  - [x] 캠퍼스 운영 시간 08:00-23:00 출석 가능

### AttendanceLogs
- [x] 전체 츨결 기록
- [x] 일별 출결 기록 추가
- [x] 전체 지각, 결석 횟수 계산
- [x] 전체 출결 기록에 따른 크루의 상태 계산
 
### AttendanceBook
- [x] 크루와 출결 기록 매핑
- [x] 크루 검색
  - [x] 존재하지 않는 크루 닉네임인 경우 예외 발생

- [x] 출석 확인
- [x] 출석 수정
- [x] 크루별 출결 기록 확인
  - [x] 검색한 크루에 해당하는 출결 기록 확인
- [x] 제적 위험자 확인
  - [x] 지각 3회를 결석 1회로 간주해 결석 횟수 내림차순 정렬
  - [x] 결석 횟수가 같은 경우 닉네임 오름차순 정렬

### AttendanceStatus
- [x] 출석, 지각, 결석 상태

### AttendanceResult
- [x] 전체 출결 기록의 지각 및 결석 횟수
- [x] 전체 출결 기록의 상태(정상, 경고, 면담, 제적)

### Menu
- [x] 출석 확인, 출석 수정, 크루별 출석 기록 확인, 제적 위험자 확인, 종료 기능
