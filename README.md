# java-attendance

출석 미션 저장소

## 요구 기능 사항

### 교육 시간 판정 기능

- [X] `주말`은 `운영 시간`이 아니다.
- [X] `공휴일`은 `운영 시간`이 아니다.
- [X] `운영 시간 외`은 `운영 시간`이 아니다.
- [X] 캠퍼스 `운영 시간`은 매일 `08:00~23:00`이다.
- [X] `교육 시간`은 `월요일`은 `13:00~18:00`, `화요일`~`금요일`은 `10:00~18:00`이다.
- [X] `운영 시간 외`에 `교육 시간`을 판정 시도하면 예외를 throw한다.

### 출석 결과 판정 기능

- [X] 운영 정책을 기반으로 출석 결과를 판정한다.
- [X] 운영 정책은 다음 조건을 적용한다.
    - [X] 해당 요일의 시작 시각으로부터 `5분 초과`는 `지각`으로 간주한다.
    - [X] 해당 요일의 시작 시각으로부터 `30분 초과`는 `결석`으로 간주한다.
    - [X] 등교하지 않아 `출석 기록이 없는 날`은 `결석`으로 간주한다.

### 당일 날짜 데이터 제공 기능

- [X] 오늘에 해당되는 년, 월, 일을 저장해야 한다.
- [X] 오늘에 해당되는 월초부터 당일 직전까지의 운영 대상 날짜 데이터를 제공한다.

### 출석 확인 기능

- [ ] 사용자로부터 `닉네임`과 `등교 시간`을 입력받는다.
- [X] 사용자의 출석을 저장한다.
- [ ] 출석 처리 완료 후, `당일 날짜`, `요일`, `시간`, `출석 결과`를 주어진 형식에 맞게 출력한다.
- [X] 존재하지 않는 닉네임일 경우, 예외를 throw한다.
- [X] 이미 당일 출석이 존재하는 경우, 예외를 throw한다.
- [X] `운영 시간`외 시간에 출석을 시도하는 경우, 예외를 throw한다.

### 출석 위험 대상자 판정 기능

- [X] 출석 결과를 기반으로 `누적 지각 및 결석 횟수`를 세야 한다.
- [X] `지각` 3회는 `결석` 1회로 간주한다.
- [X] `누적 지각 및 결석 횟수`에 따라 `경고` 또는 `면담`을 시행한다. 또한 결석 횟수가 `5회를 초과`할 때 `제적`을 시행한다.
    - [X] `경고` 대상자: `결석` 2회 이상
    - [X] `면담` 대상자: `결석` 3회 이상
    - [X] `제적` 대상자: `결석` 5회 초과

### 출석 수정 기능

- [ ] 사용자로부터 `닉네임`, `수정하려는 날짜`, `등교 시간`을 입력받는다.
- [X] 사용자의 변경 대상 출석 데이터를 수정한다.
- [ ] 수정 처리 후, `변경 전`과 `변경 후`의 `출석 기록`을 주어진 형식에 맞게 출력한다.

### 크루별 출석 기록 확인

- [ ] 사용자로부터 `닉네임`을 입력받는다.
- [ ] 전날까지의 크루 출석 기록을 주어진 형식에 맞게 출력한다.
- [X] 전날까지의 크루 출석 기록을 조회한다.
- [X] 전날까지의 크루 출석 기록에서 누락된 날짜의 출석도 포함하여 조회한다.
- [ ] `출석`, `지각`, `결석` 횟수를 순서대로 출력한다.
- [ ] `출석 위험 대상자`일 경우, `출석 위험 대상자 판정 결과`를 출력한다.

### 제적 위험자 조회 기능

- [ ] 제적 위험 대상자를 출력한다.
- [X] 제적 위험 여부를 판정한다.
- [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력한다.
- [X] 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.
- [X] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

### 출석 데이터 로드 기능

- [ ] csv 파일로부터 저장되어있는 사용자별 출석 데이터를 가져와야 한다.
- [ ] csv 파일로부터 읽어온 데이터로 출석 데이터를 저장한다.
