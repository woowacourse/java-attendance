# java-attendance

출석 미션 저장소

### 출석부

- [ ] 출석 기록 파일을 읽어와, 해당 파일에 있는 크루를 기준으로 출석부를 생성한다.

### 출석

- [x] 출석부에 없는 크루 닉네임으로 접근 시, "[ERROR] 출석부에 존재하지 않는 닉네임입니다." 를 출력하고 초기 화면으로 돌아간다.
- [ ] 월요일 교육 시간은 13:00 - 18:00, 그 외의 평일엔 10:00 - 18:00이다.
    - [x] 교육 시작 시간 기준 5분까지 출석, 30분까지는 지각, 이후는 결석으로 처리한다.
- [ ] 출석 시간의 포맷은 'HH:MM' 이다. 만약 포맷이 안맞을 시, "[ERROR] 올바르지 않은 입력입니다."를 출력하고 초기 화면으로 돌아간다.
- [x] 캠퍼스 운영 시간은 08:00 - 23:00 이다. 이외의 시간을 입력할 시 "[ERROR] 캠퍼스 운영 시간이 아닙니다."를 출력하고 초기 화면으로 돌아간다.

### 출석하기

- [x] 출석을 추가하기 전, 해당 요일이 주말 또는 공휴일일 경우 "[ERROR] 주말 및 공휴일은 출석할 수 없습니다."를 출력하고 초기 화면으로 돌아간다.
- [ ] 닉네임을 입력한다.
    - [x] 이미 입력된 크루의 출석이 해당 요일이 있는 경우 "[ERROR] 이미 출석 기록이 존재합니다. 수정 기능을 이용해 주세요."를 출력하고 초기 화면으로 돌아간다.
- [ ] 출석 시간을 입력한다.

### 출석 수정하기

- [ ] 닉네임을 입력한다.
- [ ] 날짜(일)을 입력한다.
    - [ ] 크루와 해당 날짜에 대한 출석 기록이 없는 경우 "[ERROR] 출석 기록이 존재하지 않습니다."를 출력하고 초기화면으로 돌아간다.
    - [ ] 1-31을 제외한 숫자가 들어올 경우 "[ERROR] 올바르지 않은 입력입니다."를 출력하고 초기화면으로 넘어간다.
- [ ] 출석 시간을 입력한다.

### 크루별 출석 기록 확인하기

- [ ] 닉네임을 입력한다.
- [ ] 현재 달, 해당 크루의 출석 기록을 출력한다.
    - [ ] 출석 기록이 있어야하지만 없는 경우에는 결석으로 처리한다.
- [ ] 해당 크루의 출석 횟수, 지각 횟수, 결석 횟수를 출력한다.
- [ ] 지각 횟수, 결석 횟수를 통해 학적 상태를 출력한다.
    - [ ] 지각 3회는 결석 1회로 간주한다.
    - [ ] 경고 대상자: 결석 2회 이상
    - [ ] 면담 대상자: 결석 3회 이상
    - [ ] 제적 대상자: 결석 5회 초과

### 제적 위험자 확인하기

- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력하며, 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다. 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.
