# java-attendance

출석 미션 저장소

### 1. 파일 입출력
- [x] 리소스에 있는 csv 파일에 데이터를 입력한다

### 2. 크루별 출석 기록 확인
- [x] 사용자로부터 닉네임을 입력받는다.
- [x] 입력받은 닉네임에 해당하는 크루를 가져온다.
- [x] 크루의 출석 기록을 출력한다.
- [x] 크루의 출석 기록 통계를 출력한다.
- [x] 만약 제적위험자(면담, 경고 등)이라면, 대상자임을 알린다.

#### 예외 사항
1. 입력받은 닉네임에 해당하는 크루가 없다면, 예외가 발생한다.

### 3. 크루 출석 확인
- [x] 사용자로부터 닉네임을 입력 받는다.
- [x] 사용자로부터 등교시간을 입력 받는다.
- [x] 만약 출석을 했다면 수정 기능으로 안내한다.
- [x] 크루에게 등교시간에 대한 출석 결과를 추가한다.
- [x] 출석 결과를 출력한다.

#### 예외 사항
1. 입력받은 닉네임에 해당하는 크루가 없다면, 예외가 발생한다.
2. 올바르지 않은 시간을 입력하면, 예외가 발생한다.
3. 등교일이 아닌날에 출석하면, 예외가 발생한다.
