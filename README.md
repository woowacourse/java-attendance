# 2단계 : 출석 다시 구현하기

## 기능 요구 사항

### 출석 확인

- **닉네임**, **등교 시간**을 입력하여 출석한다.
  - 출석 날짜는 오늘로 기록된다.
- 출석 후에는 **날짜**, **등교 시간**, **출석 상태**를 확인할 수 있다.
- 예외 상황
  - 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 사용하도록 안내한다.
  - 존재하지 않는 닉네임인 경우, 메시지를 출력 후 메인 화면으로 돌아간다.
  - 출석할 수 없는 시간인 경우, 메시지를 출력 후 메인 화면으로 돌아간다.
  - 오늘이 주말 및 공휴일인 경우, 메시지를 출력 후 메인 화면으로 돌아간다.

### 출석 수정

- **닉네임**, **날짜**, **등교 시간**을 입력하여 수정한다.
  - 기존에 출석하지 않았던 날짜도 수정할 수 있다. (결론적으로 출석 기록 추가)
- 수정 후에는 **날짜**, **수정 전 시간**, **수정 전 출석 상태**, **수정 후 시간**, **수정 후 출석 상태**를 확인할 수 있다.
- 예외 상황
  - 존재하지 않는 닉네임인 경우, 메시지를 출력 후 메인 화면으로 돌아간다.
  - 출석할 수 없는 시간으로 수정하려는 경우, 메시지를 출력 후 메인 화면으로 돌아간다.

### 크루별 출석 기록 확인

- **닉네임**을 입력하여 이번 달의 출석 기록을 확인한다.
- **각 날짜별 출석 기록**, **총 출석/지각/결석 횟수**, **면담 대상자 여부**를 확인할 수 있다.
  - 출석 가능한 날짜(주말, 공휴일 제외)에 대한 기록만을 반환한다.
  - 기록이 없는 경우에도 `--:--` 포맷으로 반환한다. (결석)

### 제적 위험자 확인

- 위험자 크루별 **결석 횟수**, **지각 횟수**, **위험 상태**를 확인할 수 있다.
  - 정상 상태와 제적자는 제외한다.
