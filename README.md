# 기능 구현 목록

## 요구사항
- 교육 시간 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00이다.
- 캠퍼스 운영 시간은 매일 08:00~23:00이다.
- 해당 요일의 시작 시각으로부터 5분 초과는 지각으로 간주한다.
- 해당 요일의 시작 시각으로부터 30분 초과는 결석으로 간주한다.
- 주말 및 공휴일에는 출석을 받지 않는다.

- 지각 3회는 결석 1회로 간주한다.
- 경고 대상자: 결석 2회 이상
- 면담 대상자: 결석 3회 이상
- 제적 대상자: 결석 5회 초과

- 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

## 기능 구현 목록

- [x] 파일을 읽고 출석 정보를 가져온다.
- [x] 출석 기록을 추가한다.
### 출석 확인
- [] 출석할 이름을 입력 받는다.
- [] 출석할 시간을 입력 받는다.
- [x] 기존의 출석기록 여부를 확인한다.
- [] 출석기록이 있다면 수정기능을 이용하도록 안내한다.
- [x] 출석 기록을 추가한다.
- [x] 출석 상태를 판단한다.
- [] 추가된 출석 기록을 출력한다.
- [x] [예외] 출석날짜가 공휴일, 주말일 경우 예외를 반환한다.
- [x] [예외] 출석기록에 존재하지 않는 이름을 입력한 경우 예외를 반환한다.
- [x] [예외] 출석시간이 캠퍼스 운영시간이 아닌 경우 예외를 반환한다.

### 출석 수정
- [] 수정할 이름을 입력 받는다.
- [] 수정할 날짜를 입력 받는다.
- [] 수정할 시간을 입력 받는다.
- [x] 출석 기록을 수정한다.
  - [x] 출석 수정을 원하는 날짜에 출석기록 여부를 확인한다.
- [x] 출석 상태를 판단한다.
- [] 변경 전의 출석기록과 변경 후의 출석 기록을 출력한다.
  - [] 출석기록이 없었던 경우 '--:--' 로 출력한다.
- [x] [예외] 출석기록에 존재하지 않는 이름을 입력한 경우 예외를 반환한다.
- [x] [예외] 수정 시간이 캠퍼스 운영시간이 아닌 경우 예외를 반환한다.
- [x] [예외] 출석날짜가 공휴일, 주말일 경우 예외를 반환한다.

### 크루별 출석 확인
- [] 출석 기록을 확인할 이름을 입력 받는다.
- [x] 해당 이름의 전날까지 출석 기록을 조회한다.
- [x] 출석 상태를 판단한다.
- [] 크루의 출결상태를 집계한다.
- [] 출결상태에 따라 경고, 면담, 제적 위험자인지 판단한다.
- [] 출결상태를 출력한다.
- [] 위험자 여부를 출력한다.
- [x] [예외] 출석기록에 존재하지 않는 이름을 입력한 경우 예외를 반환한다.

### 제적위험자 확인
- [] 크루별로 전날 까지 출결기록을 조회한다.
- [] 크루별로 출결 상태를 판단한다. (제적, 면담, 경고 순 , 지각횟수 내림차순, 이름순)
- [] 크루별 출결 상태를 출력한다.
