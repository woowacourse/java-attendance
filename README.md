# java-attendance

### 기능 목록
- [x] 파일의 모든 줄을 읽어온다.
- [x] 크루를 생성한다.
  - 닉네임은 2글자 이상, 4글자 이하만 가능하다.
  - 해당 범위를 벗어나면 예외를 발생시킨다.
- [x] 출석을 생성한다.
  - 출석 시간이 휴일인 경우 예외를 발생시킨다.
    - 휴일은 주말과 양력 공휴일이다.
  - 캠퍼스 운영 시간을 벗어나면 예외를 발생시킨다.
- [x] 출석을 수정한다.
- [x] 출석을 저장한다.
- [x] 출석을 조회한다.
- [x] 전날까지의 모든 출석을 조회한다.
- [x] 지각/결석 여부를 확인한다.
  - 지각은 시작 시간으로부터 5분 초과 30분까지다
  - 결석은 시작 시간으로부터 30분 초과부터다
- [x] 제적/면담/경고 대상자인지를 확인한다.
- [ ] 닉네임을 입력받는다.
- [ ] 등교 시간을 입력받는다.
- [ ] 수정 일자를 입력받는다.
- [ ] 변경 시간을 입력받는다.
- [ ] 출석 기록을 출력한다.
- [ ] 수정된 출석 기록을 출력한다.
- [ ] 오늘 날짜를 확인한다.
- [ ] 제적 위험자를 확인한다.
