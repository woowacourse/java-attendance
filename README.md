# 1단계 - 출석 미션

### 목표: 12월 시범 출석 관리 시스템

### 출석 규칙
* 출석 확인 기준은 저장된 시간이다.
* 시간은 24시간 형식만 사용한다. (00:00 ~ 24:00)
* 캠퍼스 운영 시간은 매일 08:00 ~ 23:00이다.
* 주말 및 공휴일에는 출석을 받지 않는다.
* 교육시간
  * 월요일 13:00 ~ 18:00
  * 화-금요일 10:00 ~ 18:00
* 지각 및 결석 기준
  * 출석: 00분 ~ 05분
  * 지각: 06분 ~ 30분
  * 결석: 31분 ~ + 출석 기록이 없는 날
* 경고 및 면담 기준
  * 지각 3회 = 결석 1회로 판단 후 다음 조건 확인
  * 경고 대상자: 결석 2회 이상
  * 면담 대상자: 결석 3회 이상
  * 제적 대상자: 결석 5회 초과

## 기능 구현 목록

### 파일 읽기
- [ ] 출석 시스템에 등록된 크루 정보와 12월 출석 기록 파일(attendances.csv)을 읽어올 수 있다.

###  기능 선택
- [ ] 1~4번까지의 기능을 선택한다.
  - [ ] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다. 
  - [ ] 유효하지 않은 번호를 입력한 경우 예외 발생
- [ ] 종료를 선택하면 프로그램이 종료된다.
### 출석 확인
- [ ] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
- [ ] 출석 후 출석 기록을 확인할 수 있다.
- [ ] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 안내한다.

### 출석 수정: 정보를 입력받아 출석을 수정한다.
- [ ] 닉네임을 입력받는다.
  - [ ]문자열이 비어있는 경우 예외 발생
  - 등록되지 않은 닉네임인 경우 예외 발생
- [ ] 수정하려는 날짜를 입력받는다.
  - [ ]숫자가 아닌 경우 예외 발생
  - [ ]날짜 범위가 아닌 경우 예외 발생
  - [ ]휴일인 경우 예외 발생
- [ ] 변경 등교 시간을 입력받는다.
  - [ ]시간 형식이 유효하지 않은 경우 예외 발생
  - [ ]캠퍼스 운영 시간이 아닌 경우 예외 발생
- [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 출력한다. (`변경전` -> `변경후`)

### 크루별 출석 기록 확인
- [ ] 닉네임을 입력받는다.
    - [ ] 등록되지 않은 닉네임인 경우 예외 발생
- [ ] 크루 출석 기록을 전날까지 출력한다.
- [ ] 출석 통계를 출력한다.
- [ ] 경고, 면담, 제적에 해당하는 경우 상태를 출력한다.

### 제적 위험자 확인
- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [ ] 제적 대상자, 면담 대상자, 경고 대상자순으로 정렬하여 출력한다.
  - [ ] 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.
  - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.
