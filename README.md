# java-attendance

## 기능 요구사항

### `attendances.csv`에서 지난 출석 정보 불러오기

- [x] 크루들의 지난 출석 정보를 저장한다.

### 출석 등록

- [x] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
    - [ ] 등교 시간은 "HH:mm" 형태이다.
    - [x] 존재하는 크루의 닉네임이어야 한다.
    - [x] 주말 및 공휴일에는 출석할 수 없다.
- [x] 출석 후 출석 기록을 확인할 수 있다.
- [x] 이미 출석한 경우, 다시 출석할 수 없다.

### 출석 수정

- [x] 닉네임과 수정하려는 날짜, 등교 시간을 입력하면 출석 기록을 수정할 수 있다.
    - [ ] 등교 시간은 "HH:mm" 형태이다.
    - [x] 존재하는 크루의 닉네임이어야 한다.
    - [x] 주말 및 공휴일에는 출석할 수 없다.
    - [x] 오늘 이후의 날짜는 출석을 수정할 수 없다.
- [x] 수정 후 변경 전과 변경 후의 출석 기록을 확인할 수 있다.

### 크루별 출석 기록 확인

- [x] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인할 수 있다.
    - [x] 등교하지 않아 출석 기록이 없는 날은 결석으로 간주한다.
- [x] 출석, 지각, 결석 횟수를 확인할 수 있다.
- [x] 제적, 면담, 경고 대상자를 확인할 수 있다.

### 제적 위험자 확인

- [x] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 확인한다.
- [ ] 제적 위험자는 제적, 면담, 경고 대상자 순으로 출력한다.
    - [ ] 지각 3회는 결석 1회로 간주한다.
    - [ ] 지각을 결석으로 간주하여 내림차순한다.
    - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

### 기타 요구사항

- [ ] 프로그램은 사용자가 종료할 때까지 종료되지 않는다.
- [ ] 해당 기능을 수행한 후 초기화면으로 돌아간다.
