# java-attendance

출석 미션 저장소

## 셋업

- [x] 파일 내용을 읽어와서 DB에 저장한다.

## 기능 선택

- [x] 요일과 날짜를 출력하고, 안내 문구를 출력한다.
- [x] 1번 ~ 4번, Q번 입력을 받는다.
  - [x] 각 번호에 맞는 기능을 실행한다.

## 출석 확인 기능

### 1. 출석을 처리한다.

- [x] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
- [x] 이미 출석한 경우, 다시 출석할 수 없다.

### 2. 닉네임과 등교 시간을 입력받아 안내한다.

- [x] 출석 후 출석 기록을 확인할 수 있다.
- [x] 이미 출석한 경우, 수정 기능을 이용하도록 안내한다.

## 출석 수정 기능

- [x] 출석 확인을 수정하려면 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정할 수 있다.
- [x] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인할 수 있다.

## 크루별 출석 기록 확인 기능

- [x] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인할 수 있다.
- [x] 마지막에는 출석/지각/결석 횟수를 반환한다.
- [x] 마지막에는 제적 위험자 유형을 반환한다.

## 제적 위험자 확인 기능

- [x] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [x] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력하며, 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.
  - [x] 지각을 결석으로 간주 -> 지각 3회를 결석으로 처리
- [x] 치환한 결석 횟수가 같으면 닉네임으로 오름차순 정렬한다.

## 종료

- [x] `Q` 입력시 프로그램을 종료시킨다.
