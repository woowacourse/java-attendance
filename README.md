# java-attendance

출석 미션 저장소

# 구현할 기능 목록

- [x] 잘못된 기능을 입력하면 다시 입력하도록 안내하는 기능
- [x] 출석 등록 기능
    - [x] 닉네임과 등교 시간을 입력하여 출석을 등록한다
    - [x] 출석 등록 후 출석 기록을 출력한다
    - [x] 출석 등록 후 출석한 요일(월요일...)을 출력한다
    - [x] 출석 등록 후 출석 상태를 출력한다 (지각, 결석, 출석 ...)
    - [x] 등록되지 않은 닉네임을 입력하면 에러를 출력한다
    - [x] 쉬는 날, 운영 시간 이외를 입력하면 에러를 출력한다
    - [x] 이미 출석한 경우, 수정 기능을 이용하도록 안내한다
    - [x] 출석 관리자에서 출석을 등록하는 기능
    - [x] 출석 관리자에서 이미 출석했는지 확인하는 기능
    - [X] 휴일 및 주말에는 출석을 등록하면 예외가 발생한다
    - [x] 캠퍼스 운영 시 이외로 출석을 등록하면 예외가 발생한다
- [x] 출석 수정 기능
    - [x] 닉네임, 수정할 날짜, 등교 시간을 입력하여 출석 기록을 수정한다
    - [x] 수정 후 변경 전, 변경 후의 출석 기록을 출력한다
    - [x] 수정 후 변경 전, 변경 후의 출석 상태를 출력한다 (지각, 결석, 출석 ...)
    - [x] 등록되지 않은 닉네임을 입력하면 에러를 출력한다
    - [x] 쉬는 날, 운영 시간 이외를 입력하면 에러를 출력한다
    - [x] 출석 관리자에서 출석을 수정하는 기능
    - [X] 휴일 및 주말에는 출석을 수정하면 예외가 발생한다
    - [x] 캠퍼스 운영 시간 이외로 출석을 수정하면 예외가 발생한다
- [X] 크루별 출석 기록 확인 기능
    - [x] 닉네임을 입력하여 `전날`까지의 크루 출석 기록을 확인한다
    - [x] 닉네임의 날짜별 출석 기록을 출력한다
    - [x] 출석과 지각과 결석 횟수를 출력한다
    - [x] 경고와 면담과 제적 대상인지 출력한다
    - [x] 등록되지 않은 닉네임을 입력하면 에러를 출력한다
    - [x] 어제를 기준으로 출석 가능한 날짜들을 가져오는 기능
    - [x] 출석 관리자에서 크루별 출석 기록을 확인하는 기능
- [x] 제적 위험자 확인 기능
    - [x] 추가적인 입력 없이 제적 위험자를 확인한다
    - [x] `전날`까지의 출석 기록으로 제적, 면담, 경고 대상자 순으로 출력한다
    - [x] 출석 기록이 존재하지 않으면 결석으로 처리하는 기능
    - [x] 출석 기록을 토대로 제적 위험자를 가져오는 기능
    - [x] 출력 정렬 순서는 지각을 결석으로 간주하여 내림차순하고, 출석 상태가 같으면 닉네임으로 오름차순 정렬하여 출력한다
- [x] 프로그램 시작시 `src/main/resources/attendances.csv`를 통해 구현에 필요한 크루별 출석 정보를 조회한다

# 구현 완료 후 검토 사항

- [x] 프로그램은 12월을 대상으로 구현한다
- [x] 시간은 24시간 형식을 사용한다
- [x] 교육 시간
    - 월요일은 `13:00`~`18:00`
    - 화~금요일은 `10:00`~`18:00`
- [x] `지각` 판정 해당 요일의 시작 시각으로부터 5분 초과
    - (10:05) 출석
    - (10:06) 지각
- [x] `결석` 판정은 해당 요일의 시작 시각으로부터 30분 초과
- [x] 또는 출석 기록이 없는 경우
    - (10:30) 지각
    - (10:31) 결석
    - (null)  결석
- [x] 누적 지각 및 결석 횟수에 따라 경고 또는 면담을 시행한다
    - 지각 3회는 결석 1회로 간주한다
    - 경고 : 결석 2회 이상
    - 면담 : 결석 3회 이상
    - 제적 : 결석 6회 이상 (결석 5회 초과)
- [x] 캠퍼스 운영 시간은 매일 `08:00`~`23:00`이다
- [x] 주말 및 공휴일에는 출석을 받지 않는다
- [x] 출석 시스템에 등록된 크루와 '12월 출석' 기록은 제공된 파일(attendances.csv)에서 확인할 수 있다
- [x] 프로그램은 사용자가 종료할 때까지 종료되지 않는다
- [x] 기능 수행 후 초기 화면으로 돌아간다
- [x] 등록되지 않은 닉네임을 입력하면 에러를 출력한다
