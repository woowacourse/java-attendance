# 출석 미션 저장소

# 기능 목록

### 크루 출석 기록 확인
- [ ] 파일 파싱
- [ ] 크루 생성
- [ ] 크루 별 출석 기록 저장
  - [ ] 출석 결과 저장

### 출석 확인
- [ ] 닉네임과 등교 시간을 입력한다.
- [ ] 닉네임과 등교 시간을 토대로 출석 확인을 진행한다.
  - [x] 주어진 날짜가 공휴일 혹은 주말인지 판별한다.
  - [x] 등교 시간을 토대로 출석, 지각, 결석을 판별한다.
  - [x] 출석 결과를 저장한다.
  - [ ] 날짜, 등교시간, 출석 결과를 출력한다.

### 출석 수정
- [ ] 닉네임과 등교 시간, 수정 날짜를 입력한다.
- [ ] 닉네임과 등교 시간, 수정 날짜를 토대로 출석을 수정한다.

### 크루 별 출석 기록 확인
- [ ] 출석을 확인할 크루 닉네임을 입력한다.
- [ ] 닉네임을 토대로 출석 기록을 출력한다.

### 제적 위험자 확인
- [ ] 크루 별 지각/결석 횟수를 토대로 제적 위험자를 결정한다.
- [ ] 제적 위험자를 출력한다.
