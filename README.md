# java-attendance

출석 미션 저장소

## 도메인 정보

* 24시간 형식을 사용한다.
* 교육 시간
  * 월요일: 13:00~18:00
  * 화~금요일: 10:00~18:00
* 출석 상태 기준
  * 지각: 5분 초과
  * 결석: 30분 초과 또는 미출석
* 관리 대상자 기준
  * 경고: 결석 2회 이상
  * 면담: 결석 3회 이상
  * 제적: 결석 6회 이상
* 캠퍼스 운영 시간: 매일 08:00~23:00
  * 운영 시간이 아니면 출석을 받지 않는다.
* 주말 및 공휴일에는 출석을 받지 않는다.
* 프로그램이 특정 기능을 수행한 뒤에는 초기 화면으로 돌아간다.

## 기능 설계

- [x] 출석 확인
  - [x] 닉네임과 등교 시간을 입력하여 출석한다.
  - [x] 출석 후 출석 기록을 확인할 수 있다.
  - [x] 이미 출석한 경우, 수정 기능을 이용하도록 안내한다. (출석 처리 x)

- [ ] 출석 수정
  - [ ] 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정할 수 있다.
  - [ ] 수정 후에는 변경 전과 변경 후의 기록을 확인할 수 있다.

- [ ] 크루별 출석 기록 확인
    - [ ] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인할 수 있다.
      - [ ] 날짜, 시간, 출석 상태를 출력한다.
      - [ ] 출석 상태별 횟수를 출력한다.
      - [ ] 관리 대상자 여부를 출력한다. (경고, 면담, 제적)

- [ ] 제적 위험자 확인
    - [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
    - [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자 순으로 출력한다.
    - [ ] 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순 정렬한다.
    - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.
