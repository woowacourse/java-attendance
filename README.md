## 🎭 역할

### 📅 출석 일자
- [ ] 출석 일자를 저장하는 역할
    - 요일을 반환하는 메서드
    - 휴일 여부를 반환하는 메서드

### ⏰ 출석 시각
- [ ] 출석 시각을 저장하는 역할
    - 지각 여부 반환 메서드
    - 결석 여부 반환 메서드
    - 운영 시간 여부 반환 메서드

### 📌 출석 데이터
- [ ] 출석 일자 + 시각을 저장하는 역할
    - 출석 일자, 시각 클래스를 필드로 포함
    - 출석 타입을 반환하는 메서드

### 📝 출석 기록
- [ ] 출석 기록을 관리하는 역할
    - 크루별 출석 기록 확인 메서드
    - 제적 위험자 확인 메서드
    - 데이터 존재 유무 확인 메서드
    - 수정 메서드

### 👤 크루
- [ ] 크루 역할
    - 필드로 크루의 닉네임 포함

### 👥 크루의 일급 컬렉션
- [ ] 크루 존재 여부 확인

### 🏷️ 출석 타입 Enum
- [ ] 출석 타입 관리
    - 출석 상수
    - 지각 상수
    - 결석 상수
    - **💡 고민점:**
        - 필드 `String name;`을 추가해야 할까?
        - 추가하면 **View 변경사항이 Domain에 전파**됨.
        - 추가하지 않으면 **View가 Domain에 의존**해야 함. _(Enum 상수를 기반으로 String을 생성해야 하기 때문)_

### ⚠️ 제적 타입 Enum

    - 제적 상수
    - 면담 상수
    - 경고 상수
