# 출석

## 기능 요구사항

### 데이터 초기화

- [x] `src/main/resources/attendances.csv` 파일 읽기
- [x] 닉네임에 해당하는 크루의 출석 일시 저장
  - [x] 크루의 출석 기록이 중복될 경우 예외 발생

### 출석 확인

- [ ] 캠퍼스 운영일이 아닌 경우 예외
- [ ] 닉네임 입력
    - [ ] 존재하지 않은 닉네임인 경우 예외
    - [ ] 이미 출석한 경우 예외
- [ ] 등교 시간 입력
    - [ ] 유효한 시간 형식이 아닌 경우 예외
    - [ ] 캠퍼스 운영 시간이 아닌 경우 예외
- [ ] 출석 기록 확인

### 출석 수정

- [ ] 닉네임 입력
    - [ ] 존재하지 않은 닉네임인 경우 예외
- [ ] 수정 날짜(일) 입력
    - 존재하지 않은 날짜(일)인 경우 예외
- [ ] 수정할 시간 입력
    - [ ] 유효한 시간 형식이 아닌 경우 예외
    - [ ] 캠퍼스 운영 시간이 아닌 경우 예외
- [ ] 수정 기록 출력

### 출석 기록 확인

- [ ] 닉네임 입력
    - [ ] 존재하지 않은 닉네임인 경우 예외
- [ ] 출석 기록 출력
- [ ] 출석, 지각, 결석 횟수 출력
- [ ] 대상자 유형 출력

> 전날까지의 출석 기록을 기준으로 한다.

### 제적 위험자 확인

- [ ] 제적 위험자 조회 결과 출력
    - [ ] 제적 대상자, 면담 대상자, 경고 대상자 순으로 출력
    - [ ] 지각을 결석으로 간주하여 내림차순 정렬
    - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬
