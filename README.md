# java-attendance

출석 미션 저장소

## 도메인 정보

* 시간은 24시간 형식만 사용한다. 예를 들어, "22:30"은 오후 10시 30분을 의미한다.
* 교육 시간
    * 월요일: 13:00-18:00
    * 화요일-금요일: 10:00-18:00
* 출석 상태 기준
    * 지각: 해당 요일의 시작 시각으로부터 6분 이상 늦음
    * 기록이 있는 결석: 해당 요일의 시작 시각으로부터 31분 이상 늦음
    * 기록이 없는 결석: 등교하지 않아 출석 기록이 없음
* 제적 위험 등급 기준
    * 지각 3회는 결석 1회로 간주한다.
        * 경고: 결석 2회 이상
        * 면담: 결석 3회 이상
        * 제적: 결석 5회 초과
* 출석 시스템에 등록된 크루와 출석 기록은 제공된 파일(attendances.csv)에서 확인할 수 있다.
* 출석을 기록할 수 없는 시간
    * 캠퍼스 운영 시간이 아닌 시간
        * 캠퍼스 운영 시간: 매일 08:00-23:00
    * 주말 및 공휴일
* [x] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

## 기능 요구 사항

### attendances.csv로부터 출석 기록 읽어오기

* [x] `src/main/resources/attendances.csv`에 저장되어있는 출석 기록을 불러온다.
* [x] 불러온 출석 기록을 출석 기록 저장소에 저장한다.

### 메인 화면 안내 기능

* [x] 오늘 날짜와 함께 출석 시스템 기능 안내 메시지를 출력한다.
* [x] 사용자로부터 커맨드를 입력받는다.
    * 가능한 커맨드: 1,2,3,4,Q

```
오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
1
```

### 출석 기록 기능

* [x] 닉네임과 등교 시간을 입력 받는다.
    * [x] 존재하는 크루의 닉네임이여야 한다.
* [x] 출석 기록을 저장한다.
    * [x] 이미 출석 기록이 있는 경우, 다시 출석을 기록할 수 없으며 수정 기능을 이용하도록 안내한다.
* [x] 출석 기록에 성공한 경우 저장한 출석 기록을 출력한다.

```
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 05일 화요일 09:59 (출석)
```

### 출석 기록 수정 기능

* [x] 닉네임, 수정하려는 날짜, 등교 시간을 입력 받는다.
    * [x] 존재하는 크루의 닉네임이어야 한다.
* [x] 출석 기록을 수정한다.
    * [x] 수정하려는 시간과 동일한 기록이 있다면, 수정할 수 없으며 이미 같은 기록이 존재한다고 안내한다.
* [x] 수정에 성공한 경우, 변경 전과 변경 후의 출석 기록을 출력한다.

```
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

### 크루별 월단위 출석 기록 확인 기능

* [x] 닉네임을 입력 받는다.
* [x] 해당 크루의 해당 월의 1일~전날까지의 출석 기록 통계를 읽어온다
    * 출석 기록 통계
        * [x] 특정 크루의 월 단위 출석 기록
        * [x] 출석 상태별 횟수
        * [x] 제적 위험 등급
* [x] 출석 기록 통계를 출력한다.

```
닉네임을 입력해 주세요.
빙티

이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 10:07 (지각)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:03 (출석)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)
12월 13일 금요일 10:02 (출석)

출석: 3회
지각: 0회
결석: 3회

면담 대상자입니다.
```

### 제적 위험자 목록 조회

* [x] 전날까지의 출석 기록을 바탕으로 제적 위험자 목록을 조회한다
    * [x] 크루 목록을 가져온다
    * [x] 각 크루별 월 단위 출석 기록을 가져온다
    * [x] 각 크루별 지각 횟수, 결석 횟수를 계산한다
    * [x] 각 크루의 제적 위험 등급을 계산한다
* [x] 제적 위험자 목록을 출력한다.
    * 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자를 의미한다.
    * 제적 위험자 출력 순서
        * [x] 제적, 면담, 경고 대상자 순으로 정렬
        * [x] 같은 대상자인 경우, 지각 3회를 결석 1회로 간주하여 내림차순 정렬
        * [x] 결석 횟수도 같은 경우, 닉네임으로 오름차순 정렬

```
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 4회 (면담)
- 이든: 결석 2회, 지각 5회 (면담)
- 빙봉: 결석 1회, 지각 6회 (면담)
- 쿠키: 결석 2회, 지각 3회 (면담)
- 짱수: 결석 0회, 지각 6회 (경고)
```
