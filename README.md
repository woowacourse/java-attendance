# java-attendance

출석 미션 저장소

크루의 출석 기록을 관리하는 시스템을 개발합니다.

## 출석 확인

- [ ] 닉네임을 입력한다.
    -  [ ] 크루 목록에 존재하는 닉네임이어야 한다.
- [ ] 등교 시간을 입력한다.
    - [ ] 24시간 형식이어야 한다.
    - [ ] 캠퍼스 운영 시간 (08:00 ~ 23:00) 내여야 한다.
    - [ ] 교육 시간은 아래와 같다.
        - [ ] 월요일 : 13:00 ~ 18:00
        - [ ] 화요일 ~ 금요일 : 10:00 ~ 18:00
- [ ] 주말 및 공휴일에는 출석을 받지 않는다.
- [ ] 출석 후 출석 기록을 출력한다.
    - [ ] 지각 : 해당 요일의 시작 시각으로부터 5분 초과
    - [ ] 결석 : 해당 요일의 시작 시각으로부터 30분 초과
- [ ] 이미 출석 한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.

## 출석 수정

- [ ] 수정하려는 크루의 닉네임을 입력한다.
- [ ] 수정하려는 날짜를 입력한다.
- [ ] 등교 시간을 입력한다.
- [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 출력한다.

## 크루 별 출석 기록 확인

- [ ] 크루의 닉네임을 입력한다.
- [ ] 전 날까지의 해당 크루 출석 기록을 출력한다.
    - [ ] 출석, 지각, 결석 횟수를 출력한다.
    - [ ] 제적, 면담, 경고 대상자 여부를 출력한다.

## 제적 위험자 확인

- [ ] 확인하고자 하는 크루의 닉네임을 입력한다.
- [ ] 전 날까지의 크루 출석 기록을 바탕으로 제적 위험자 목록을 출력한다.
    - [ ] 지각 3회는 결석 1회로 간주한다.
    - [ ] 경고 대상자 : 결석 2회 이상
    - [ ] 면담 대상자 : 결석 3회 이상
    - [ ] 제적 대상자 : 결석 5회 초과
    - [ ] 제적 대상자, 면담 대상자, 경고 대상자 순으로 출력한다.
    - [ ] 출석 상태가 같을 경우, 닉네임으로 오름차순 정렬해 출력한다.
