# java-attendance

# 출석 미션 저장소

## 요구 사항

### 출석 관리 규칙 및 시스템 설계 정책

- 출석 시스템의 출석 확인은 크루가 캠퍼스에 들어온 후 시스템에 출석 데이터가 저장된 시간을 기준으로 한다.
- 시간은 24시간 형식만 사용한다.
- 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00이다.
    - 5분 초과는 지각으로 간주한다.
    - 30분 초과는 결석으로 간주한다.
    - 출석 기록이 없는 날은 결석으로 간주한다.
- 누적 지각 및 결석 횟수에 따라 경고 또는 면담을 시행한다.
    - 지각 3회는 결석 1회로 간주한다.
    - 경고 대상자: 결석 2회 이상
    - 면담 대상자: 결석 3회 이상
    - 제적 대상자: 결석 5회 초과
- 캠퍼스 운영 시간은 매일 08:00~23:00이다.
- 주말 및 공휴일에는 출석을 받지 않는다.
- 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(attendances.csv)에서 확인할 수 있다.
- 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

## 기능 목록

### 초기화

- [ ] 프로그램 시작 시, attendances.csv 파일을 통해 정보 조회

### 출석 확인

- [x] 등교 시간 입력시 출석 상태 판별
    - [x] 5분 초과는 지각, 30분 초과는 결석
    - [x] 캠퍼스 오픈 시간이 아니면 예외
    - [x] 캠퍼스 오픈일이 아니면 예외 (주말, 크리스마스)
- [x] 닉네임과 등교 시간이 들어오면, 크루의 출석 기록이 추가
    - [x] 등교 시간이 들어오면, 크루의 출석 기록이 추가
    - [x] 닉네임이 들어오면, 크루를 추가
        - [x] 이미 추가된 크루면 예외
    - [x] 닉네임을 통해, 크루를 찾기

### 출석 수정

- [x] 닉네임, 수정하려는 날짜를 입력하여 출석 확인
    - [x] 크루의 닉네임으로 출석 기록 찾기
    - [x] 출석 기록에서 날짜에 맞는 기록 찾기
- [x] 등교 시간을 받아 기록 수정 가능
- [x] 수정 전과 수정 후 Attendance는 달라야 한다(Attendance를 불변 객체로)

### 크루별 출석 기록 확인

- [x] 닉네임을 통해 크루를 가져오고, 전날까지의 출석 기록 가져오기
- [x] 출석 기록이 없을 시, 0시 0분으로 시간 표시
- [x] 캠퍼스 운영 날짜가 아니면 출석 기록을 가져오지 않음
- [x] 출석, 지각, 결석 횟수 출력
- [x] 경고, 면담, 제적 대상자일 경우 출력
    - [x] 지각 3회는 결석 1회로 간주

### 제적 위험자 확인

- [x] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악
- [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력
    - [ ] 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순 정렬
    - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬

### 입출력 요구 사항

- [ ] 오늘 날짜와 기능 선택하도록 출력
- [ ] 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(attendances.csv)에서 확인
