# java-attendance

## 기능 목록

### 0. 프로그램 실행 기능

- [ ] 프로그램을 시작하면 src/main/resources/attendances.csv를 통해 저장된 출석 데이터를 조회한다.
  - [ ] 출석 시스템에 등록된 크루의 출석 기록은 제공된 파일(attendances.csv)에서 확인할 수 있다.

- [ ] 실행 가능한 기능 선택 목록을 출력한다.
```
오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.  
  1. 출석 확인  
  2. 출석 수정  
  3. 크루별 출석 기록 확인  
  4. 제적 위험자 확인   
  Q. 종료
```

- [ ] 사용자로부터 실행할 기능 번호를 입력받는다.
  - [ ] 실행할 수 없는 기능 번호를 받는 경우, 재입력을 요청한다.
- [ ] 입력받은 기능을 수행한 후 초기 화면으로 돌아간다.
- [ ] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, `Q`가 입력되면 종료된다.

### 1. 출석 확인 기능

- [ ] 닉네임을 입력받는다.
  - [ ] 데이터 목록에 닉네임이 존재하지 않는 경우, 예외 메세지를 출력한 후 초기화면으로 돌아간다.
- [ ] 등교 시간을 입력받는다.
  - [ ] HH:mm 형식이 아닐 경우 재입력 받는다.
- [ ] 출석 후 출석 기록을 출력한다.(출석 후 출석 기록을 확인할 수 있다.)
- [X] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.
- [ ] 출석 기준 시간 규칙
  - [ ] 출석 시스템의 출석 확인은 크루가 캠퍼스에 들어온 후 시스템에 출석 데이터가 저장된 시간을 기준으로 한다.
  - [X] 주말 및 공휴일에는 출석을 받지 않는다.
  - [X] 캠퍼스 운영 시간은 매일 08:00~23:00이다.
  - [X] 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00이다.
  - [X] 해당 요일의 시작 시각으로부터 5분 초과는 지각으로 간주한다.
  - [X] 해당 요일의 시작 시각으로부터 30분 초과는 결석으로 간주한다.
- [X] 예외 발생 케이스
  - [X] 등교일이 아닌 날짜에 출석 확인 기능 실행 시 `[ERROR] 12월 14일 토요일은 등교일이 아닙니다.`
  - [X] 캠퍼스 운영 시간이 아닌 경우 출석 확인 기능 실행 시 `[ERROR] 현재 캠퍼스 운영시간이 아닙니다.`

### 2. 출석 수정 기능

- [X] 출석 확인을 수정하려면 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정할 수 있다.
  - [ ] 닉네임을 입력받는다.
    - [ ] 데이터 목록에 닉네임이 존재하지 않는 경우, 예외 메세지를 출력한 후 초기화면으로 돌아간다.
  - [ ] 수정하려는 날짜를 입력받는다.
    - [X] 수정하려는 날짜가 없는 경우, 새로운 출석 기록을 추가한다.
- [ ] 수정하려는 시간을 입력받는다.
- [X] 수정 후에는 변경 전과 변경 후의 출석 기록을 출력한다.

### 3. 크루별 출석 기록 확인

- [X] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인할 수 있다.
  - [ ] 닉네임을 입력받는다.
  - [ ] 전날까지의 출석 기록을 출력한다.
  - [ ] 출석, 지각, 결석 횟수를 출력한다.
  - [ ] 경고, 면담, 제적 대상자일 경우 안내 메시지를 출력한다.
- [X] 등교하지 않아 출석 기록이 없는 날은 결석으로 간주한다.

### 4. 제적 위험자 확인

- [ ] **전날**까지의 크루 출석 기록을 바탕으로 제적 위험자를 출력한다.
  - [ ] 출석 기록은 해당 월의 출석 기록만 이용한다.
- [ ] 출석 기록이 없는 경우, 결석으로 간주한다.
- [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력한다.
  - [ ] 총 결석 횟수에 따라 정렬한다.
- [X] 누적 지각 및 결석 횟수에 따라 경고 또는 면담을 시행한다. 또한 결석 횟수가 5회를 초과할 때 제적을 시행한다.
  - [X] 경고 대상자: 결석 2회 이상
  - [X] 면담 대상자: 결석 3회 이상
  - [X] 제적 대상자: 결석 5회 초과
- [X] 지각 3회는 결석 1회로 간주한다.
