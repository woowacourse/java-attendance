# java-attendance

# 출석 미션 저장소

## 요구 사항
### 출석 관리 규칙 및 시스템 설계 정책
- 출석 시스템의 출석 확인은 크루가 캠퍼스에 들어온 후 시스템에 출석 데이터가 저장된 시간을 기준으로 한다.
- 시간은 24시간 형식만 사용한다.
- 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00이다.
  - 5분 초과는 지각으로 간주한다.
  - 30분 초과는 결석으로 간주한다.
  - 출석 기록이 없는 날은 결석으로 간주한다.
- 누적 지각 및 결석 횟수에 따라 경고 또는 면담을 시행한다.
  - 지각 3회는 결석 1회로 간주한다.
  - 경고 대상자: 결석 2회 이상
  - 면담 대상자: 결석 3회 이상
  - 제적 대상자: 결석 5회 초과
- 캠퍼스 운영 시간은 매일 08:00~23:00이다.
- 주말 및 공휴일에는 출석을 받지 않는다.
- 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(attendances.csv)에서 확인할 수 있다.
- 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

## 기능 목록
### 출석 확인
- [ ] 닉네임과 등교 시간을 입력시 출석
- [ ] 출석 후 출석 기록을 확인 가능
- [ ] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내

### 출석 수정
- [ ] 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 출석 확인 기록 수정 가능
- [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인 가능
- [ ] 수정할 날짜 입력이 출석 기록에 없으면 추가 

### 크루별 출석 기록 확인
- [ ] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인 가능
- [ ] 결석 시 '--:--'로 시간 표시
- [ ] 캠퍼스 운영 날짜가 아니면 출력하지 않음

### 제적 위험자 확인
- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악
- [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력
  - [ ] 대상 항목별 정렬 순서는 지각을 결석으로 간주(지각 3회 = 결석 1회)하여 내림차순 정렬 
  - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬

### 입출력 요구 사항
- [ ] 오늘 날짜와 기능 선택하도록 출력
- [ ] 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(attendances.csv)에서 확인

### 검증 목록
- [ ] 캠퍼스 운영 시간 확인
- [ ] 닉네임 확인
- [ ] 등교 시간 입력 포맷 확인
- [ ] 날짜 정수로 입력했는지
- [ ] 1, 2, 3, 4, Q 이외의 기능 선택시
