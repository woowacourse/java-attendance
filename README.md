## java-attendance

### 문제 상황

지금까지 출석부를 수동으로 관리하다 보니 많은 크루의 출석 현황을 효율적으로 관리하기 어려웠습니다.
제때 누적 지각 크루를 파악하지 못해 면담이 지연되거나, 결석 일수를 계산하는 과정에서 실수가 발생한 경우가 있었습니다.

### 목표

`2024년 12월` 한 달 동안 시범적으로 최소한의 기능을 갖춘 `출석 시스템`을 개발하여 코치가 출석을 체계적으로 관리할 수 있도록 합니다.

### 구현할 기능 목록

- [ ] 홈 화면
    - [ ] `오늘은 MM월 dd일 E요일입니다. 기능을 선택해 주세요.` 문구를 출력한다.
        - [ ] 기능 선택
            - [ ] 선택 가능한 기능 목록을 출력한다.
- [ ] 출석 확인 기능
    - [ ] 출석할 크루의 닉네임 입력
        - [ ] `닉네임을 입력해 주세요.` 문구를 출력한다.
    - [ ] 등교 시간 입력
        - [ ] `등교 시간을 입력해 주세요.` 문구를 출력한다.
    - [ ] 출석 기록 출력
        - [ ] `MM월 dd일 E요일 HH:mm ({출석 유형})` 형태로 출력한다.
- [ ] 출석 수정 기능
    - [ ] 수정할 크루의 닉네임 입력
        - [ ] `출석을 수정하려는 크루의 닉네임을 입력해 주세요.` 문구를 출력한다.
    - [ ] 수정할 날짜 입력
        - [ ] `수정하려는 날짜(일)를 입력해 주세요.` 문구를 출력한다.
    - [ ] 수정할 시간 입력
        - [ ] `언제로 변경하겠습니까?` 문구를 출력한다.
    - [ ] 변경 전과 변경 후의 출석 기록 출력
        - [ ] `MM월 DD일 E요일 HH:mm ({출석 유형}) -> HH:mm ({출석 유형}) 수정 완료!` 형태로 출력한다.
- [ ] 크루별 출석 기록 확인 기능
    - [ ] 확인할 크루의 닉네임 입력
        - [ ] `닉네임을 입력해 주세요.` 문구를 출력한다.
    - [ ] 크루의 출석 기록 출력
        - [ ] `이번 달 빙티의 출석 기록입니다.` 문구를 출력한다.
        - [ ] 전날까지의 크루 출석 기록
            - [ ] `MM월 dd일 E요일 HH:mm ({출석 유형})` 형태로 출력한다.
        - [ ] 출석, 지각, 결석 횟수 출력
            - [ ] `{출석 유형}: n회` 형태로 출력한다.
        - [ ] 누적 지각 및 결석 횟수에 따른 경고 유형 출력
            - [ ] `{경고 유형} 대상자입니다.` 형태로 출력한다.
- [ ] 제적 위험자 확인 기능
    - [ ] `제적 위험자 조회 결과` 문구를 출력한다.
    - [ ] 제적 위험자 명단 출력
        - [ ] `- {닉네임}: 결석 n회, 지각 m회 ({경고 유형})` 형태로 출력한다.
            - 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 정렬하며,   
              대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.  
              출석 상태가 같으면 닉네임으로 오름차순 정렬한다.
- [ ] 프로그램 종료 기능
    - 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

## 출석 로그

- [x] 닉네임과 등교 시간을 가진다.
    - 닉네임
        - [x] 2자 이상 4자 이하여야 한다.
        - [x] 한글만 가능하다.
        - [x] 공백으로만 구성될 수 없다.
    - 등교 시간
        - [x] 날짜와 시간을 가진다.
        - [x] 시간은 24시간 형식이다.
        - [x] 시간 기록이 없는 경우 결석으로 간주한다.

### 필요한 데이터

프로그램을 시작하면 `src/main/resources/attendances.csv` 파일을 활용하여 구현한다.
파일에는 구현에 필요한 닉네임과 출석 일시가 기록되어 있다.

```csv
nickname,datetime
쿠키,2024-12-13 10:08
빙봉,2024-12-13 10:07
빙티,2024-12-13 10:07
이든,2024-12-13 10:07
```
