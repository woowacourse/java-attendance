# java-attendance

---

### 출석 시간 (CampusTime)
- [x] 문자열 HH:MM 형식 (ex:"10:30")을 입력받아 객체를 생성한다.
  - [x] 지정된 형식 HH:MM  이 아닌 문자열 입력시, 예외를 발생시킨다. 
  - [x] 시가 0~24, 분이 0~60 범위를 초과할 경우, 예외를 발생시킨다. 
- [x] isAfter(), isBefore() 등 시간간의 비교를 구현한다.
- [x] 캠퍼스 운영 시간은 매일 08:00 ~ 23:00 이다. 
  - [x] 운영 시간 외의 시간을 입력받을 시, 예외를 발생시킨다.

### 출석 날짜 (CampusDate)
- [x] 현재 날짜를 입력받아, 객체로 생성한다. 
- [x] 일(day)을 입력받아, 객체로 생성한다.
  - [x] 해당 월의 범위를 초과한 일을 입력받은 경우 (ex 2월 31일) 예외를 발생시킨다. 
- [x] 해당 일이 어떤 요일인지 반환한다. 
- [x] 주말 및 공휴일에는 출석을 받지 않는다.
  - [x] 만약 주말의 데이터가 들어왔을 경우, 예외를 발생시킨다.

### 출석 정보 (AttendanceInfo)
- [x] 날짜와 시간을 입력받아, 객체를 생성한다.
- [x] 시간을 입력받아 해당 정보로 수정한다.
- [x] 해당 결과의 출석 상태를 계산한다.

### 출석 상태 (AttendanceStatus)
- [x] 출석, 지각, 결석 세 가지 상태로 존재한다.
- [x] 출석 날짜와 출석 시간을 토대로 출석 상태를 계산한다.
  - [x] 5분 초과시 지각, 30분 초과 시 결석으로 계산한다.
  - [x] 화 ~ 금 은 10:00 ~ 18:00 기준으로 계산한다.
  - [x] 월요일은 13:00 ~ 18:00 기준으로 계산한다.
  
### 출석 정보들 (AttendanceInfos)
- [x] 아무것도 없는 기본 정보들을 생성하거나, 출석 정보 리스트를 입력받아 객체를 생성한다. 
- [x] 생성된 출석 정보를 추가한다.
- [x] 출석 날짜, 시간(CampusDate, CampusTime)을 입력받아, 생성된 정보를 추가한다.
- [x] 출석 날짜(CampusDate)를 입력받아, 해당 값이 존재하는지 확인한다.
- [x] 출석 날짜(CampusDate)를 입력받아, 해당하는 출석 정보를 찾는다.
  - [x] 찾지 못한다면, 예외를 발생시킨다.
- [x] 출석 날짜(CampusDate)를 입력받아, 해당 날짜의 정보를 수정한다.
- [x] 기준 날짜 전날까지의 출석 정보와, 출석 상태 횟수, 출결 상태를 반환한다.
  - [x] 결석 2회 이상부터 경고, 3회 이상부터 면담, 5회 초과시 제적 대상자로 구분한다.

### 출석부 (AttendanceBook)
- [x] 초기 빈 값의 출석부를 생성한다.
- [x] 크루와 출석 정보들을 연결시킨다.
- [x] 출석부에 크루를 등록한다.
- [x] 출석부에 출석정보를 등록한다.
- [x] 시간과 날짜 정보를 입력하여 크루에 출석정보를 추가한다.
- [x] 시간과 날짜 정보를 입력하여 크루의 기존 날짜정보를 수정한다.
- [x] 크루의 정보를 입력하여 출석 기록들을 반환한다.
- [x] 제적 위험자를 조회한다.

### 크루 상태 (AttendanceRiskLevel)
- [x] 정상, 경고, 면담, 제적 대상자로 구분한다.

### 출석 횟수 정보 (AttendanceCounts)
- [x] 출석, 지각, 결석 횟수를 인자로 받는다. 
- [x] 출석 정보를 전달받아, 출결 상태를 반환한다.
  - [x] 결석 2회 이상부터 경고, 3회 이상부터 면담, 5회 초과시 제적 대상자로 구분한다.

### 출석 기능 (AttendanceOperation)
- [x] 1,2,3,4,Q의 각 기능들을 입력받아 변환한다.
  
### 크루 (Crew) 
- [x] 크루 이름을 입력받아, 객체를 생성한다.
  - [x] 크루 이름에 가-힣 이외의 문자가 들어올 경우, 예외를 발생시킨다.
- [x] 동일한 이름을 가진 크루객체들이 동일하도록, equals() 및 hashCode()를 구현한다. 

### 파일 리더기 
- [x] "쿠키,2025-02-14 10:08" 의 형식을 입력받는다.
- [x] 파일이 없는 경우, 예외를 발생한다.
