# java-attendance

출석 미션 저장소

### 출석 확인

- [x] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
- [x] 출석 후 출석 기록을 확인할 수 있다.
- [x] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.
- [x] 기준 시간에서 5분 초과시 지각, 30분 초과시 결석으로 처리한다.
- [x] 주말 및 공휴일에는 출석할 수 없다.
- [x] 요일에 따라 다른 출석 시간을 적용한다.
- [x] 운영 시간을 벗어난 출석은 예외처리한다. (캠퍼스 운영 시간은 매일 08:00~23:00이다.)

### 출석 수정

- [x] 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정할 수 있다
- [x] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인할 수 있다.

### 출석 기록 확인

- [] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인할 수 있다.
- [x] 출석 기록 확인시 출석, 지각, 결석의 각 횟수를 확인할 수 있다.
- [x] 출석 기록 확인시 어떤 제제의 대상자인지 확인할 수 있다.
- [x] 등교하지 않아 출석 기록이 없는 날은 결석으로 간주한다.
- [x] 누적 지각 및 결석 횟수에 따라 경고 또는 면담, 제적을 시행한다.
  ```
  지각 3회는 결석 1회로 간주한다.
  
  경고 대상자: 결석 2회 이상
  면담 대상자: 결석 3회 이상
  제적 대상자: 결석 5회 초과
  ```

### 제적 위험자 확인

- [x] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [x] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력한다
    - [x] 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.
    - [x] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.
