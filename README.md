# java-attendance

출석 미션 저장소

### 출석확인

- [x] 요일에 따라 출석 상태를 판단한다.
- [x] 출석 시간을 입력 받아 출석 체크한다.
- [ ] 출석 기록이 없는 날은 결석으로 간주되는지 확인한다.

### 출석 수정

- [ ] 수정일자에 따라 출석을 수정한다.

### 크루별 출석 확인

- [ ] 해당 크루의 모든 출석 기록을 확인한다.
    - [ ] 오늘 날짜를 기준으로 전날까지의 출석 기록을 모두 확인한다.
- [ ] 크루의 출석 상태별 횟수를 확인한다.

### 제적 위험자 확인

- [ ] 해당 크루가 제적 위험자인지 확인한다.

### 예외

- [x] 주말에 출석을 시도하면 예외를 발생시킨다.
- [ ] 공휴일에 출석을 시도하면 예외를 발생시킨다.
- [ ] 주말 일자로 출석 상태를 확인하면 예외를 발생시킨다.
- [ ] 등록되지 않은 닉네임을 입력하면 예외를 발생시킨다.
- [ ] 수정일자를 주말로 설정하면 예외를 발생시킨다.
- [ ] 수정일자를 공휴일로 설정하면 예외를 발생시킨다.
