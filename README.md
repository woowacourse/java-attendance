## 🏗️ 설계

### 도메인 클래스 (Domain)

| 클래스명 | 역할 | 속성 | 행위 |
|---------|------|------|------|
| **Attendance** | 하루의 출석 기록 | 날짜, 시간 | 저장, 수정, 조회 |
| **CrewName** | 크루 이름 저장 | 이름 | 저장, 조회 |
| **AttendanceRecord** | 여러 날의 출석 기록 | 복수의 Attendance | 저장, 수정, 조회 |
| **AttendanceBook** | 크루별 출석 기록을 전부 저장 | Crew와 AttendanceRecord를 매핑 | 저장, 수정, 조회 |
| **AttendanceStatus** | 출석 상태 지정 | [출석, 지각, 결석] | - |
| **Penalty** | 위험 상태 지정 | [제적, 면담, 경고, NONE] | - |

### 뷰 클래스 (View)

| 클래스명 | 역할 |
|---------|------|
| **InputView** | 입력 값 처리, 검증 |
| **OutputView** | 출력 값 처리 |

### 컨트롤러 클래스 (Controller)

| 클래스명 | 역할 |
|---------|------|
| **AttendanceController** | 어플리케이션 실행 흐름 관리 |

## 📱 기능 요구사항

### 1. 출석 기능

- [X] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
    - [X] 존재하지 않는 닉네임일 경우 예외가 발생한다.
    - [ ] 시간 형식(HH:mm)이 올바르지 않을 경우 예외가 발생한다.
- [X] 출석 후 출석 기록을 확인할 수 있다.
    - [X] [월, 일, 요일, 시간, 출석 상태]를 확인할 수 있다.
- [ ] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.
  - [X] 이미 출석한 경우, 예외가 발생한다.

#### 실행 예시
```
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 13일 금요일 09:59 (출석)
```

### 2. 출석 수정 기능

- [X] 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 출석 기록을 수정할 수 있다.
    - [X] 존재하지 않는 닉네임일 경우 예외가 발생한다.
    - [ ] 날짜 형식이 올바르지 않을 경우 예외가 발생한다.
    - [ ] 시간 형식(HH:mm)이 올바르지 않을 경우 예외가 발생한다.
- [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인할 수 있다.
    - [ ] 변경 전 [월, 일, 요일, 시간, 출석 상태]를 확인할 수 있다.
    - [ ] 변경 후 [시간, 출석 상태]를 확인할 수 있다.

#### 실행 예시
```
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

### 3. 크루별 출석 기록 확인 기능

- [ ] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인할 수 있다.
    - [ ] 존재하지 않는 닉네임일 경우 예외가 발생한다.
    - [ ] [월, 일, 요일, 시간, 출석 상태]의 기록들과 [출석 상태별 횟수], [페널티 여부]를 확인할 수 있다.

#### 실행 예시
```
닉네임을 입력해 주세요.
빙티

이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 10:07 (지각)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:03 (출석)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)
12월 13일 금요일 10:02 (출석)

출석: 5회
지각: 2회
결석: 3회

면담 대상자입니다.
```

### 4. 제적 위험자 확인 기능

- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [ ] [이름], [출석 상태별 횟수], [페널티 여부]를 확인할 수 있다.
- [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력한다.
- [ ] 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.
- [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

#### 실행 예시
```
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 4회 (면담)
- 이든: 결석 2회, 지각 5회 (면담)
- 빙봉: 결석 1회, 지각 6회 (면담)
- 쿠키: 결석 2회, 지각 3회 (면담)
- 짱수: 결석 0회, 지각 6회 (경고)
```

### 5. 프로그램 실행 및 종료 기능

- [ ] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

#### 실행 예시
```
오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
Q
```

### 6. 파일 조회 기능

- [ ] 프로그램을 시작하면 `src/main/resources/attendances.csv`를 통해 구현에 필요한 정보를 조회한다.
- [ ] `attendances.csv`에는 닉네임과 출석 일시가 기록되어 있다.

#### 파일 예시
```
nickname,datetime
쿠키,2024-12-13 10:08
빙봉,2024-12-13 10:07
빙티,2024-12-13 10:07
이든,2024-12-13 10:07
```

## 📜 시스템 규칙

### 출석 기록 규칙

- [ ] 캠퍼스 운영(08:00~23:00) 외 시간에는 출석을 받지 않는다.
- [ ] 주말 및 공휴일에는 출석을 받지 않는다.

### 출석 상태 규칙

- [ ] 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00이다.
- [ ] 해당 요일의 시작 시각으로부터 5분 초과는 지각으로 간주한다.
- [ ] 해당 요일의 시작 시각으로부터 30분 초과는 결석으로 간주한다.
- [ ] 등교하지 않아 출석 기록이 없는 날은 결석으로 간주한다.

### 페널티 규칙

- [ ] 지각 3회는 결석 1회로 간주한다.
- [ ] 경고 대상자: 결석 2회 이상
- [ ] 면담 대상자: 결석 3회 이상
- [ ] 제적 대상자: 결석 5회 초과

### 예외 규칙

- [ ] 입력 값이 잘못된 경우 [ERROR]로 시작하는 예외 메시지를 출력하고, 해당 부분부터 다시 입력을 받는다.
