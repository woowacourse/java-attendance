# java-attendance

## 기능 목록

### 입력
- [ ] 기능 명령어
- [x] 닉네임
- [x] LocalTime
- [ ] DayOfMonth

### 출력
- [ ] 기능 1: 출석 확인
- [ ] 기능 2: 출석 수정
- [ ] 기능 3: 크루별 출석 기록 확인
- [ ] 기능 4: 종료

### 상세 정보
#### 기능 명령어
- [ ] type: 1, 2, 3, 4, Q
- [ ] 명령어 입력 시 각 기능 실행

#### 닉네임
- [x] format: 한글만 가능
- [x] length: 2 -  4
- [ ] exception
  - [ ] 등록되지 않은 닉네임의 입력

#### LocalDate
- [x] format: HH:mm
- [x] 시간은 24시간 형식

#### DayOfMonth
- [ ] format: Integer
- [ ] range: 1 - 31


#### 기능1. 출석 확인
- [ ] 입력 : 닉네임 / LocalTime(등교 시간)
- [ ] 출력: 출석 후 출석 기록
- [ ] 예외
  - [ ] 이미 같은 yyyy-MM  형식의 출석이 존재할 경우
    - [ ] -> 수정 기능을 이용하도록 안내
  - [ ] 등교일이 아닌 경우 (닉네임을 받기 전)

#### 기능2. 출석 수정
- [ ] 입력: 닉네임 / DayOfMonth / LocalTime(수정 시간)
- [ ] 출력: 수정 후 변경 전, 변경 후의 출석 기록
- [ ] 예외 : 변경 전 LocalTime와 같은 LocalTIme의 입력일 경우

#### 기능3. 크루별 출석 기록 확인
- [ ] 입력: 닉네임
- [ ] 출력: 전날까지의 크루 출석 기록 / 출석type count list / 제적 위험자 판별 결과

#### 기능4. 제적 위험자 확인
- [ ] 입력: none
- [ ] 출력: 전날까지의 크루 출석 기록을 바탕으로 제적 위험자 list
  - [ ] (sort 결석 DESC, 닉네임 ASC)

#### 디테일
##### 출석 기록의 형식
- [ ] 결석이 아닐 경우 (출석, 지각)
  - [ ] `12월 02일 월요일 13:00 (출석)`
  - [ ] `12월 03일 화요일 10:07 (지각)`
- [ ] 결석일 경우
  - [ ] `12월 09일 월요일 --:-- (결석)`
##### 캠퍼스 운영 & 교육 시간
* 캠퍼스 운영 시간
  - [x] 매일: 8:00 - 23:00
- 교육 시간
  - [x] 월요일: 13:00 - 18:00
  - [x] 화-금요일: 10:00 - 18:00
* 주말 및 공휴일은 출석을 받지 않음

##### 출석 type 판별
- [x] 지각: 시작 시간으로부터 5분 초과
- [x] 결석
  - [x] 시작 시간으로부터 30분 초과
  - [ ] 등교하지 않아 출석 기록이 없는 날

##### 제적 대상자 type 판별
- [ ] 지각 3회 == 결석 1회
- [ ] 제적 대상자: 결석 5회 초과
- [ ] 면담 대상자: 결석 4회 초과
- [ ] 경고 대상자: 결석 3회 초과
