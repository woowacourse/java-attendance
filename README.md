# java-attendance

## 기능 목록

출석 미션 저장소

- [x] 시간은 24시간 형식
- 교육시간
    - [x] 월요일 13:00 ~ 18:00
    - [x] 화요일 ~ 금요일 10:00 ~ 18:00
- 출결
    - [x] 지각 : 5분초과
    - 결석
        - 30분초과 or 출석기록 없을 때
            - 지각 3회는 결석 1회로 간주
    - [x] 경고 대상자 : 결석 1회 초과
    - [x] 면담 대상자 : 결석 2회 초과
    - [x] 제적 대상자 : 결석 5회 초과
- [x] 운영 시간
    - 08:00 ~ 23:00
- [x] 주말 및 공휴일에는 출석을 받지 않음
- csv파일에서 확인할 수 있다.
- 사용자가 종료할 때까지 종료되지 않음
- 해당 기능을 수행한 후 초기 화면으로 돌아감

### 출석 확인

[x] 입력 : 닉네임, 등교 시간
[x] 유효성 검증
[x] 닉네임

- 한글만 가능
- 2~4글자만 가능
- 존재 하지 않으면 예외 -> input에서 존재하지 않는값 잡아내기
  [x] 등교 시간
- LocalDateTimeFormat 사용

- 출력 : 출석 기록
- 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내
    - 오늘자로 출석이 돼있다면 예외처리 (수정기능 이용하도록 안내)

### 출석 수정

- [x] 입력 : 닉네임, 수정하려는 날짜, 등교 시간
    - [x] 유효성 검증
        - 닉네임(공통)
        - 수정하려는 날짜
        - 등교 시간(공통)
- 출력 : 변경 전과 변경 후의 출석 기록

### 크루별 출석 기록 확인

- 입력 : 닉네임
- 출력
    - 크루 출석 안내 문구
    - 전날까지의 크루 출석 기록 리스트
        - 출석기록이 없다면 자동으로 결석처리
    - 출석/지각/결석 (결석 간주 x)
    - 경고/면담/제적 (결석 간주 O)

### 제적 위험자 확인

- 입력 : 없음
- 출력 : 제적 위험자 조회 결과
    - 제적 위험자 조회 안내 문구
    - 크루별 결석/지각 횟수 및 대상자 분류 리스트
