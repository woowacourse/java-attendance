# java-attendance

출석 미션 저장소

### 출석 확인

- [x] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
- [x] 출석 후 출석 기록을 확인할 수 있다.
- [x] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.
- [x] 기준 시간에서 5분 초과시 지각, 30분 초과시 결석으로 처리한다.
- [x] 주말 및 공휴일에는 출석할 수 없다.
- [x] 요일에 따라 다른 출석 시간을 적용한다.
- [x] 운영 시간을 벗어난 출석은 예외처리한다. (캠퍼스 운영 시간은 매일 08:00~23:00이다.)

### 출석 수정

- [] 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정할 수 있다
- [] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인할 수 있다.
