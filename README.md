# 출석 📆

## 기능 구현 목록 ⚙️

### ✅ 출석 시스템 초기 설정 기능

- [ ] `attendances.csv` 파일로 초기 출석을 등록한다
- [ ] 휴일 목록에 12월 및 2월 공휴일을 추가한다

### ✅ 메뉴 선택 기능

- [ ] 메뉴의 목록을 출력한다
- [ ] 메뉴의 목록 중 선택한다
- [x] 입력과 일치한 메뉴를 반환한다
- [ ] `Q` 입력인 경우 종료한다
- [x] `예외처리` 잘못된 메뉴 선택의 입력인 경우 예외가 발생한다 `[ERROR] 잘못된 메뉴 선택의 입력입니다.`

```
오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
Q
```

### ✅ 출결 상태 검사 기능

- [ ] 캠퍼스 운영 시간은 08:00 ~ 23:00이다
- [ ] 월요일 등교 시간은 13:00 ~ 18:00이다
- [ ] 화요일~금요일 등교 시간은 10:00 ~ 18:00이다
- [ ] 시작 시간으로부터 5분 초과는 지각이다
- [ ] 시작 시간으로부터 30분 초과는 결석이다
- [ ] 등교하지 않은 날은 결석이다
- [ ] 주말 및 공휴일에는 출석할 수 없다
- [ ] `예외처리` 등교 일자가 아닌 경우 예외가 발생한다 `[ERROR] 12월 14일 토요일은 등교일이 아닙니다.`
- [ ] `예외처리` 등교 시간이 아닌 경우 예외가 발생한다 `[ERROR] 월요일 등교 시간은 13:00 ~ 18:00 입니다.`

### ✅ 출결 위험도 검사 기능

- [ ] 출결 위험도 검사
    - [ ] 결석 2회 이상은 경고 대상자이다
    - [ ] 결석 3회 이상은 면담 대상자이다
    - [ ] 결석 5회 초과는 제적 대상자이다
    - 지각 3회는 결석 1회다

### ✅ 출석 확인 기능

- [ ] 출석할 닉네임을 입력한다
- [ ] 출석할 등교 시간을 입력한다
- [ ] 닉네임과 입력 시간으로 크루의 출석을 등록한다
- [ ] 출석 날짜, 시간과 출결 상황을 출력한다
- [ ] `예외처리` 등록된 닉네임이 아닌 경우 예외가 발생한다 `[ERROR] 등록되지 않은 닉네임입니다.`
- [ ] `예외처리` 잘못된 형식의 시간 입력인 경우 예외가 발생한다 `[ERROR] 잘못된 형식의 시간 입력입니다.`
- [ ] `예외처리` 이미 출석한 경우, 다시 출석할 수 없다. `[ERROR] 이미 출석이 등록되었습니다. 수정 기능을 이용 해주세요.`

```
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 13일 금요일 09:59 (출석)
```

### ✅ 출석 수정 기능

- [ ] 수정할 닉네임을 입력한다
- [ ] 수정할 일자를 입력한다
- [ ] 수정할 시간을 입력한다
- [ ] 닉네임과 입력 일자와 시간으로 크루의 출석을 수정한다
- [ ] 수정 전과 후의 출석 날짜, 시간과 출결 상황을 출력한다
- [ ] `예외처리` 등록된 닉네임이 아닌 경우 예외가 발생한다 `[ERROR] 등록되지 않은 닉네임입니다.`
- [ ] `예외처리` 잘못된 형식의 일자 입력인 경우 예외가 발생한다 `[ERROR] 잘못된 형식의 날짜(일) 입력입니다.`
- [ ] `예외처리` 입력된 일자에 출석 기록이 없을 경우 예외가 발생한다 `[ERROR] 입력된 날짜(일)에는 출석 기록이 존재하지 않습니다.`
- [ ] `예외처리` 잘못된 형식의 시간 입력인 경우 예외가 발생한다 `[ERROR] 잘못된 형식의 시간 입력입니다.`

```
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

### ✅ 출석 기록 확인 기능

- [ ] 기록 확인할 닉네임을 입력한다
- [ ] 크루의 전날 출석 날짜, 시간과 출결 상황 기록을 출력한다
- [ ] `예외처리` 등록된 닉네임이 아닌 경우 예외가 발생한다

```
이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 09:58 (출석)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:08 (지각)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)

출석: 4회
지각: 2회
결석: 3회
```

### ✅ 제적 위험자 확인 기능

- [ ] 전날 출석 상황을 바탕으로 위험도를 판단한다
- [ ] 위험자의 순서를 정렬한다
    1. 제적 -> 면담 -> 경고 정렬
    2. (1. 동일시) 결석을 기준으로 내림차순 정렬 (지각 3회 == 결석 1회)
    3. (2. 동일시) 이름 오름차순 정렬
- [ ] 위험자의 출결 상황을 출력한다

```
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 2회 (면담)
- 이든: 결석 2회, 지각 4회 (면담)
- 쿠키: 결석 2회, 지각 2회 (경고)
- 빙봉: 결석 1회, 지각 5회 (경고)
```
