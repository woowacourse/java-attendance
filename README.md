# java-attendance

---

## 프로그래밍 요구 사항

- TDD로 구현한다.
- 인덴트 1, 메서드는 10라인까지 허용한다.
- Collection 및 Enum을 사용한다.
- 원시값을 사용하지 않도록 포장한다.
- 일급 컬렉션을 사용한다.

---

## 기능 요구 사항

- 2025년 2월 한달 기준의 출석 프로그램을 작성한다.

### 추가 사항

- 잘못된 메뉴 옵션을 입력한 경우에 한해, 다시 입력 받도록 한다.
- 잘못된 입력 값에 대해, `1llegalArgumentException`을 발생시킨다.
    - `[ERROR]`로 시작하는 예외 메시지를 출력한다.

### 기본 사항

- 출석 시간:
    - 시스템에 출석이 체크된 시점을 기준으로 한다.
    - 시간은 24시간 형식을 사용한다.
    - 월요일은 13:00 ~ 18:00, 화요일부터 금요일은 10:00 ~ 18:00이다.
    - 운영 시간은 08:00 ~ 23:00이다.
    - 주말 및 공휴일은 출석을 받지 않는다.

- 출결 처리:
    - 해당 요일의 시작 시간을 기준으로 출석, 지각, 결석을 판단한다.
    - 출석 기준 시간에서 5분 초과는 지각이다.
    - 출석 기준 시간에서 30분 초과는 결석이다.
    - 출석 데이터 혹은 출석 체크 기록이 없는 날은 결석으로 처리한다.

- 제적 위험 대상:
    - 결석 2회 이상은 경고 대상이다.
    - 결석 3회 이상은 면담 대상이다.
    - 결석 5회 초과는 제적 대상이다.
    - 지각 3회는 결석 1회로 간주한다.

## 기능 목록

- [ ] 파일 입력:
    - 출석 데이터는 CSV 파일을 읽어온다.
    - [예외] 파일이 존재하지 않거나 내용이 없는 경우, `IllegalStateException` 예외를 발생시킨다.
    - 출석 데이터(닉네임, 출석 날짜 및 출석 시간)

- [ ] 메뉴 옵션:
    - 프로그램은 사용자가 메뉴 옵션 중 종료(Q)을 누르지 않으면 종료되지 않는다.
    - [예외] 메뉴 옵션이 1, 2, 3, 4, Q가 아닌 경우, 다시 입력 받는다.
    - 사용자가 선택한 옵션을 수행하고 난 후에는 다시 메뉴 옵션 안내 문구를 출력한다.
    - 안내 문구(월, 일, 요일)

- [ ] 크루 출석 확인:
    - 닉네임, 출석 시간 입력을 받아 출석을 처리한다.
    - [예외] 크루 명단에 등록되지 않은 닉네임 입력 시, 예외를 발생시킨다.
    - [예외] 올바르지 않은 형식의 출석 시간 입력 시, 예외를 발생시킨다.
    - [예외] 주말 및 공휴일에 출석 체크 시도 시, 예외를 발생시킨다.
    - [예외] 운영 시간이 아닌 출석 시간 입력 시, 예외를 발생시킨다.
    - [예외] 이미 출석한 경우, 수정 기능을 이용하라는 안내 문구를 출력한다.
    - 출석 내역(월, 일, 요일, 출석 시간, 출결 상태)

- [ ] 크루 출석 수정:
    - 닉네임, 출석 수정 날짜, 출석 수정 시간을 입력 받아 출석을 수정한다.
    - [예외] 크루 명단에 등록되지 않은 닉네임 입력 시, 예외를 발생시킨다.
    - [예외] 올바르지 않은 형식의 출석 날짜 혹은 출석 수정 시간 입력 시, 예외를 발생시킨다.
    - [예외] 주말 및 공휴일인 출석 수정 날짜 입력 시, 예외를 발생시킨다.
    - [예외] 운영 시간이 아닌 출석 수정 시간 입력 시, 예외를 발생시킨다.
    - [예외] 현재 시점보다 미래의 출석 수정 날짜 입력 시, 예외를 발생시킨다.
    - [예외] 기존 출석과 동일한 출석 수정 시간 입력 시, 예외를 발생시킨다.
    - 이전 출석 내역(월, 일, 요일, 출석 시간, 출결 상태)
    - 출석 수정 내역(새 출석 시간, 새 출결 상태, 안내 문구)

- [ ] 크루별 출석 기록 조회:
    - 닉네임을 입력하면, 전날까지의 크루의 출석 기록을 확인할 수 있다.
    - [예외] 크루 명단에 등록되지 않은 닉네임 입력 시, 예외를 발생시킨다.
    - 크루 출석 기록(월, 일, 요일, 출석 시간, 출결 상태)
    - 크루 출석 통계(출석 횟수, 지각 횟수, 결석 횟수)
    - 제적 위험 유형(해당 시, 경고, 면담, 제적)

- [ ] 크루들 제적 위험 대상 조회:
    - 제적, 면담, 경고 대상자 순으로 정렬한다.
        - 지각을 결석으로 간주해 내림차순 정렬한다.
        - 출결 횟수가 같으면 닉네임으로 오름차순 정렬한다.
    - 제적 위험 대상 목록(닉네임, 결석 횟수, 지각 횟수, 제적 위험 유형)
