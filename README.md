# 목적

추후에 사용할 가능성이 있는 출석 프로그램 12월 버전 시범 개발하기

# 기능 요구사항

- [ ]  출석 확인
- [ ]  출석 수정
- [ ]  크루별 출석 기록 확인
- [ ]  제적 위험자 확인

## 출석 확인

### 출석 확인 Flow

1. 닉네임을 입력받는다.
2. 등교 시간을 입력받는다.
3. 출석을 기록한다.

### 필요한 기능

- [ ]  크루 목록에서 입력된 크루 이름을 검색한다.
- [ ]  오늘 날짜와 등교 시간을 합쳐서 크루의 출석부에 기록한다.

## 출석 수정

### 출석 수정 Flow

1. 닉네임을 입력받는다.
2. 수정하려는 날짜를 숫자로 입력한다.
3. 등교 시간을 입력받는다.
4. 출석을 수정한다.

### 필요한 기능

- [ ]  크루 목록에서 입력된 크루 이름을 검색한다.
- [ ]  수정 날짜를 정수형으로 입력받는다.
- [ ]  입력받은 날짜의 출석 기록을 불러온다.
- [ ]  해당 출석 기록을 변경한다.

## 출석 기록 확인

### 출석 기록 확인 Flow

1. 닉네임을 입력받는다.
2. 크루의 출석 기록을 출력한다.
3. 출석 통계(출석, 지각, 결석, 제적대상자 여부)를 출력한다.

### 필요한 기능

- [ ]  크루 목록에서 입력된 크루 이름을 검색한다.
- [ ]  크루의 출석 기록을 불러온다.
- [ ]  출석 기록에서 출석 통계를 불러온다.

## 제적 위험자 확인

### 제적 위험자 확인 Flow

1. 크루 리스트에서 제적 위험자를 불러온다.

### 필요한 기능

- [ ]  크루 목록을 순회하면서 해당 크루가 면담,경고,제적 상태인지 알아낸다.
- [ ]  크루가 가진 출석부가 면담,경고,제적 상태인지 알아낸다.
- [ ]  해당 목록을 정렬한다. (결석*3 + 지각 1순위, 닉네임 오름차순 2순위)

## 그 외 필요한 기능

- [ ] 날짜를 입력받았을때, 한글 요일 String으로 변환하는 기능

# 예외사항

- [ ]  닉네임이 없는 크루면 예외가 발생한다.
  **`[ERROR] 등록되지 않은 닉네임입니다.`**
- [ ]  등교 시간 포맷이 잘못되면 예외가 발생한다 (HH:mm)
- [ ]  00:00 ~ 23:59 이외의 시간을 입력하면 예외가 발생한다.
- [ ]  공휴일(토, 일, 그 외 쉬는날)에 출석하려고 시도하면 예외가 발생한다.
  **`[ERROR] 12월 14일 토요일은 등교일이 아닙니다.`**
- [ ]  수정하려는 날짜가 없으면 예외가 발생한다.
- [ ]  수정하려는 날짜가 정수가 아니면 예외가 발생한다.
- [ ]  수정하려는 날짜가 0 미만 31 초과면 예외가 발생한다.
