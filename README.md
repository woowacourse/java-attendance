# java-attendance

코치가 사용할 크루의 출석 관리 프로그램을 구현합니다.

## 구현할 기능 목록

- [X] 사용할 기능을 입력 받는다.
    - [X] `오늘은 mm월 dd일 x요일입니다. 기능을 선택해 주세요.` 문구를 출력한다.

### 출석 확인

- [x] 금일 출석이 불가능한 날짜인 경우 예외가 발생한다.
- [x] 닉네임을 입력 받는다.
    - [X] `닉네임을 입력해 주세요.` 문구를 출력한다.
    - [x] 등록되지 않은 크루인 경우 예외가 발생한다.
- [x] 등교 시간을 입력 받는다.
    - [x] `등교 시간을 입력해 주세요.` 문구를 출력한다.
    - [x] `hh:MM` 단위가 아닌 경우 예외가 발생한다. (24시 단위)
    - [x] 이미 출석한 경우 예외가 발생한다.
- [x] 출석 확인 메시지를 출력한다.
    - [x] `mm월 dd일 금요일 hh:MM (출석)` 문구를 출력한다.

### 출석 수정

- [x] 닉네임을 입력 받는다.
    - [x] `출석을 수정하려는 크루의 닉네임을 입력해 주세요.` 문구를 출력한다.
    - [x] 등록되지 않은 크루인 경우 예외가 발생한다.
- [x] 수정하려는 날짜를 입력 받는다.
    - [x] `수정하려는 날짜(일)를 입력해 주세요.` 문구를 출력한다.
    - [x] 세상에 없는 날짜인 경우 예외가 발생한다.
    - [x] 출석이 불가능한 날짜인 경우 예외가 발생한다.
    - [x] 미래의 출석을 수정할 경우 예외가 발생한다.
- [x] 수정하려는 시간을 입력 받는다.
    - [x] `언제로 변경하시겠습니끼?` 문구를 출력한다.
    - [x] `hh:MM` 단위가 아닌 경우 예외가 발생한다. (24시 단위)
- [x] 수정 완료 메시지를 출력한다.
    - [x] `mm월 dd일 x요일 hh:MM (지각) -> hh:MM (출석) 수정 완료!` 문구를 출력한다.

### 크루별 출석 기록 확인

- [x] 닉네임을 입력 받는다.
    - [x] `닉네임을 입력해 주세요.` 문구를 출력한다.
    - [x] 등록되지 않은 크루인 경우 예외가 발생한다.
- [x] 해당 크루의 당월 출석 기록을 출력한다.
    - [x] `이번 달 {크루}의 출석 기록입니다.` 문구를 출력한다.
    - [x] 출석 가능한 날에 출석 기록이 없는 경우 결석이다.
    - [x] 출석, 지각, 결석 횟수를 출력한다.
    - [x] 제적 위험 여부를 출력한다.

### 제적 위험자 확인

- [x] 제적 위험자 목록 출력
    - [x] `제적 위험자 조회 결과` 문구를 출력한다.
    - [x] `- {크루}: 결석 n회, 지각 m회 (면담)` 형식으로 출력한다.
    - [x] 제적 위험자 정렬 기준
        - 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력한다.
        - 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.
        - 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

### 종료

- [x] 프로그램을 종료한다.
