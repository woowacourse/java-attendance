# 파일 입출력
- [x] `src/main/resources/attendances.csv` 불러오기
- [x] 크루 등록
- [x] 출석 확인

# 기능 선택
- [x] 메뉴 메시지 출력
> "오늘은 12월 12일 토요일입니다. 기능을 선택해 주세요."  
> "1. 출석 확인"  
> "2. 출석 수정  
> "3. 크루별 출석 기록 확인"  
> "4. 제적 위험자 확인"  
> "Q. 종료"  

- [ ] 각 메뉴 기능 선택 (입력)
    - [ ] 입력 값은 1, 2, 3, 4, Q / 이외의 값 입력 시 예외 발생
- [ ] 각 기능 수행 후 초기 화면으로 돌아감
    
# 출석 확인 
- [x] 닉네임과 등교 시간을 입력하면 출석
> "닉네임을 입력해 주세요."  
> "등교 시간을 입력해 주세요."  
- [ ] 출석 후 출석 기록을 확인
> "12월 05일 화요일 09:59 (출석)"  
- [ ] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내
> "이미 출석하여 다시 출석할 수 없습니다. 수정 기능을 이용해주세요."

# 출석 수정
- [x] 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정
  > "출석을 수정하려는 크루의 닉네임을 입력해 주세요."  
  > "수정하려는 날짜(일)를 입력해 주세요."  
  > "언제로 변경하겠습니까?"
  - [x] 출석 기록이 없는 날짜를 수정할 경우 예외 발생
- [ ] 수정 후 변경 전과 변경 후의 출석 기록을 확인
> "12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!"  

# 출석, 지각 결석 판단
- `교육 시간 = 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00`  
<br/>

- [x] 해당 요일의 시작 시각으로부터 5분 초과는 지각
- [x] 해당 요일의 시작 시각으로부터 30분 초과는 결석
- [ ] 출석 기록이 없는 날의 경우 결석

# 크루별 출석 기록 확인
- [ ] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인
> "닉네임을 입력해 주세요."  
> "이번 달 빙티의 출석 기록입니다."  
> "12월 12일 월요일 12:20 (출석)"  
> "출석: 3회"  
> "면담 대상자입니다."  

# 제적 위험자 확인
- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악  
- [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력 
- [ ] 정렬 순서는 지각을 결석으로 간주하여 내림차순 / 출석 상태가 같으면 닉네임으로 오름차순  
> "제적 위험자 조회 결과"  
> "빙티: 결석 3회, 지각 4회 (면담)"  

- 지각 3회는 결석 1회로 간주한다.  
- 경고 대상자: 결석 2회 이상  
- 면담 대상자: 결석 3회 이상  
- 제적 대상자: 결석 5회 초과

# 예외 처리
- [ ] 예외 발생 시 발생 시점부터 재입력 기능
- [ ] 예외 발생 시 `[ERROR]`와 함께 메시지 출력
> "[ERROR] 등록되지 않은 닉네임입니다."
- [ ] 주말 및 공휴일에 출석 시 예외 발생 (출석 확인, 수정)
> "[ERROR] 12월 14일 토요일은 등교일이 아닙니다."  
- [ ] 캠퍼스 운영 시간이 아닐 시 예외 발생 (출석 확인, 수정)
> "[ERROR] 캠퍼스 운영 시간이 아닙니다."  
- [ ] 등록되지 않은 크루원을 입력할 경우 경우 예외 발생
> "[ERROR] 등록되지 않은 닉네임입니다."
- [ ] 미래 날짜를 출석, 수정할 시 예외 발생
> "[ERROR] 미래 날짜는 출석할 수 없습니다."
