## 구현할 기능 목록
- [x] 출석 확인 기능
    - [x] 닉네임과 등교 시간을 입력하면 출석할 수 있음.
    - [x] 출석 후 출석 기록을 확인하는 기능.
    - [x] 이미 출석한 경우, 수정 기능을 안내하는 기능.
    - [x] 출석, 지각, 결석 여부가 표시되어야 함.


- [ ] 출석 수정 기능
    - [x] 닉네임, 수정 날짜 및 시간을 입력할 수 있음.
    - [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인할 수 있음.


- [ ] 크루별 출석 확인 기능
    - [ ] 크루의 닉네임을 입력할 수 있음.
    - [ ] 전날까지의 크루 출석 기록을 확인할 수 있음.
    - [ ] 출석, 지각, 결석 횟수를 확인할 수 있음.
    - [ ] 적용된 패널티(면담 등)을 확인할 수 있음.


- [ ] 제적 위험자 확인 기능
    - [ ] 제적 대상자, 면담 대상자, 경고 대상자 순으로 출력.
    - [ ] 지각을 결석으로 간주하여 내림차순 해야 함.
    - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬해야 함.


- [x] 프로그램 첫 시작 시 현재 날짜 + 요일을 출력해야 함.
- [x] 기능을 선택할 수 있어야 함.
- [ ] 출석하고자 하는 날이 등교일이 아니라면, 에러를 띄워야 함.
