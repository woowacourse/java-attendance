## java-attendance

### 문제 상황

지금까지 출석부를 수동으로 관리하다 보니 많은 크루의 출석 현황을 효율적으로 관리하기 어려웠습니다.
제때 누적 지각 크루를 파악하지 못해 면담이 지연되거나, 결석 일수를 계산하는 과정에서 실수가 발생한 경우가 있었습니다.

### 목표

`2024년 12월` 한 달 동안 시범적으로 최소한의 기능을 갖춘 `출석 시스템`을 개발하여 코치가 출석을 체계적으로 관리할 수 있도록 합니다.

### 구현할 기능 목록

- [x] 홈 화면
    - [x] `오늘은 MM월 dd일 E요일입니다. 기능을 선택해 주세요.` 문구를 출력한다.
        - [x] 기능 선택
            - [x] 선택 가능한 기능 목록을 출력한다.
            - [x] 명령어를 입력받고 확인한다.
- [x] 출석 확인 기능
    - [x] 출석할 크루의 닉네임 입력
        - [x] `닉네임을 입력해 주세요.` 문구를 출력한다.
    - [X] 등교 시간 입력
        - [x] `등교 시간을 입력해 주세요.` 문구를 출력한다.
    - [x] 출석 기록 출력
        - [x] `MM월 dd일 E요일 HH:mm ({출석 유형})` 형태로 출력한다.
- [x] 출석 수정 기능
    - [x] 수정할 크루의 닉네임 입력
        - [x] `출석을 수정하려는 크루의 닉네임을 입력해 주세요.` 문구를 출력한다.
    - [x] 수정할 날짜 입력
        - [x] `수정하려는 날짜(일)를 입력해 주세요.` 문구를 출력한다.
    - [x] 수정할 시간 입력
        - [x] `언제로 변경하겠습니까?` 문구를 출력한다.
    - [x] 변경 전과 변경 후의 출석 기록 출력
        - [x] `MM월 DD일 E요일 HH:mm ({출석 유형}) -> HH:mm ({출석 유형}) 수정 완료!` 형태로 출력한다.
- [x] 크루별 출석 기록 확인 기능
    - [x] 확인할 크루의 닉네임 입력
        - [x] `닉네임을 입력해 주세요.` 문구를 출력한다.
    - [x] 크루의 출석 기록 출력
        - [x] `이번 달 {닉네임}의 출석 기록입니다.` 문구를 출력한다.
        - [x] 전날까지의 크루 출석 기록
            - [x] `MM월 dd일 E요일 HH:mm ({출석 유형})` 형태로 출력한다.
        - [x] 출석, 지각, 결석 횟수 출력
            - [x] `{출석 유형}: n회` 형태로 출력한다.
        - [x] 누적 지각 및 결석 횟수에 따른 경고 유형 출력
            - [x] `{경고 유형} 대상자입니다.` 형태로 출력한다.
- [x] 제적 위험자 확인 기능
    - [x] `제적 위험자 조회 결과` 문구를 출력한다.
    - [x] 제적 위험자 명단 출력
        - [x] `- {닉네임}: 결석 n회, 지각 m회 ({경고 유형})` 형태로 출력한다.
            - [ ] 정렬하여 출력한다.
                - 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 정렬하며,   
                  대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.  
                  출석 상태가 같으면 닉네임으로 오름차순 정렬한다.
- [x] 프로그램 종료 기능
    - 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

## 명령어

- 명령어를 명확하게 정의하고, 입력 값을 기반으로 해당 명령어를 찾는 기능을 제공한다.
    - [x] 특정 명령어의 코드와 일치하는 문자열로 명령어로 바꿀 수 있다.
    - [x] 각 명령어가 수행할 기능의 설명을 가진다.
    - [x] 찾을 수 없는 명령어인 경우 예외가 발생한다.

## 출석 유형

- [x] 출석, 지각, 결석으로 구성된다.
    - [x] 기준 시간과 등교 시간으로 출석 유형을 판단할 수 있다.
        - [x] 등교하지 않아 출석 시간이 없는 날은 결석으로 간주한다.

## 교육 일정(스케줄)

- [x] 각 요일마다 교육이 있는 경우 시작 시간과 종료 시간을 가진다.
    - [x] 요일로 시작 시간을 확인할 수 있다.
        - [x] 교육 일정이 없는 요일인 경우 예외가 밣생한다.

## 법정 공휴일

- 법정 공휴일을 관리한다.
    - [x] 월과 일을 가진다.
    - [x] 날짜로 법정 공휴일인지 확인할 수 있다.

## 출석 로그

- [x] 닉네임과 등교 시간을 가진다.
    - 닉네임
        - [x] 2자 이상 4자 이하여야 한다.
        - [x] 한글만 가능하다.
        - [x] 공백으로만 구성될 수 없다.
    - 등교 시간
        - [x] 날짜와 시간을 가진다.
        - [x] 시간은 24시간 형식이다.
        - [x] 시간 기록이 없는 경우 결석으로 간주한다.
        - [x] 주말에는 출석할 수 없다.
        - [x] 법정 공휴일에는 출석할 수 없다.
        - [x] 캠퍼스 운영시간 외에는 출석할 수 없다.
    - [x] 닉네임과 출석 날짜가 같은 경우 동일한 출석 기록으로 간주한다.

## 출석 로그 목록

- [x] 출석 로그 목록을 가진다.
    - 출석 로그 목록
        - [x] 출석 로그를 저장할 수 있다.
        - [x] 같은 닉네임을 가진 경우 같은 크루로 간주한다.
        - [x] 기준 날짜와 닉네임으로 기준 날짜 전날까지의 출석 기록을 조회할 수 있다.

## 출석 로그 파일

```csv
nickname,datetime
쿠키,2024-12-13 10:08
빙봉,2024-12-13 10:07
빙티,2024-12-13 10:07
```

- [x] 위와 같은 형식의 파일에서 출석 로그 데이터를 불러온다.
    - `src/main/resources/attendances.csv` 경로를 사용한다.
    - 파일을 불러오는 중 발생할 수 있는 예외 종류
        - [x] 파일 입출력 문제가 발생한 경우
        - [x] 파일 형태가 올바르지 않은 경우
            - [x] 파일이 비어있는 경우
            - [x] 파일 헤더 형태가 다른 경우
            - [x] 데이터 형태가 다른 경우 (닉네임, 등교 시간)
