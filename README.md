# 📕 출석
2024년 12월 한 달 동안 시범적으로 사용할 최소한의 기능을 갖춘 출석 시스템 개발

## ⚙️ 기능 구현 목록

### 프로그램 동작
- [ ] 현재 날짜와 선택 가능한 메뉴를 출력하는 기능
- [ ] 선택할 메뉴를 입력받는 기능

### 출석 등록
- [ ] 닉네임과 등교 시간을 입력받는 기능
- [ ] 현재 날짜와 입력받은 시간을 기반으로 출석 기록을 생성하는 기능
- [ ] 출석 기록을 출력하는 기능

### 출석 수정
- [ ] 닉네임, 수정하려는 날짜, 등교 시간을 입력받는 기능
- [ ] 대응하는 출석 기록의 시간을 변경하는 기능
- [ ] 변경 전과 변경 후의 출석 기록을 출력하는 기능

### 크루별 출석 기록 확인
- [ ] 닉네임을 입력받는 기능
- [ ] 특정 크루의 출석 기록들을 찾는 기능
- [ ] 크루의 출석 기록을 출력하는 기능

### 제적 위험자 확인
- [ ] 제적 위험자인 크루들을 파악하는 기능
- [ ] 제적 위험자 목록을 정렬하고 출력하는 기능

### 예외 상황
- [ ] 출석하려는 날짜가 주말 및 공휴일인 경우
- [ ] 출석하려는 시간이 캠퍼스 운영 시간이 아닌 경우
- [ ] 등록되지 않은 크루 이름을 입력한 경우
- [ ] 존재하지 않는 옵션을 입력한 경우
- [ ] 입력한 날짜 형식이 올바르지 않은 경우
- [ ] 입력한 시간 형식이 올바르지 않은 경우
- [ ] 출석 기록이 존재하는데 다시 출석을 시도하는 경우
