# java-attendance

---

### 출석 시간 (CampusTime)
- [x] 문자열 HH:MM 형식 (ex:"10:30")을 입력받아 객체를 생성한다.
  - [x] 지정된 형식 HH:MM  이 아닌 문자열 입력시, 예외를 발생시킨다. 
  - [x] 시가 0~24, 분이 0~60 범위를 초과할 경우, 예외를 발생시킨다. 
- [x] isAfter(), isBefore() 등 시간간의 비교를 구현한다.
- [x] 캠퍼스 운영 시간은 매일 08:00 ~ 23:00 이다. 
  - [x] 운영 시간 외의 시간을 입력받을 시, 예외를 발생시킨다.

### 출석 날짜 (CampusDate)
- [x] 현재 날짜를 입력받아, 객체로 생성한다. 
- [x] 일(day)을 입력받아, 객체로 생성한다.
  - [x] 해당 월의 범위를 초과한 일을 입력받은 경우 (ex 2월 31일) 예외를 발생시킨다. 
- [x] 해당 일이 어떤 요일인지 반환한다. 
- [x] 주말 및 공휴일에는 출석을 받지 않는다.
  - [x] 만약 주말의 데이터가 들어왔을 경우, 예외를 발생시킨다.

### 출석 정보 (AttendanceInfo)
- [x] 날짜와 시간을 입력받아, 객체를 생성한다.
- [x] 시간을 입력받아 해당 정보로 수정한다.

### 출석 정보들 (AttendanceInfos)
- [ ] 출석 정보들을 모아둔다. 
- [ ] 생성된 출석 정보를 추가한다. 
- [ ] 일(day)를 입력받아, 해당하는 출석 정보를 찾는다.
- [ ] 기준 날짜 전날까지의 출석 정보와, 출석 상태 횟수, 출결 상태를 반환한다.
    - [ ] 결석 2회 이상부터 경고, 3회 이상부터 면담, 5회 초과시 제적 대상자로 구분한다.

### 출석부 (AttendanceBook)
- [ ] 크루와 출석 정보들을 연결시킨다. 
- [ ] 출석 기록이 없을 시 결석으로 간주한다.
- [ ] 제적 위험자를 조회한다.  
  - [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 정렬한다.
  - [ ] 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순으로 정렬한다. 
  - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

### 출석 상태 (AttendanceStatus)
- [ ] 출석, 지각, 결석 세 가지 상태로 존재한다.
- [ ] 출석 날짜와 출석 시간을 토대로 출석 상태를 계산한다.
  - [ ] 5분 초과시 지각, 30분 초과 시 결석으로 계산한다.
  - [ ] 화 ~ 금 은 10:00 ~ 18:00 기준으로 계산한다.
  - [ ] 월요일은 13:00 ~ 18:00 기준으로 계산한다.

### 크루 상태 (AttendanceRiskLevel)
- [ ] 정상, 경고, 면담, 제적 대상자로 구분한다.
- [ ] 출석 정보를 전달받아, 출결 상태를 반환한다.
  - [ ] 결석 2회 이상부터 경고, 3회 이상부터 면담, 5회 초과시 제적 대상자로 구분한다.

### 크루 (Crew) 
- [ ] 크루 이름을 입력받아, 객체를 생성한다.
- [ ] 동일한 이름을 가진 크루객체들이 동일하도록, equals() 및 hashCode()를 구현한다.
