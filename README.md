# java-attendance

2단계 - 출석 다시 구현하기

## 도메인 요구 사항

### 1. 출석 확인 기능

- [x] 1.1 닉네임과 등교 시간을 받으면 오늘 날짜로 출석 기록을 생성할 수 있다.
    - 입력한 출석 시간에 따라 출석, 지각 또는 결석으로 처리한다.
    - 교육 시간은 월요일은 13:00-18:00, 화요일-금요일은 10:00-18:00이다.
    - 해당 요일의 시작 시각으로부터 5분 초과는 지각으로 간주한다.
    - 해당 요일의 시작 시각으로부터 30분 초과는 결석으로 간주한다.
- [x] 1.2 이미 출석한 경우 예외를 발생시킬 수 있다.
    - `[ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해 주세요.`
- [x] 1.3 기록이 없는 닉네임을 입력하면 예외를 발생시킬 수 있다.
    - `[ERROR] 등록되지 않은 닉네임입니다.`
- [x] 1.4 등교일이 아닐 경우(주말, 공휴일, 방학) 예외를 발생시킬 수 있다.
    - `[ERROR] 3월 1일 토요일은 등교일이 아닙니다.`
- [x] 1.5 캠퍼스 운영 시간이 아닐 경우 예외를 발생시킬 수 있다.
    - 캠퍼스 운영 시간은 매일 08:00~23:00이다.
    - `[ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.`

### 2. 출석 수정 기능

- [x] 2.1 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정할 수 있다.
- [x] 2.2 기록이 없는 닉네임을 입력하면 예외를 발생시킬 수 있다.
    - `[ERROR] 등록되지 않은 닉네임입니다.`
- [x] 2.3 출석 기록이 없는 날짜를 입력한 경우 예외를 발생시킬 수 있다.
    - `[ERROR] 출석 기록이 없는 날짜는 수정할 수 없습니다.`

### 3. 크루별 출결 기록 확인 기능

- [x] 3.1 닉네임을 입력하면 전날까지의 출결 기록을 확인할 수 있다.
- [x] 3.2 닉네임을 입력하면 전날까지의 크루 출결 횟수를 확인할 수 있다.
- [x] 3.3 닉네임을 입력하면 크루의 제적 위험자 여부를 확인할 수 있다.
    - 지각 3회는 결석 1회로 간주한다.
    - 경고 대상자: 결석 2회 이상
    - 면담 대상자: 결석 3회 이상
    - 제적 대상자: 결석 5회 초과
- [x] 3.4 기록이 없는 닉네임을 입력하면 예외를 발생시킬 수 있다.
    - `[ERROR] 등록되지 않은 닉네임입니다.`

  ### 4. 제적 위험자 확인 기능

    - [x] 4.1 제적 위험자에 해당하는 크루들을 확인할 수 있다.
        - 지각 3회는 결석 1회로 간주한다.
        - 경고 대상자: 결석 2회 이상
        - 면담 대상자: 결석 3회 이상
        - 제적 대상자: 결석 5회 초과

## 입출력 요구 사항

### 5. 메뉴 입출력

- [x] 5.1 오늘 날짜와 메뉴 리스트를 출력할 수 있다.
- [x] 5.2 실행할 메뉴를 입력할 수 있다.
- [x] 5.3 사용자가 입력한 메뉴에 따라 해당 기능을 실행할 수 있다.
- [ ] 5.4 예외가 발생하면 초기 화면으로 돌아갈 수 있다.
- [x] 5.5 존재하지 않는 메뉴를 선택한 경우 예외를 발생시킬 수 있다.
    - `[ERROR] 존재하지 않는 메뉴입니다.`

```angular2html
오늘은 2월 25일 화요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
Q
```

### 6. 출결 관리 파일 입출력

- [x] 6.1 프로그램 시작 시 출석 기록 파일에서 출석 기록을 읽어올 수 있다.

```angular2html
nickname,datetime
밍트,2025-02-24 13:06
프리,2025-02-24 13:02
노랑,2025-02-24 13:01
미미,2025-02-24 13:00
말론,2025-02-24 13:00
```

### 7. 출석 확인 입출력

- [x] 7.1 출석을 확인하고자 하는 크루의 닉네임을 입력할 수 있다.
- [x] 7.2 등교 시간을 입력할 수 있다.
- [x] 7.3 출석 후 출석 기록을 출력할 수 있다.
- [x] 7.4 시간 입력 형식이 잘못된 경우 예외를 발생시킬 수 있다.
    - `[ERROR] 시간은 HH:mm 형식으로 입력해 주세요.`

```declarative
닉네임을 입력해 주세요.
노랑
등교 시간을 입력해 주세요.
09:59

2월 25일 화요일 09:59 (출석)
```

### 8. 출석 수정 입출력

- [x] 8.1 출석을 수정하고자 하는 크루의 닉네임을 입력할 수 있다.
- [x] 8.2 출석 수정할 날짜(월)을 입력할 수 있다.
- [x] 8.3 출석 수정할 날짜(일)을 입력할 수 있다.
- [ ] 8.4 등교 시간을 입력할 수 있다.
- [ ] 8.5 변경 전과 변경 후의 출석 기록을 출력할 수 있다.
- [x] 8.6 날짜 입력 형식이 잘못된 경우 예외를 발생시킬 수 있다.
    - `[ERROR] 숫자를 입력해 주세요.`
    - `[ERROR] {}월 {}일은 존재하지 않는 날짜입니다.`
- [ ] 8.7 시간 입력 형식이 잘못된 경우 예외를 발생시킬 수 있다.
    - `[ERROR] 시간은 HH:mm 형식으로 입력해 주세요.`

```declarative
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
노랑
수정하려는 날짜(월)를 입력해주세요.
2
수정하려는 날짜(일)를 입력해 주세요.
18
언제로 변경하겠습니까?
09:58

02월 18일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

### 9. 크루별 출결 기록 확인 입출력

- [ ] 9.1 출석 기록을 확인하고자 하는 크루의 닉네임을 입력할 수 있다.
- [ ] 9.2 크루 출결 기록을 출력할 수 있다.
- [ ] 9.3 크루 출결 횟수를 출력할 수 있다.
- [ ] 9.4 제적 위험자 여부를 출력할 수 있다.

```declarative
닉네임을 입력해 주세요.
노랑

노랑의 출석 기록입니다.

02월 11일 화요일 --:-- (결석)
02월 12일 수요일 --:-- (결석)
02월 13일 목요일 10:02 (출석)
02월 14일 금요일 10:07 (지각)
02월 17일 월요일 10:02 (출석)
02월 18일 화요일 10:07 (지각)
02월 19일 수요일 10:01 (출석)
02월 20일 목요일 --:-- (결석)
02월 21일 금요일 10:03 (출석)
02월 24일 월요일 10:02 (출석)

출석: 5회
지각: 2회
결석: 3회

면담 대상자입니다.
```

### 10. 제적 위험자 확인 입출력

- [ ] 10.1 제적 위험자 조회 결과를 출력할 수 있다.
    - 제적 대상자, 면담 대상자, 경고 대상자순으로 출력한다.
    - 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다.
    - 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

```declarative
제적 위험자 조회 결과
- 노랑: 결석 3회, 지각 4회 (면담)
- 미미: 결석 2회, 지각 5회 (면담)
- 밍트: 결석 1회, 지각 6회 (면담)
- 말론: 결석 2회, 지각 3회 (면담)
- 프리: 결석 0회, 지각 6회 (경고)
```
