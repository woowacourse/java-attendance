# java-attendance

출석 미션 저장소

# 구현 기능 목록

### 0. 초기화
- [ ] 등교일 : 월~금요일 (공휴일은 제외한다)
- [ ] 교육 시간 : 월요일은 13:00-18:00, 화~금요일은 10:00-18:00이다.
- [ ] 캠퍼스 운영 시간 : 매일 08:00-23:00
- [x] 크루 파일 정보 : 닉네임 & 출석 일시

### 1. 코치가 기능을 선택한다.
- [x] 오늘 날짜와 기능 목록을 출력한다.
- [x] 사용자(코치)는 원하는 기능 번호를 입력한다.
```markdown
오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
1
```

### 2. [1] 출석 확인 기능을 수행한다.
- [x] 사용자는 닉네임과 등교 시간을 입력한다.
- [x] 오늘 날짜에 닉네임에 맞는 크루의 출석 시간과 상태를 등록한다.
- [ ] 등교일이 아닐 경우엔 예외를 반환한다.
- [x] 출석 후 출석 날짜, 출석 시간, 출결 상태를 반환한다.
- [ ] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.
```markdown
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 13일 금요일 09:59 (출석)
```

### 3. [2] 출석 수정 기능을 수행한다.
- [ ] 사용자는 닉네임, 수정일, 수정 시간을 입력한다.
- [ ] 닉네임에 맞는 크루의 수정일의 출석 시간과 상태를 변경하여 다시 등록한다.
- [ ] 미래의 날짜거나, 등교일이 아닌 날을 수정할 땐 예외를 반환한다.
- [ ] 출석한 적 없는 날짜를 수정할 땐 --:--(결석)에서 새로운 시간으로 수정한다.
- [ ] 수정 후 수정 날짜, 수정 전 시간, 수정 후 시간, 수정 전 출결상태, 수정 출결상태를 반환한다.
```markdown
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

### 4. [3] 크루별 출석 기록 확인 기능을 수행한다.
- [ ] 사용자는 닉네임을 입력한다.
- [ ] 닉네임에 맞는 크루의 일별 출석 기록과 출석 통계를 반환한다.
- [ ] 일별 출석 기록엔 출석 날짜, 출석 시간, 출결 상태가 있다.
- [ ] 출석 통계에는 총 출결 횟수와 제적 상태가 반환된다.
- [ ] 12/1부터 오늘 기준 전날까지 모든 등교일의 정보를 반환한다.
```markdown
닉네임을 입력해 주세요.
빙티

이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 09:58 (출석)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:08 (지각)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)

출석: 4회
지각: 2회
결석: 3회

면담 대상자입니다.
```

### 5. [4] 제적 위험자 확인 기능을 수행한다.
- [ ] 12/1부터 오늘 기준 전날까지 모든 제적 위험자의 정보를 반환한다.
- [ ] 각 크루의 이름, 결석횟수, 지각횟수, 패널티 상태를 반환한다.
- [ ] 제적상태는 지각 3회를 결석 1회로 치환하여 계산한다.
```markdown
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 2회 (면담)
- 이든: 결석 2회, 지각 4회 (면담)
- 쿠키: 결석 2회, 지각 2회 (경고)
- 빙봉: 결석 1회, 지각 5회 (경고)
```

### 6. [Q] 기능을 종료한다.
- [ ] 프로그램을 정상 종료한다.

### 예외 처리
- [ ] 사용자가 잘못된 값을 입력할 경우, 예외메세지를 출력하고 재입력받는다.
- [ ] 시스템 상 에러가 있을 경우, 에러메세지를 출력하고 기능 선택 화면으로 돌아간다.
