# java-attendance

## 출석 관리 시스템 요구 사항

### 출석 시스템

- [ ] 캠퍼스 운영 시간
- [ ] 요일과 시간에 따른 출석 상태
    - [ ] 주말 처리
- [ ] 출석 시간
    - [ ] 출석 상태가 결석인지 확인
    - [ ] 요일 별 출석 시간에 따른 상태 처리
- [ ] 제적 상태
    - [ ] 출석 기록으로부터 받은 패널티 횟수 메시지로 연산을 해 해당되는 패널티 반환
- [ ] 출석부
    - [ ] 초기 출석 상태 초기화 (1일부터 현재일 이전 날 까지)
- [ ] 출석 확인
    - [ ] 출석부에서 존재하는 크루 명인지 확인 후 없으면 예외 발생
    - [ ] 해당하는 크루의 출석 기록부 가져오기
    - [ ] 출석 기록에게 해당 시간 출석 등록 해달라고 요청하기

- [ ] 출석 기록
    - [ ] 제적 상태 반환
        - [ ] 출석 시간 객체에게 결석인지 메시지 요청
        - [ ] 결석이 2회 이상이면 경고 반환
        - [ ] 결석이 3회 이상이면 면담 반환
        - [ ] 결석이 5회 초과이면 제적 반환
    - [ ] 출석부로부터 출석 등록 요청받은 시간이 이미 등록되어있는지 확인 후 있으면 예외 발생
    - [ ] 출석 기록에 출석 시간 추가
    - [ ] 등록된 시간 반환

- [ ] 출석 수정
    - [ ] 출석부가 출석 기록에게 사용자로부터 전달받은 날짜를 전달해 기록이 있는지 물어본다.
        - [ ] 없으면 예외 발생
    - [ ] 이전 출석 기록을 반환한다.
    - [ ] 출석부가 출석 기록에게 수정해달라고 요청한다.
    - [ ] 출석 기록이 출석 시간에게 특정 시간으로 바꿔달라고 요청한다.
    - [ ] 출석 기록은 새로운 출석 기록을 만들어서 반환한다.

- [ ] 출석 기록 확인
    - [ ] 크루의 닉네임에 해당하는 가장 최신 출석 정보를 반환한다.

- [ ] 제적 위험자 확인
    - [ ] 결석 횟수로 1차 정렬한다.
    - [ ] 결석 횟수가 같으면 지각 횟수로 2차 정렬한다.
    - [ ] 결석 횟수도 같고 지각 횟수도 같으면 닉네임으로 3차 정렬한다.
    - [ ] 정렬된 제적위험자 크루들을 반환한다.
