# java-attendance

## 기능 목록

### 파일 입력
- [ ] csv 파일 파싱
  - [ ] 크루 정보 수집
    - [ ] 크루 유효성 검사
  - [ ] 출석일 확인
    - [ ] 등교일 여부 확인
  - [x] 결석일 생성 (값이 없을 때 자동으로)

### 커맨드
- [ ] 교육 요일, 시간 관리 - enum
- [ ] 출석 확인 (생성)
    - [x] 지각 여부
    - [x] 결석 여부
- [ ] 출석 수정
    - [ ] 출석 확인 과정 (지각/결석 여부)
- [ ] 크루 별 출석 기록 확인
    - [ ] 출석 리스트 확인
    - [x] 출/지/결 확인
    - [x] 대상자 여부 확인
- [ ] 제적자 위험 확인
    - [x] 제적 계산
    - [x] 면담 계산
    - [x] 경고 계산
    - [ ] 정렬
- [ ] 종료

### 입출력
- [ ] 무한 커맨드 입력 (Q 전까지)
- [ ] 커맨드 선택창 출력 (입력)
- [ ] 출석 확인
  - [ ] 닉네임 입력 
  - [ ] 등교시간 입력
  - [ ] 확인 내역 출력
- [ ] 출석 수정
  - [ ] 닉네임 입력
  - [ ] 날짜 입력
  - [ ] 시간 입력
  - [ ] 수정 내역 출력
- [ ] 크루별 출석 기록
  - [ ] 닉네임 입력
  - [ ] 크루별 출석 기록 출력
- [ ] 제적자 위험 조회
  - [ ] 제적자 위험 조회 출력

## 도메인

### 크루
- 이름
- 출석부
- 제적 여부

### 크루 그룹
- List<크루>

### 출석부
- List<출석기록>
+ 출석 횟수 계산
+ 지각 횟수 계산
+ (지각 변환 포함) 결석 횟수 계산
+ 순수 결석 횟수 계산

### 출석 기록
- 날짜
- 시간

### 휴일 enum
- 날짜 (공휴일, 주말)
