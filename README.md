# java-attendance

출석 미션

# 요구사항

## 파일 입출력

- 파일을 읽어오는 기능
    - [x] 닉네임, 출력일시 파일에 저장하는 기능

## 입력

- 닉네임 입력
    - [x] 한글만 입력
    - [ ] 2글자 또는 3글자만 입력
- 등교 시간 입력
    - [x] 24시간 형식 입력
- 날짜 입력
    - [x] 숫자만 입력
    - [x] 31까지의 정수만 입력

## 출력

- [x] 수정된 출석 출력
- [x] 특정 크루의 출석 기록 출력
- [x] 제적 위험자 결과 출력

## 예외 처리

- 입력 형식이 맞지 않는 경우, IllegalArgumentException을 발생시킨 후 애플리케이션을 종료시킨다.

입력 예외

- [x] 잘못된 기능 번호를 입력한 경우
- [x] 닉네임을 입력하지 않은 경우
- [x] 출석 시간을 입력하지 않은 경우
- [x] 24시간 형식으로 입력하지 않은 경우
- [x] 날짜를 숫자로 입력하지 않은경우
- [x] 날짜 입력 범위를 초과한 경우

도메인 예외

- [x] 이미 오늘 출석한 크루가 출석한 경우
- [x] 존재하지 않는 크루를 찾는 경우
- [x] 출석 시간이 캠퍼스 운영시간이 아닌 경우
- [x] 입력한 요일이 존재하지 않는 요일인 경우
- [x] 공휴일에 출석하는 경우

파일 입출력 예외

- [ ] 잘못된 파일인 경우
