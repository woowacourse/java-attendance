# java-attendance

출석 미션 저장소

# 입력

- [x]  실행할 기능을 숫자로 입력 받는다
    - [x]  1 → 출석 확인
    - [x]  2 → 출석 수정
    - [x]  3 → 크루별 출석 기록 확인
    - [x]  4 → 제적 위험자 확인
    - [x]  Q를 입력하면 시스템을 종료한다
        - [x]  1, 2, 3, 4, Q가 아닌 문자가 들어왔을 때 예외처리

```
오늘은 00월 00일 0요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
```

- [x]  한 기능이 끝나면 다시 실행할 기능을 입력 받는다

### 출석 확인

- [x]  닉네임을 입력 받는다
- [x]  등교 시간을 입력 받는다.

### 출석 수정

- [x]  닉네임을 입력 받는다
- [x]  수정 날짜를 입력 받는다
- [x]  수정 시각을 입력 받는다.

### 크루별 출석 기록 확인

- [x]  닉네임을 입력 받는다

### 제적 위험자 확인

### 예외처리

- 닉네임 입력 시
    - [x]  없는 크루의 닉네임이면 예외처리
    - [x]  이미 출석 기록이 존재하는 크루의 경우 수정 기능을 이용하도록 안내한다
- 등교 시간 입력 시
    - [x]  형식은 HH:MM이어야 한다
    - [x]  형식이 맞지 않으면 예외처리 (콜론(:)과 24시 60분 제한 모두 포함)
- 날짜 입력 시
    - [x]  수정 날짜가 해당 월에 존재하지 않는 날짜인 경우 예외를 발생시킨다.

# 도메인

- [x]  csv 파일을 기반으로 크루들을 생성한다.
- [x]  csv 파일을 기반으로 크루별 출석 기록을 생성한다.

### 출석 확인

- [x]  오늘 날짜 크루의 출석 기록을 생성한다
- [x]  등교 시간에 따라 출석, 지각, 결석을 판단한다

```
출석: 시작 시간까지 등교
지각: 시작 시간 5분 초과
결석: 시작 시간 30분 초과 
```

- [x]  지각, 결석의 경우 누적 출석 상태를 업데이트한다

### 출석 수정

- [x]  크루의 해당 날짜 출석 내역을 조회한다
- [x]  기존 출석 시간을 새로운 등교시간으로 업데이트한다
- [x]  등교 시간에 따른 출석 상태를 업데이트한다.
- [x]  지각, 결석의 경우 누적 출석 상태를 업데이트한다

### 크루별 출석 기록 확인

- [x]  크루의 전체 출석 기록을 조회한다
- [x]  크루의 전체 출석 상태를 조회한다.
- [x]  크루의 제적 위험자 여부를 조회한다

### 제적 위험자 확인

# 출력

### 출석 확인

- [x]  출석 날짜와 요일, 출석 시간, 출석 여부를 출력한다

```
12월 13일 금요일 09:59 (출석)
```

### 출석 수정

- [x]  기존 출석 날짜와 요일, 출석 시간, 출석 여부와 수정 후의 출석 날짜와 요일, 출석 시간, 출석 여부를 출력한다

```
12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

### 크루별 출석 기록 확인

- [x]  크루의 이번 달 출석 기록을 출력한다
    - [x]  결석의 경우 시간은 `--:--`로 출력한다
    - [x]  주말과 공휴일은 출력하지 않는다
- [x]  크루의 누석 출석 상태를 출력한다
- [x]  제적 위험자 여부를 출력한다

```
12월 02일 월요일 13:00 (출석)
12월 03일 화요일 10:07 (지각)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:03 (출석)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)
12월 13일 금요일 10:02 (출석)

출석: 3회
지각: 0회
결석: 3회

면담 대상자입니다.
```

### 제적 위험자 확인

- [x]  제적 위험자를 출력한다
