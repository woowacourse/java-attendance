# java-attendance

---

## 추가한 기능 요구 사항

- 잘못된 입력에 대해 재입력 처리하지 않고 프로그램을 종료한다.
- 잘못된 입력을 한 경우, 에러 메시지를 출력한다.

---

## 기능 요구 사항

### 1. 출석 확인

- [ ] 닉네임, 등교 시간 입력
- [ ] 출석 확인 내역 출력
- [ ] 이미 출석한 경우, 재출석 금지
- [예외]

### 2. 출석 수정

- [ ] 닉네임, 수정 날짜, 등교 시간 입력
- [ ] 출석 수정 내용 변경 전과 후 내역 출력
- [예외]

### 3. 크루별 출석 기록 확인

- [ ] 닉네임 입력하면, 전날까지의 출석 기록 출력
- [예외]

### 4. 제적 위험자 확인

- [ ] 전날까지의 출석 기록 바탕으로 제적 위험자 계산
- [ ] 제적 위험자에 한해서, 제적, 면담, 경고 대상자순으로 출력
    - 정렬 기준1: 지각을 결석으로 간주하여 내림차순 정렬
    - 정렬 기준2: 출석 상태 동일하면 닉네임으로 오름차순 정렬
