# java-attendance

## 기능 목록

### 출석 시스템

- 크루의 출석 정보를 등록할 수 있다.
  - 2024년 12월을 시작으로 각 크루의 출석 정보를 등록할 수 있다.
  - 한 번 출석을 등록하면 같은 날 다시 등록하지 못한다.
  - 주말/공휴일에는 출석하지 못한다.
- 크루의 출석 정보를 수정할 수 있다.
  - 미래의 출석 정보는 수정할 수 없다.
  - 이전의 출석 정보와 수정된 출석 정보를 보여준다.
- 각 크루의 출석 정보를 확인할 수 있다.
  - 각 출석 기록은 각 기준에 따라 출석 / 지각 / 결석인지 알 수 있어야한다.
  - 크루의 출석 기록이 없다면 결석으로 등록한다.
- 전체 크루의 경고 상태 여부를 확인할 수 있다.
  - 전체 크루 중 경고 / 면담 / 제적에 해당하는 크루를 반환한다.
  - 보여지는 크루는 결석 / 지각 / 이름 순으로 정렬한다.

### 파일 입력

- [x] csv 파일 파싱
    - [x] 크루 정보 수집
        - [x] 크루 유효성 검사
    - [x] 출석일 확인
        - [x] 등교일 여부 확인
    - [x] 결석일 생성 (값이 없을 때 자동으로)

### 커맨드

- [x] 교육 요일, 시간 관리 - enum
- [x] 출석 확인 (생성)
    - [x] 지각 여부
    - [x] 결석 여부
- [x] 출석 수정
    - [x] 출석 확인 과정 (지각/결석 여부)
- [x] 크루 별 출석 기록 확인
    - [x] 출석 리스트 확인
    - [x] 출/지/결 확인
    - [x] 대상자 여부 확인
- [x] 제적자 위험 확인
    - [x] 제적 계산
    - [x] 면담 계산
    - [x] 경고 계산
    - [x] 결석 - 지각 - 이름 순으로 정렬
- [x] 종료

### 입출력

- [x] 무한 커맨드 입력 (Q 전까지)
- [x] 커맨드 선택창 출력 (입력)
- [x] 출석 확인
    - [x] 닉네임 입력
    - [x] 등교시간 입력
    - [x] 확인 내역 출력
- [x] 출석 수정
    - [x] 닉네임 입력
    - [x] 날짜 입력
    - [x] 시간 입력
    - [x] 수정 내역 출력
- [x] 크루별 출석 기록
    - [x] 닉네임 입력
    - [x] 크루별 출석 기록 출력
- [x] 제적자 위험 조회
    - [x] 제적자 위험 조회 출력
