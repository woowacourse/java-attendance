# java-attendance

## 프로그램 소개

12월간 시범 운영되는 출석 시스템입니다.

---

## 기능 목록

### 출석 정보 불러오기

- csv 파일의 정보를 불러온다.
- 불러온 정보로 크루와 출석 기록을 동기화한다.

### 출석 저장

- 닉네임을 입력하면, 해당 크루의 출석 시간과 출석 상태를 저장한다.
- 출석 기록이 없는 닉네임을 입력할 경우, 예외가 발생한다.
- 이미 출석한 경우, 예외가 발생한다.
- 캠퍼스 운영 시간이 아닐 경우, 예외가 발생한다.

### 출석 수정

- 닉네임, 수정 날짜, 수정 시간을 입력하여, 출석 정보를 수정한다.

### 크루 출석 기록

- 닉네임을 입력하면, 전날까지의 크루 출석 기록을 확인할 수 있다.
- 출석하지 않은 날은 결석 처리한다.
- 크루의 출석 상태 통계를 확인할 수 있다.

### 재적 상태 관리

- 크루의 제적 상태를 확인할 수 있다.
- 제적 상태 통계는 크루의 제적 상태에 따라 정렬된다.
