# 2단계 - 출석 미션

### 12월 시범 출석 관리 시스템을 구현한다.

### 출석 규칙

* 출석 시스템의 출석 확인은 크루가 캠퍼스에 들어온 후 시스템에 출석 데이터가 저장된 시간을 기준으로 한다.
* 시간은 24시간 형식만 사용한다. (00:00 ~ 24:00)
* 캠퍼스 운영 시간은 매일 08:00 ~ 23:00이다.
    * 캠퍼스 운영 시간 외에는 출석을 받지 않는다.
* 주말 및 공휴일에는 출석을 받지 않는다.
* 교육시간
    * 월요일 13:00 ~ 18:00
    * 화-금요일 10:00 ~ 18:00
* 지각 및 결석 기준
    * 출석: 00분 ~ 05분
    * 지각: 06분 ~ 30분
    * 결석: 31분 ~ + 출석 기록이 없는 날
* 경고 및 면담 기준
    * 지각 3회 = 결석 1회로 판단 후 다음 조건 확인
    * 경고 대상자: 결석 2회 이상
    * 면담 대상자: 결석 3회 이상
    * 제적 대상자: 결석 5회 초과

---

## 기능 구현 목록

### 파일 읽기

- [x] 출석 시스템에 등록된 크루 정보와 12월 출석 기록 파일(attendances.csv)을 읽어올 수 있다.

### 기능 선택

- [x] 오늘 날짜와 요일, 기능 선택 안내를 출력한다.
- [x] 1~4번까지의 기능을 선택한 후, 해당 기능을 실행한다.
    - [x] 유효하지 않은 번호를 입력한 경우 예외 발생
- [x] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.
- [x] 종료(Q)를 선택하면 프로그램이 종료된다.

출력 예시

~~~~~
오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
~~~~~

### 출석 확인

- [x] 닉네임을 입력받는다.
    - [x] 문자열이 비어있는 경우 예외 발생
    - [x] 등록되지 않은 닉네임인 경우 예외 발생
- [x] 등교 시간을 입력받는다.
    - [x] HH:mm 형식이 아닌 경우 예외 발생
    - [x] 캠퍼스 운영 시간이 아닌 경우 예외 발생
- [ ] 정보를 출석부에 저장 후 출력한다.
- [x] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 안내한다.

출력 예시

~~~~
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 05일 화요일 09:59 (출석)
~~~~

### 출석 수정

- [ ] 닉네임을 입력받는다.
    - [ ] 문자열이 비어있는 경우 예외 발생
    - [ ] 등록되지 않은 닉네임인 경우 예외 발생
- [ ] 수정하려는 날짜를 입력받는다.
    - [ ] 숫자가 아닌 경우 예외 발생
    - [ ] 날짜 범위가 1~31이 아닌 경우 예외 발생
    - [ ] 휴일인 경우 예외 발생
    - [ ] 출석하지 않은 날짜일 경우 예외 발생
- [ ] 변경 등교 시간을 입력받는다.
    - [ ] HH:mm 형식이 아닌 경우 예외 발생
    - [ ] 캠퍼스 운영 시간이 아닌 경우 예외 발생
- [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 출력한다. (`변경전` -> `변경후`)

출력 예시

~~~~
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
~~~~

### 크루별 출석 기록 확인

- [ ] 닉네임을 입력받는다.
    - [ ] 등록되지 않은 닉네임인 경우 예외 발생
    - [ ] 출석이 되어 있지 않은 경우 예외 발생
- [ ] 크루 출석 기록을 전날까지 출력한다.
- [ ] 출석 통계를 출력한다.
- [ ] 경고, 면담, 제적에 해당하는 경우 상태를 출력한다.

출력 예시

~~~~
닉네임을 입력해 주세요.
빙티

이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 10:07 (지각)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:03 (출석)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)
12월 13일 금요일 10:02 (출석)

출석: 5회
지각: 2회
결석: 3회

면담 대상자입니다.
~~~~

### 제적 위험자 확인

- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [ ] 제적 대상자, 면담 대상자, 경고 대상자순으로 정렬하여 출력한다.
    - [ ] 대상 항목별 정렬 순서는 지각 3회를 결석 1회로 간주하여 내림차순한다.
    - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

출력 예시

~~~~
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 4회 (면담)
- 이든: 결석 2회, 지각 5회 (면담)
- 빙봉: 결석 1회, 지각 6회 (면담)
- 쿠키: 결석 2회, 지각 3회 (면담)
- 짱수: 결석 0회, 지각 6회 (경고)
~~~~
