## 시간에 대한 정책

- [ ] 24시간 형식만 사용한다.

## 출석 기록에 대한 정책

- [x] 출석 기록이 없으면 결석이다.
- [x] 캠퍼스 운영 시간은 매일 08:00~23:00 이다.
    - [x] 운영 시간이 아니면 출석할 수 없다.
- [x] 주말이거나 공휴일인 경우 출석할 수 없다.

## 출석 시각에 대한 정책

- [x] 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00이다.
- [x] 요일의 교육 시작 시간으로부터 5분 초과는 지각이다.
- [x] 요일의 교육 시작 시간으로부터 30분 초과는 결석이다.

## 결석 및 지각 횟수에 대한 정책

- [x] 결석 2회 이상은 경고 대상이다.
- [x] 결석 3회 이상은 면담 대상이다.
- [x] 결석 5회 초과는 제적 대상이다.
- [x] 지각 3회는 결석 1회로 간주한다.

## 출석을 확인할 수 있다.

```
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 05일 화요일 09:59 (출석)

```

- [x] 닉네임과 등교시간을 입력하면 출석할 수 있다.
    - [x] 요청하는 날짜로 출석 기록을 저장한다.
    - [x] 이 때, 출석 기록 / 시각 에 대한 정책에 적합한지 확인한다.
    - [x] 존재하지 않는 크루인 경우 안내 문구를 출력한다.
- [x] 출석 후 출석 기록을 확인할 수 있다.
- [x] 이미 출석 기록이 있는지 확인한다.
    - [x] 같은 날짜에 대한 출석 기록인지 확인한다.
    - [x] 같은 크루에 대한 출석 기록인지 확인한다.
    - [x] 있다면 수정 기능을 사용하도록 안내한다.
- [x] 존재하지 않는 크루의 이름을 입력하면 바로 예외를 던진다.

## 출석을 수정할 수 있다.

```
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

- [x] 수정하고자 하는 크루의 닉네임과 날짜를 입력한다.
    - [x] 해당하는 출석 기록이 존재하지 않으면 안내 문구를 출력한다.
    - [x] 존재하지 않는 크루인 경우 안내 문구를 출력한다.
- [x] 변경하고자 하는 등교 시간을 입력한다.
    - [x] 이 때, 출석 기록 / 시각 에 대한 정책에 적합한지 확인한다.
    - [ ] 이 때, 시간 형식이 적합한지 확인한다.
- [x] 기존의 출석 기록을 수정한다.
- [ ] 변경 전과 변경 후의 출석 기록을 확인한다.
- [x] 존재하지 않는 크루의 이름을 입력하면 바로 예외를 던진다.

## 크루별 출석 기록 확인

```
닉네임을 입력해 주세요.
빙티

이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 10:07 (지각)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:03 (출석)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)
12월 13일 금요일 10:02 (출석)

출석: 5회
지각: 2회
결석: 3회

면담 대상자입니다.

```

- [x] 확인하고자 하는 크루의 닉네임을 입력한다.
    - [x] 이 때, 존재하지 않는 크루인 경우 안내 문구를 출력한다.
- [x] 조회하는 시점의 전날까지의 각 날짜의 출석 기록을 출력한다.
    - [x] 이 때, 출석 기록이 존재하지 않는 경우 `--:-- (결석)` 으로 출력한다.
- [x] 총 출석 / 지각 / 결석 횟수를 센다.
    - [x] 이 때 기록이 존재하지 않는 경우 결석으로 처리한다.
- [x] 면담 대상자인지 여부를 출력한다.
    - [x] 이 때, 지각 3회는 결석 1회로 가정한다.
- [x] 존재하지 않는 크루인 경우 바로 예외를 던진다.

## 제적 위험자 확인

```
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 4회 (면담)
- 이든: 결석 2회, 지각 5회 (면담)
- 빙봉: 결석 1회, 지각 6회 (면담)
- 쿠키: 결석 2회, 지각 3회 (면담)
- 짱수: 결석 0회, 지각 6회 (경고)
```

- [x] 조회하는 시점의 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
    - [x] 이 때, 제적 위험자는 결석 및 지각 횟수에 대한 정책 을 참고한다.
- [x] 제적 대상자 -> 면담 대상자 -> 경고 대상자 순으로 출력한다.
- [x] 지각을 결석으로 간주해 결석 횟수의 내림차순으로 출력한다.
- [x] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

## 옵션 선택

```
오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
```

- [ ] 각 선택지에 해당하는 로직을 수행한다.
- [x] 존재하지 않는 옵션을 선택한 경우 예외를 던진다.
- [ ] 오늘 날짜를 출력한다.
