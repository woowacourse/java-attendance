# 📕 출석
2024년 12월 한 달 동안 시범적으로 사용할 최소한의 기능을 갖춘 출석 시스템 개발

## ⚙️ 기능 구현 목록

- [x] 출석 등록
- [x] 출석 수정
- [x] 크루별 출석 기록 확인
- [x] 제적 위험자 확인

### view
- [x] 현재 날짜와 선택 가능한 메뉴를 출력하는 기능
- [x] 선택할 메뉴를 입력받는 기능

- 출석 등록
  - [x] 닉네임과 등교 시간을 입력받는 기능
  - [x] 출석 기록을 출력하는 기능

- 출석 수정
  - [x] 닉네임, 수정하려는 날짜, 등교 시간을 입력받는 기능
  - [x] 변경 전과 변경 후의 출석 기록을 출력하는 기능

- 크루별 출석 기록 확인
  - [x] 닉네임을 입력받는 기능
  - [x] 크루의 출석 기록을 출력하는 기능

-  제적 위험자 확인
  - [x] 제적 위험자 목록을 정렬하고 출력하는 기능

### controller
- [x] Q를 입력하기 전까지 반복 실행

### domain
- AttendanceBook
  - [x] 크루들과 크루들에 대한 출석 기록들을 저장
- Attendance
  - [x] 출석 날짜, 출석 시간, 출석 상태 저장
- Attendances
  - [x] 크루 한 명의 출석 기록들을 저장
- AttendanceDate
  - [x] 출석 날짜 저장
- AttendanceTime
  - [x] 출석 시간 저장
- AttendanceStatus
  - [x] 출석 상태(출석, 지각, 결석) 저장
- Crew
  - [x] 크루의 정보 저장
- CrewStatus
  - [x] 크루의 제적 상태 저장(해당없음, 경고, 면담, 제적)

### util
- DateTimeConvertor
  - [x] 문자열로 이루어진 날짜와 시간 정보를 LocalDate, LocalTime으로 파싱
- AttendanceFileReader
  - [x] 파일의 내용을 String으로 읽어오는 기능
- DayOfWeekConvertor
  - [x] 요일을 한글로 변환하는 기능
- InputProcessor
  - [x] 예외 발생 시 메시지를 출력하고 정상 반복까지 반복하는 기능

### 예외 상황
- [x] 출석하려는 날짜가 주말 및 공휴일인 경우
- [x] 출석하려는 시간이 캠퍼스 운영 시간이 아닌 경우
- [x] 등록되지 않은 크루 이름을 입력한 경우
- [x] 존재하지 않는 옵션을 입력한 경우
- [x] 입력한 날짜 형식이 올바르지 않은 경우
- [x] 입력한 시간 형식이 올바르지 않은 경우
- [x] 출석 기록이 존재하는데 다시 출석을 시도하는 경우
