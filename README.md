# java-attendance

출석 미션

# 요구사항

## 파일 입출력
- 파일을 읽어오는 기능
  - [ ] 닉네임, 출력일시 파일에 저장하는 기능

## 입력

- 닉네임 입력
    - [ ] 한글만 입력
    - [ ] 2글자 또는 3글자만 입력
- 등교 시간 입력
    - [ ] 24시간 형식 입력
    - [ ] 00:00 형식으로 입력
- 날짜 입력
    - [ ] 숫자만 입력
    - [ ] 31까지의 정수만 입력

## 출력

- [ ] 수정된 출석 출력
- [ ] 특정 크루의 출석 기록 출력
- [ ] 제적 위험자 결과 출력

## 예외 처리
- 입력 형식이 맞지 않는 경우, IllegalArgumentException을 발생시킨 후 애플리케이션을 종료시킨다.
