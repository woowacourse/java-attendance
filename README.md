# java-attendance

## 출결 관리 규칙
- `2024년 12월 한 달` 동안 시범적으로 최소한의 기능을 갖춘 출석 시스템을 개발하여 출석을 체계적으로 관리
- [x] 시간은 `24시간` 형식
- [x] 교육 시간 및 운영 시간
  - [x] 운영 시간은 매일 08:00 ~ 23:00 
  - [x] 월요일 13:00 ~ 18:00
  - [x] 화~금요일 10:00 ~ 18:00
  - [x] 주말 및 공휴일 출석 X
- [ ] 지각 및 결석 정책
  - [x] 시작 시간 5분 초과 - 지각
  - [x] 시작 시간 30분 초과 - 결석
  - [ ] 출석 기록 X - 결석
  - [ ] 지각 3회 == 결석 1회
  - [ ] 결석 2회 이상 - 경고
  - [ ] 결석 3회 이상 - 면담
  - [ ] 결석 5회 초과 - 제적

## 기능 요구 사항
- [ ] 출석 기록을 관리한다.
  - [ ] `src/main/resources/attendances.csv` 파일을 통해 출석 기록을 가져온다.
    - 닉네임, 출석 일시가 기록되어 있다.
- [ ] 출석 확인
  - [ ] 닉네임과 등교 시간을 입력
  - [ ] 출석 후 출석 기록 출력
    - [ ] 운영 시간 이외는 출석이 불가하다.
  - [ ] 이미 출석한 경우, 다시 출석 X
    - [ ] 수정 기능 이용하도록 안내 출력
- [ ] 출석 수정
  - [ ] 닉네임, 수정 날짜, 등교 시간을 입력
  - [ ] 출석 기록이 있는지 확인한다.
    - [ ] 출석 기록이 없으면 수정이 불가
  - [ ] 변경 전, 후 출석 기록 출력
- [ ] 크루별 출석 기록 확인
  - [ ] 닉네임을 입력
  - [ ] 크루 출석 기록을 출력
    - [ ] 일자별 출석 기록 출력
    - [ ] 현재 날짜까지의 출석 횟수 출력
    - [ ] 현재 날짜까지의 지각 횟수 출력
    - [ ] 현재 날짜까지의 결석 횟수 출력
    - [ ] 지각 및 결석 정책에 대한 결과 출력
- [ ] 제적 위험자 확인
  - [ ] 전날까지의 출석 기록으로 결석 횟수 출력
  - [ ] 전날까지의 출석 기록으로 지각 횟수 출력
  - [ ] 결석, 지각 횟수를 통해 결석 정책 결과 출력
    - 지각 3회 == 결석 1회
  - [ ] 제적 - 면담 - 경고 대상자 순으로 정렬 출력
    - 지각을 결석으로 간주하여 내림차순
      - 지각 3회를 결석 1회로 보고 남은 지각 횟수 + 결석으로 내림차순
