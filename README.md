# java-attendance

출석 미션 저장소

## 기능 요구 사항

### 출석 관리 규칙 및 시스템 설계 정책

- 출석 확인은 크루가 캠퍼스에 들어온 후 시스템에 출석 데이터가 저장된 시간 기준
- 시간은 24시간 형식만 사용 예) 22:30
- 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00
  - 해당 요일의 시작 시각으로부터 5분 초과는 지각
  - 해당 요일의 시작 시각으로부터 30분 초과는 결석
  - 등교하지 않아 출석 기록이 없는 날은 결석
- 경고/면담/제적 대상자
  - 지각 3회는 결석 1회로 간주
  - 경고 대상자: 결석 2회 이상
  - 면담 대상자: 결석 3회 이상
  - 제적 대상자: 결석 5회 초과
- 캠퍼스 운영 시간: 매일 08:00~23:00
  - 주말 및 공휴일에는 출석을 받지 않음

### 파일 입출력

- [x] 프로그램을 시작하면 파일을 통해 구현에 필요한 정보를 조회
  - [x] 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(attendances.csv)에서 확인 가능
  - [x] 닉네임과 출석 일시가 기록되어 있음

### 기능 선택

- [x] 프로그램은 사용자가 종료할 때까지 종료되지 않음
  - [x] 해당 기능을 수행한 후 초기 화면으로 돌아감

### 출석 확인

- [x] 닉네임과 등교 시간을 입력하면 출석 가능
- [x] 출석 후 출석 기록 확인 가능
- [x] 이미 출석한 경우, 다시 출석 불가
  - [x] 해당 날짜의 출석 기록이 있는지 확인

### 출석 수정

- [x] 출석 확인을 수정하려면 닉네임, 수정하려는 날짜, 등교 시간을 입력하여 기록을 수정 가능
- [x] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인 가능

### 크루별 출석 기록 확인

- [x] 닉네임을 입력하면 전날까지의 크루 출석 기록을 확인 가능

### 제적 위험자 확인

- [x] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악
- [x] 제적 위험자 정렬
  - [x] 제적 대상자, 면담 대상자, 경고 대상자순으로 출력
  - [x] 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순
  - [x] 출석 상태가 같으면 닉네임으로 오름차순 정렬
