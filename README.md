# java-attendance

출석 미션 저장소

## 요구 사항

- 12월 한 달만 고려한다.
- 데이터에서 주어진 닉네임 이외에 새로운 크루는 없다고 가정한다.
- 시간은 24시간 형식만 사용한다.
- 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00
- 해당 요일의 시작 시각으로부터 5분 초과는 지각, 30분 초과는 결석으로 간주한다.
- 출석 기록이 없으면 결석으로 간주한다.
- 누적 지각 및 결석 횟수에 따라 경고 또는 면담을 시행한다.
    - 결석 횟수가 5회 초과하면 제적한다.
    - 지각 3회는 결석 1회로 간주한다.
        - 경고 대상자: 결석 2회 이상
        - 면담 대상자: 결석 3회 이상
        - 제적 대상자: 결석 5회 초과
- 캠퍼스 운영 시간은 매일 08:00~23:00이다.
- 주말 및 공휴일에는 출석을 받지 않는다.
- 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

## 기능 사항

- 출석부는 크루별 출결 현황을 저장한다.
- 크루별 출결 현황(attends)는 무엇을 하는가?
    - 등록, 조회, 수정
- 출석(attend)은 무엇을 하는가?
- 시간 정보를 잘 가지고 있으면 됨.
    - 데이터를 그저 잘 가지는 책임.
    - 데이터 검증의 책임.

### 출석 등록

- [ ] 닉네임과 등교 시간을 입력해야 한다.
- [X] 닉네임과 등교 시간을 기반으로 출석 객체가 만들어져야 한다.
- [X] 출석 가능 일자인지 확인해야 한다.
- [X] 출석을 추가해야 한다.
- [X] 이미 출석한 경우, 예외를 throw 한다.
- [X] 주말 및 공휴일일 경우, 예외를 throw 한다.

### 출석 수정

- [ ] 닉네임, 수정하려는 날짜, 등교 시간을 입력해야 한다.
- [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 출력해야 한다.
- [X] 같은 날짜에 출석이 존재하는지 확인하는 기능
- [X] 닉네임 대상 출석 수정 기능
    - [X] 수정할 날짜에 출석이 존재하면 기존 출석을 변경하는 기능
    - [X] 수정할 날짜에 출석이 존재하지 않으면 추가하는 기능
- [ ] 출석 기록이 없는 날짜의 출석을 수정하려는 경우, 변경 전 시간은 '--:--'로 표시한다.
- [ ] 존재하지 않는 닉네임을 입력했을 경우, 예외를 throw 한다.
- [ ] 운영 시간 외 시간을 입력했을 경우, 예외를 throw 한다.

### 출석 기록 확인

- [ ] 닉네임을 입력받아야 한다.
- [ ] 현재 달의 출석 기록만 출력해야 한다.
- [ ] 존재하지 않는 닉네임을 입력했을 경우, 예외를 throw 한다.

### 제적 위험자 확인

- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악해야 한다.
- [ ] 제적 위험자는 제적 대상자, 면담 대상자, 경고 대상자순으로 출력해야 한다.
- [ ] 지각을 결석으로 간주하여 내림차순한다. 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.

### 파일 읽어오기

- [ ] csv 타입의 파일을 읽어야 한다.
