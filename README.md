# java-attendance

## 기능 목록

### 출석 시스템

- 크루의 출석 정보를 등록할 수 있다.
    - 2024년 12월을 시작으로 각 크루의 출석 정보를 등록할 수 있다.
    - 한 번 출석을 등록하면 같은 날 다시 등록하지 못한다.
    - 주말/공휴일에는 출석하지 못한다.
- 크루의 출석 정보를 수정할 수 있다.
    - 미래의 출석 정보는 수정할 수 없다.
    - 이전의 출석 정보와 수정된 출석 정보를 보여준다.
- 각 크루의 출석 정보를 확인할 수 있다.
    - 각 출석 기록은 각 기준에 따라 출석 / 지각 / 결석인지 알 수 있어야한다.
    - 크루의 출석 기록이 없다면 결석으로 등록한다.
- 전체 크루의 경고 상태 여부를 확인할 수 있다.
    - 전체 크루 중 경고 / 면담 / 제적에 해당하는 크루를 반환한다.
    - 보여지는 크루는 결석 / 지각 / 이름 순으로 정렬한다.

### 입력

- [x] 출석부 csv 파일을 읽는다.
- [x] 실행하고자 하는 명령어를 입력받아 'Q'가 나오기 전까지 반복한다.
- [x] 출석 확인을 위한 값을 입력받는다.
    - [x] 닉네임을 입력받는다.
    - [x] 등교 시간을 입력받는다.
- [x] 출석 수정을 위한 값을 입력받는다.
    - [x] 닉네임을 입력받는다.
    - [x] 수정 일을 입력받는다.
    - [x] 수정 시간을 입력받는다.
- [ ] 크루별 출석 기록 확인을 위한 값을 입력받는다.
    - [ ] 닉네임을 입력받는다.

### 출력

- [x] 출석 확인 정보를 출력한다.
- [ ] 출석 수정 정보를 출력한다.
    - [ ] 수정 전 시간과 수정 후 시간을 모두 보여준다.
- [ ] 크루별 출석 기록 확인 정보를 출력한다.
    - [ ] 해당 크루의 전체 출석 정보를 출력한다.
    - [ ] 출석, 지각, 결석 횟수를 출력한다.
    - [ ] 대상자라면 대상 정보를 출력한다 (경고/면담/제적)
- [ ] 제적 위험자 정보를 출력한다.

### 주요 기능

- [x] 출석부를 초기화한다
    - [x] 크루의 초기 출석 기록을 저장한다
- [x] 출석한다
    - [x] 오늘 날짜에 출석 정보가 존재하는지 확인한다
    - [x] 오늘이 주말 또는 공휴일인지 확인한다
        - [x] 주말에는 출석할 수 없다
        - [x] 공휴일에는 출석할 수 없다
    - [x] 출석 가능한 시간인지 확인한다
        - [x] 캠퍼스는 오전 8시~오후 11시까지 운영한다
    - [x] 출석 정보를 등록한다
    - [x] 출석 상태를 계산한다 (출석/지각/결석)
        - [x] 월요일 13시 5분까지 출석 / 13시 6분~30분 지각/ 13시 30분 초과 결석
        - [x] 그 외 평일 10시 5분 출석 / 10시 6분~30분 지각 / 10시 30분 초과 결석
- [x] 출석을 수정한다
    - [x] 오늘 또는 과거의 출석일자인지 확인한다
    - [x] 출석 정보를 수정한다
    - [x] 출석 상태를 계산한다 (출석/지각/결석)
- [ ] 크루의 출석 기록을 확인한다
    - [ ] 전체 출석 / 지각 / 결석 횟수를 계산한다
    - [ ] 대상자 여부를 계산한다
- [ ] 제적 위험자를 확인한다
    - [ ] 전체 크루 중 대상자를 계산한다
    - [ ] 대상자를 결석 > 지각 > 이름 순으로 정렬한다
- [ ] 공통
    - [x] 존재하는 크루인지 확인한다
