# 2단계 - 출석 미션

### 목표: 코치를 위한 12월 시범 출석 관리 시스템

### 출석 규칙
* 출석 확인 기준은 저장된 시간이다.
* 시간은 24시간 형식만 사용한다. (00:00 ~ 24:00)
* 입력에도 24시간 형식으로 입력해야 한다.
* 캠퍼스 운영 시간은 매일 08:00 ~ 23:00이다.
* 주말 및 공휴일에는 출석을 받지 않는다.
* 교육시간
  * 월요일 13:00 ~ 18:00
  * 화-금요일 10:00 ~ 18:00
* 지각 및 결석 기준
  * 출석: 00분 ~ 05분
  * 지각: 06분 ~ 30분
  * 결석: 31분 ~ + 출석 기록이 없는 날
* 경고 및 면담 기준
  * 지각 3회 = 결석 1회로 판단 후 다음 조건 확인
  * 경고 대상자: 결석 2회 이상
  * 면담 대상자: 결석 3회 이상
  * 제적 대상자: 결석 5회 초과
* 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(`attendances.csv`)에서 확인할 수 있다.

---
## 기능 구현 목록

### 파일 읽기
- [x] 출석 시스템에 등록된 크루 정보를 읽어올 수 있다.
  - [x] 파일 이름이 맞지 않는다면 예외를 발생

###  기능 선택
- [x] 1~4번 + Q(q)의 기능을 선택한 후, 그 기능을 실행한다.
  - [x] 유효하지 않은 번호를 입력한 경우 예외 발생
  - [x] 기능 실행 시, 예외가 발생하는 경우 다시 기능 입력부터 시작
- [x] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.
- [x] 종료를 선택하면 프로그램이 종료된다.

### 출석 확인
- [x] 닉네임을 입력받는다.
  - [x] 문자열이 비어있는 경우 예외 발생
  - [x] 등록되지 않은 닉네임인 경우 예외 발생
  - [x] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 안내
- [x] 등교 시간을 입력받는다. 
  - [x] 시간 형식이 유효하지 않은 경우 예외 발생 
  - [x] 캠퍼스 운영 시간이 아닌 경우 예외 발생
- [x] 정보를 출석부에 저장한다.
- [x] 출석 후, 저장된 날의 출석 기록을 확인할 수 있다.

### 출석 수정
- [x] 닉네임을 입력받는다.
  - [x] 문자열이 비어있는 경우 예외 발생
  - [x] 등록되지 않은 닉네임인 경우 예외 발생
- [x] 수정하려는 날짜를 입력받는다.
  - [x] 숫자가 아닌 경우 예외 발생
  - [x] 날짜 범위가 아닌 경우 예외 발생
  - [x] 출석하지 않은 날짜일 경우 예외 발생
- [x] 변경 등교 시간을 입력받는다.
  - [x] 시간 형식(`00:00`)이 유효하지 않은 경우 예외 발생
  - [x] 캠퍼스 운영 시간이 아닌 경우 예외 발생
- [x] 입력한 날짜에 해당하는 출석 기록을 검색한다.
- [x] 해당 날짜의 출석 기록을 수정한다.
- [x] 수정 후에는 변경 전과 변경 후의 출석 기록을 출력한다. (`변경전` -> `변경후`)

### 크루별 출석 기록 확인
- [x] 닉네임을 입력받는다.
  - [x] 문자열이 비어있는 경우 예외 발생
  - [x] 등록되지 않은 닉네임인 경우 예외 발생
- [x] 크루 출석 기록을 전날까지 출력한다.(휴일, 주말 제외)
  - [x] 해당 날짜의 기록이 없는 경우 결석으로 출력(시간:`--:--`)
- [x] 출석, 지각, 결석에 대한 총합을 계산한다.
- [x] 출석 통계를 출력한다.
- [ ] 경고 및 면담 기준을 계산한다.
- [ ] 경고, 면담, 제적에 해당하는 경우 상태를 출력한다.

### 제적 위험자 확인
- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [ ] 제적 대상자, 면담 대상자, 경고 대상자순으로 정렬하여 출력한다.
  - [ ] 정렬 순서는 지각을 결석으로 간주하여 내림차순 정렬
  - [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬
