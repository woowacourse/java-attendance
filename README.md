# java-attendance

---

### 운영 시간
- [ ] 평일 08:00 ~ 23:00 (주말, 공휴일 제외)

### 교육 시간
- [ ] 월 -> 13:00 ~ 18:00
- [ ] 화 ~ 금 -> 10:00 ~ 18:00

### 출석
- [ ] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
    - [ ] 등교 시간 -> 출석 상태
      - [ ] 5분 초과 -> 지각
      - [ ] 30분 초과 -> 결석
    - [ ] 닉네임 -> 출석 기록 관리
- [ ] 출석 기록이 없는 날 -> 결석
- [ ] 이미 출석한 경우 -> 출석 불가

### 출석 수정
- [ ] 닉네임, 수정하려는 날짜, 등교 시간 -> 수정

### 크루별 출석 기록 확인
- [ ] 닉네임 -> 전날까지의 크루 출석 기록

### 제적 위험자 확인
- [ ] 전날까지의 크루 출석 기록들 -> 제적 위험자
- [ ] 정렬  
  - [ ] (1) 위험도 내림차순 
  - [ ] (2) 닉네임 오름차순  

### 결석
- [ ] 지각 3회 -> 결석 1회
- [ ] 경고 -> 결석 2회 이상
- [ ] 면담 -> 결석 3회 이상
- [ ] 제적 -> 결석 6회 이상

### 기타
- [ ] 시간은 24시간 형식만 사용한다.
- [ ] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.
- [ ] 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(attendances.csv)에서 확인할 수 있다.
