# 출석 미션 저장소

# 기능 목록

### 크루 초기화
- [x] 파일 파싱
- [x] 크루 생성
- [x] 크루 저장
- [x] 크루 별 출석 기록 저장

### 기능 선택
- [x] 원하는 기능을 선택한다.
  - [x] 존재하지 않는 기능일 경우, 예외를 발생시킨다.

### 출석 확인
- [x] 닉네임과 등교 시간을 입력한다.
  - [x] 잘못된 시간 형식일 경우, 예외를 발생시킨다.
- [x] 닉네임을 토대로 크루를 찾아온다.
  - [x] 존재하지 않는 크루일 경우, 예외를 발생시킨다.
- [x] 닉네임과 등교 시간을 토대로 출석 확인을 진행한다. 
  - [x] 주어진 날짜가 공휴일 혹은 주말인지 판별한다.
  - [x] 등교 시간을 토대로 출석, 지각, 결석을 판별한다.
  - [x] 출석 결과를 저장한다.
  - [x] 날짜, 등교시간, 출석 결과를 출력한다.
  - [x] 이미 출석한 경우, 다시 출석할 수 없다.
  - [x] 공휴일 혹은 주말일 경우, 출석을 할 수 없다.

### 출석 수정
- [x] 닉네임과 등교 시간, 수정 날짜를 입력한다.
  - [x] 잘못된 시간 형식일 경우, 예외를 발생시킨다.
- [x] 닉네임을 토대로 크루를 찾아온다.
  - [x] 크루가 존재하지 않는다면, 예외를 발생시킨다.
- [x] 찾아온 크루를 토대로 등교 시간, 수정 날짜를 출석을 수정한다.
  - [x] 출석 기록이 존재하지 않는다면, 예외를 발생시킨다.

### 크루 별 출석 기록 확인
- [x] 출석을 확인할 크루 닉네임을 입력한다. 
  - [x] 크루가 존재하지 않는다면, 예외를 발생시킨다.
- [x] 닉네임을 토대로 출석 기록을 출력한다.
  - [x] 공휴일 혹은 주말은 출력하지 않는다.
  - [x] 출석을 했지만 결석인 경우에는 시간을 출력한다.
  - [x] 출석을 하지 않아 결석인 경우에는 시간을 출력하지 않는다.
  - [x] 이번 달 출석, 지각, 결석 횟수를 출력한다.

### 제적 위험자 확인
- [x] 크루 별 지각/결석 횟수를 토대로 제적 위험자를 결정한다.
- [x] 제적 위험자를 출력한다.
