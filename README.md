# 출석 미션 저장소

## 프로그램 설명
2024년 12월 한정으로 시범 운영되는 출석 시스템입니다.

### 커스텀 요구사항
- 예외가 발생한 경우 안내를 하고 다시 옵션을 입력 받는다.
- 크루의 닉네임은 null 또는 공백일 수 없다.
- 크루의 닉네임은 중복되지 않는다.
- 등교 기록이 없는 결석일 경우 시간을 --:--의 형태로 출력한다.

### 기능 목록
- [ ] 크루 및 출석 초기화
  - [x] 파일을 읽어온다.
  - [x] 크루와 출석 기록을 동기화한다.
    - [ ] 크루의 닉네임이 공백 또는 null일 경우 예외를 발생한다.
  - [x] 출석 기록을 동기화한다.
  

- [x] 옵션
  - [x] 옵션을 입력 받는다
    - [x] 존재하지 않는 옵션일 경우 예외를 발생한다.
  - [x] 입력 받은 옵션에 따라 각 기능을 실행한다.
  - [x] 예외가 발생한 경우 예외 메세지를 출력하고 옵션부터 다시 입력 받는다.


- [x] 출석 확인
  - [x] 오늘이 캠퍼스 등교일이 아니면 안내를 하고 옵션부터 다시 입력 받는다.
  - [x] 닉네임을 입력 받는다.
    - [x] 존재하지 않는 크루 닉네임일 경우 안내를 하고 옵션부터 다시 입력 받는다.
    - [x] 이미 출석한 경우 안내를 하고 옵션부터 다시 입력 받는다.
  - [x] 등교 시간을 입력 받는다.
    - [x] 유효한 시간 형식이 아닌 경우 예외를 발생한다.
    - [x] 캠퍼스 운영 시간이 아닌 경우 안내를 하고 옵션부터 다시 입력 받는다.
  - [x] 출석 처리를 한다.
  - [x] 출석 결과를 출력한다.
  

- [x] 출석 수정
  - [x] 닉네임을 입력 받는다.
    - [x] 존재하지 않는 크루 닉네임일 경우 안내를 하고 옵션부터 다시 입력 받는다.
  - [x] 수정 날짜를 입력 받는다. 
    - [x] 유효한 날짜가 아닌 경우 예외를 발생한다.
    - [x] 수정 날짜가 캠퍼스 등교일이 아니면 안내를 하고 옵션부터 다시 입력 받는다.
    - [x] 해당 날짜에 출석 기록이 없으면 안내를 하고 옵션부터 다시 입력 받는다.
  - [x] 변경 출석 시간을 입력 받는다.
    - [x] 유효한 시간 형식이 아닌 경우 예외를 발생한다.
    - [x] 캠퍼스 운영 시간이 아닌 경우 안내를 하고 옵션부터 다시 입력 받는다.
  - [x] 출석 시간을 변경한다.
  - [x] 수정 전과 후 출석 결과를 출력한다.
  

- [x] 크루별 출석 기록 확인
  - [x] 닉네임을 입력 받는다.
    - [x] 존재하지 않는 크루 닉네임일 경우 안내를 하고 옵션부터 다시 입력 받는다.
  - [x] 해당 크루의 출석 기록을 조회한다.
  - [x] 출석 기록을 출력한다.
    - [x] 아예 등교하지 않은 경우 결석으로 간주한다.
  - [x] 출석 통계를 출력한다.
  - [x] 면담 대상자일 경우 면담 대상임을 출력한다.


- [x] 제적 위험자 확인
  - [x] 출석 기록을 바탕으로 제적 위험자를 확인한다.
  - [x] 제적 위험자를 출력한다.
