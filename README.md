# :sparkling_heart: java-attendance 프로젝트 소개

웹 백엔드 7기 레벨1 출석 미션 2단계를 구현한 프로젝트입니다.

# :dart: 구현 기능 목록

## :rocket: 초기 데이터 등록

### 초기 데이터 등록 - 입력

- [x] src/main/resources/attendances.csv 파일을 읽는다.
    ```
    nickname,datetime
    쿠키,2024-12-13 10:08
    빙봉,2024-12-13 10:07
    빙티,2024-12-13 10:07
    이든,2024-12-13 10:07
    ```

### 초기 데이터 등록 - 프로세스

- [x] 파일에서 읽은 내용을 토대로 초기 크루와 출석 기록을 등록한다.

## :rocket: 메뉴 기능

### 메뉴 기능 - 입력

- [x] 메뉴 기능을 선택하는 커맨드를 입력받는다.
    ```
    오늘은 12월 14일 토요일입니다. 기능을 선택해 주세요.
    1. 출석 확인
    2. 출석 수정
    3. 크루별 출석 기록 확인
    4. 제적 위험자 확인
    Q. 종료
    1
    ```

### 메뉴 기능 - 프로세스

- [x] 선택된 메뉴에 해당하는 기능을 실행한다.
- [x] 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 기능 수행 후 초기화면으로 돌아간다.
- [x] [예외] 선택된 커맨드가 유효하지 않은 경우
    ```
    잘못된 메뉴가 선택되었습니다. 메뉴를 다시 입력해주세요!
    ```

## :rocket: 출석 확인

### 출석 확인 - 입력

- [x] 닉네임을 입력받을 수 있다.
    ```
    닉네임을 입력해 주세요.
    이든
    ```
- [x] 출석 시간을 입력받을 수 있다.
    ```
    등교 시간을 입력해 주세요.
    09:59
    ```

### 출석 확인 - 프로세스

- [x] 닉네임과 출석 시간으로 출석 기록을 추가할 수 있다.
- [x] 교육시간과 출석정책을 기준으로 출석 상태를 결정한다.
    - 교육시간 : 월요일(13:00~18:00), 화~금(10:00~18:00)
    - 출석정책 : 지각(5분 이후), 결석(30분 이후), 지각 3회는 결석 1회
- [x] [예외] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.
    ```
    [ERROR] 이미 출석을 완료했습니다! 수정 기능을 활용해주세요!
    ```
- [x] [예외] 닉네임이 등록되지 않은 경우 예외 메세지를 출력한다.
    ```
    [ERROR] 등록되지 않은 닉네임입니다.
    ```
- [x] [예외] 등교일이 아닌 경우 예외 메세지를 출력한다.
    ```
    [ERROR] 12월 14일 토요일은 등교일이 아닙니다.
    ```
- [x] [예외] 캠퍼스 운영 시간 (08:00~23:00)이 아닌 경우 예외 메세지를 출력한다.
    ```
    [ERROR] 캠퍼스 운영 시간이 아닙니다.
    ```

### 출석 확인 - 출력

- [x] 추가된 출석 기록을 출력할 수 있다.
    ```
    12월 05일 화요일 09:59 (출석)
    ```

## :rocket: 출석 수정

### 출석 수정 - 입력

- [x] 닉네임을 입력받을 수 있다.

    ```
    출석을 수정하려는 크루의 닉네임을 입력해 주세요.
    빙티
    ```

- [x] 출석을 수정할 날짜를 입력받을 수 있다.

    ```
    수정하려는 날짜(일)를 입력해 주세요.
    3
    ```

- [x] 새로운 출석 시간을 입력받을 수 있다.

    ```
    언제로 변경하겠습니까?
    09:58
    ```

### 출석 수정 - 프로세스

- [x] 닉네임, 수정 목표 날짜, 새로운 출석 시간으로 기존 출석 기록을 수정할 수 있다.
- [x] 교육시간과 출석정책을 기준으로 출석 상태를 결정한다.
    - 교육시간 : 월요일(13:00~18:00), 화~금(10:00~18:00)
    - 출석정책 : 지각(5분 이후), 결석(30분 이후), 지각 3회는 결석 1회
- [x] [예외] 닉네임이 등록되지 않은 경우 예외 메세지를 출력한다.
    ```
    [ERROR] 등록되지 않은 닉네임입니다.
    ```
- [x] [예외] 등교일이 아닌 경우 예외 메세지를 출력한다.
    ```
    [ERROR] 12월 14일 토요일은 등교일이 아닙니다.
    ```
- [x] [예외] 캠퍼스 운영 시간 (08:00~23:00)이 아닌 경우 예외 메세지를 출력한다.
    ```
    [ERROR] 캠퍼스 운영 시간이 아닙니다.
    ```

### 출석 수정 - 출력

- [x] 출석 수정 결과를 출력할 수 있다.

    ```
    12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
    ```

## :rocket: 크루별 출석 기록 확인

### 크루별 출석 기록 확인 - 입력

- [x] 닉네임을 입력받을 수 있다.

    ```
    닉네임을 입력해 주세요.
    빙티
    ```

### 크루별 출석 기록 확인 - 프로세스

- [x] 닉네임을 통해 해당 크루의 출석 기록 일자순으로 조회할 수 있다.
- [x] 닉네임을 통해 해당 크루의 출석 현황을 조회할 수 있다.
- [x] 닉네임을 통해 해당 크루의 제적 위험도를 계산할 수 있다.
- [x] 등교하지 않아 출석 기록이 없는 날은 결석으로 간주한다.
- [x] 제적 위험도 정책에 따라 제적 위험도를 결정한다.
    - 경고 대상자: 결석 2회 이상
    - 면담 대상자: 결석 3회 이상
    - 제적 대상자: 결석 5회 초과
    - 지각 3회는 결석 1회로 게산한다.
- [x] [예외] 닉네임이 등록되지 않은 경우 예외 메세지를 출력한다.
    ```
    [ERROR] 등록되지 않은 닉네임입니다.
    ```

### 크루별 출석 기록 확인 - 출력

- [x] 출석 기록을 출력할 수 있다.

    ```
    이번 달 빙티의 출석 기록입니다.
    
    12월 02일 월요일 13:00 (출석)
    12월 03일 화요일 10:07 (지각)
    12월 04일 수요일 10:02 (출석)
    12월 05일 목요일 10:06 (지각)
    12월 06일 금요일 10:01 (출석)
    12월 09일 월요일 --:-- (결석)
    12월 10일 화요일 10:03 (출석)
    12월 11일 수요일 --:-- (결석)
    12월 12일 목요일 --:-- (결석)
    12월 13일 금요일 10:02 (출석)
    ```

- [x] 출석 현황을 출력할 수 있다.

    ```
    출석: 3회
    지각: 0회
    결석: 3회
    ```

- [x] 제적 위험도를 출력할 수 있다.

    ```
    면담 대상자입니다.
    ```

## :rocket: 제적 위험자 확인

### 제적 위험자 확인 - 프로세스

- [x] 제적 위험이 있는 크루의 출석 상태와 제적 위험도를 구할 수 있다.
- [x] 제적 위험도 정책에 따라 제적 위험도를 결정한다.
    - 경고 대상자: 결석 2회 이상
    - 면담 대상자: 결석 3회 이상
    - 제적 대상자: 결석 5회 초과
    - 지각 3회는 결석 1회로 게산한다.
- [x] 조회 결과는 제적 위험도 내림차순 -> 결석 지각 내림차순 -> 닉네임 내림차순으로 정렬하여 출력한다.

### 제적 위험자 확인 - 출력

- [x] 제적 위험자를 출력할 수 있다.
    ```
    제적 위험자 조회 결과
    - 빙티: 결석 3회, 지각 4회 (면담)
    - 이든: 결석 2회, 지각 5회 (면담)
    - 빙봉: 결석 1회, 지각 6회 (면담)
    - 쿠키: 결석 2회, 지각 3회 (면담)
    - 짱수: 결석 0회, 지각 6회 (경고)
    ```
