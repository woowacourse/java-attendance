# 출석

## 기능 요구 사항

### 크루 정보 가져오기
- [ ] csv 파일을 읽어온다.

### 출석 판별
- [x] 해당 요일의 시작 시간으로부터 출석, 지각, 결석을 판별한다.
  - [x] 날짜가 주어졌을 때, 요일을 찾는다.
  - [x] 해당 요일의 시작 시간으로부터 5분을 초과할 경우, 지각이다.
  - [x] 해당 요일의 시작 시간으로부터 30분을 초과할 경우, 결석이다.
  - [x] 캠퍼스 운영 시간이 아닐 경우, 예외를 발생시킨다.
  - [x] 주말 및 공휴일에 출석을 할 경우, 예외를 발생시킨다.

### 면담 대상자 판별
- [ ] 경고, 면담, 제적 대상자를 판별한다.
  - [ ] 지각 3회는 결석으로 판별한다.


### 출석 확인
- [ ] 닉네임과 등교 시간을 입력하면 출석할 수 있다.
- [ ] 출석 후 출석 기록을 확인할 수 있다.
- [ ] 이미 출석한 경우, 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다.

### 출석 수정
- [ ] 출석을 수정하려는 크루의 닉네임을 입력받는다.
  - [ ] 크루가 존재하지 않는다면 예외를 발생시킨다.
- [ ] 수정하려는 날짜를 입력받는다.
  - [ ] 날짜가 잘못되었다면, 예외를 발생시킨다.
- [ ] 수정하려는 시간을 입력받는다.
  - [ ] 시간이 잘못되었다면, 예외를 발생시킨다.

### 크루 별 출석 기록 확인
- [ ] 크루의 닉네임을 입력 받았을 때, 출석 기록을 보여준다.
- [ ] 크루의 출결 상황을 보여준다.
- [ ] 크루가 면담 대상자인지를 판별한다.

### 제적 위험자 확인
- [ ] 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [ ] 제적 대상자, 면담 대상자, 경고 대상자 순으로 출력한다.
- [ ] 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.
