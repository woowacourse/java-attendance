# java-attendance

출석 미션 저장소

## 기능 구현 목록

### 1. 사용자로부터 기능 입력 받기

- 사용자는 "1", "2", "3", "4"를 입력하여 기능을 선택할 수 있다.
- 사용자가 "Q"를 입력할 시 프로그램은 종료된다.
- 사용자가 `1, 2, 3, 4, Q`를 제외한 문자를 입력할 시 예외 메시지를 출력한다.

### 2. 기능 호출하기

기능 이름 옆의 번호는 각 기능을 실행하기 위한 사용자의 입력값이다.

#### 2-1. 출석 하기 ("1")

- 사용자는 닉네임을 입력하여 지금 날짜, 시간을 기준으로 출석을 할 수 있다.

**제약**

- [X] 주말 및 공휴일에는 출석이 불가하다.
- [X] 닉네임이 존재하지 않을 경우 출석이 불가하다.
- [X] 이미 출석 기록이 존재하는 경우 출석이 불가하며, 수정을 유도한다.

#### 2-2. 출석 수정 ("2")

- 사용자는 닉네임과 수정하고 싶은 일, 시간을 입력하여 출석 시간을 변경할 수 있다.

**제약**

- [X] 주말 및 공휴일의 출석은 수정할 수 없다.
- [X] 닉네임이 존재하지 않을 경우 출석을 수정할 수 없다.

#### 2-3. 출석 기록 확인 ("3")

- 사용자의 닉네임을 입력하여 오늘의 전날까지의 출석을 확인할 수 있다.
- 출석, 지각, 결석 횟수를 확인할 수 있다.
- [면담 | 경고 | 제적] 대상자라면 대상자임을 확인할 수 있다.

**제약**

- [x] 닉네임이 존재하지 않을 경우 출석을 확인할 수 없다.

#### 2-4. 제적, 경고, 면담 대상자 출력 ("4")

- 전날까지의 출석 기록을 기준으로 한다.
- [면담 | 경고 | 제적] 대상자들을 한번에 확인할 수 있다.
- 출력 순서는 아래와 같다.
    - 결석을 기준으로 내림차순한다.
    - 결석 횟수가 같다면 지각 횟수를 기준으로 내림차순한다.
    - 결석 횟수, 지각 횟수가 같다면 이름을 기준으로 오름차순한다.

> 공통 제약 사항
>  - [X] 닉네임의 길이는 2글자 이상 4글자 이하만 허용한다.
>

### 3. 기능에 대한 결과 출력하기

기능을 수행한 뒤 결과를 출력한다.
