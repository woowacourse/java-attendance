# java-attendance

## 미션 요구사항

- TDD 사이클을 엄격하게 지키며 처음부터 다시 구현해 본다.
    - 기존 코드를 전부 삭제하고, 기존 코드를 참고하지 않는다.
- 구현 요구사항을 만족하는 최소한의 설계를 한다.

## 출석 프로그램 기능

### 출석하기

- 입력사항
    - 이름 입력하기
    - 등교 시간 입력하기
- 출력사항
    - `12월 05일 화요일 09:59 (출석)`와 같은 형태로 출석 기록 출력
- 에러 핸들링
    - 없는 크루의 이름을 입력하는 경우
    - 출석 기록이 있는데 재출석을 하는 경우

### 출석 수정하기

- 입력사항
    - 이름 입력하기
    - 날짜 입력하기
    - 수정 시간 입력하기
- 출력 사항
    - `12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!`와 같은 형태로 출석 수정 기록 출력
- 에러 핸들링
    - 없는 크루의 이름을 입력하는 경우
    - 해당 날짜의 해당 크루의 출석 기록이 없는 경우
    - 동일 날짜, 동일 시간으로 출석 수정을 하는 경우

### 크루별 출석 확인하기

- 입력사항
    - 이름 입력하기
- 출력사항
    - 크루의 출석 기록 출력하기
    - 크루의 출석, 지각, 결석 횟수 출력하기
    - 크루의 상태가 경고, 면담, 제적 중 하나라면 출력하기
- 에러 핸들링
    - 없는 크루의 이륾을 입력하는 경우

### 제적 위험자 확인하기

- 입력사항
- 출력사항
    - 제적 위험자 출력하기
        - 제적, 면담, 경고 순으로
        - 같다면, 이름 순으로
