# 프로그램 설명

- 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.

**⌚시간 조건**

- 시간은 24시간 형식만 사용한다. ("22:30"은 오후 10시 30분을 의미한다.)
- 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00이다.
- 캠퍼스 운영 시간은 매일 08:00~23:00이다.

**📅날짜 조건**

- 주말 및 공휴일에는 출석을 받지 않는다.

**출결 조건**

- 해당 요일의 시작 시각으로부터 5분 초과는 지각으로 간주한다.
- 해당 요일의 시작 시각으로부터 30분 초과는 결석으로 간주한다.
- 등교하지 않아 출석 기록이 없는 날은 결석으로 간주한다.

**패널티 조건**

- 누적 지각 및 결석 횟수에 따라 경고 또는 면담을 시행한다. 이때 지각 3회는 결석 1회로 간주한다.
    - 경고 대상자: 결석 2회 이상
    - 면담 대상자: 결석 3회 이상
    - 제적 대상자: 결석 5회 초과

## 기능 목록

### ◉ 크루 등록:

- 출석 시스템에 등록된 크루와 12월 출석 기록은 제공된 파일(src/main/resources/attendances.csv)에서 확인할 수 있다.
- 해당 파일에는 닉네임과 출석 일시가 기록되어 있다. (데이터 형태: 이름, YYYY-MM-DD HH:MM)


- [x] 제공된 파일로부터 출석 기록을 읽어온다.

- [x] 읽어온 출석 기록을 크루 이름, 날짜, 시간 데이터로 분리한다.
    - [x] 읽어온 출석 기록을 크루 이름, 시간 로그 데이터로 분리한다.
    - [x] 시간 로그 데이터를 날짜와 시간 데이터로 분리한다.

- [x] 분리한 데이터를 바탕으로 크루 등록을 진행한다.

- **데이터 형태 예시**:

```예시
nickname,datetime
쿠키,2024-12-13 10:08
빙봉,2024-12-13 10:07
빙티,2024-12-13 10:07
이든,2024-12-13 10:07
```

### ◉ 출석 확인:

- [x] 출석하기 위해서는 닉네임과 등교 시간을 입력 받아야 한다.

- [x] 출석하는 날이 주말이나 공휴일인 경우 예외 메시지를 출력한다.
    - `[ERROR] MM월 DD일 토요일(or 일요일 or 공휴일)은 등교일이 아닙니다.`

- [x] 이미 출석을 하였는데 다시 출석 확인을 하는 경우 예외 메시지를 출력한다.
    - `[ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해 주세요.`

- [x] 등록되지 않는 닉네임의 경우 예외 메시지를 출력한다.
    - `[ERROR] 등록되지 않은 닉네임입니다. 다시 입력해 주세요.`

- [x] 등교 시간이 캠퍼스 운영 시간이 아닌 경우 예외메시지를 출력한다.
    - `[ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.`

- [ ] 시간의 형식이 잘못된 경우 예외메시지를 출력한다.
    - `[ERROR] 잘못된 형식을 입력하였습니다.`

- [ ] 출석 후 출석 기록을 출력해야 한다.

- **출석 확인 기능 작동 예시**:

```예시
닉네임을 입력해 주세요.
이든 
등교 시간을 입력해 주세요.
09:59

12월 05일 화요일 09:59 (출석)
```

### ◉ 출석 수정:

- [x] 출석을 수정하기 위해서는 닉네임, 수정하려는 날짜, 등교시간을 입력해야 한다.

- [ ] 등록되지 않는 닉네임의 경우 에외 메시지를 출력한다.
    - `[ERROR] 등록되지 않은 닉네임입니다. 다시 입력해 주세요.`

- [ ] 수정하려는 날이 주말이나 공휴일인 경우 예외 메시지를 출력한다.
    - `[ERROR] MM월 DD일 토요일(or 일요일 or 공휴일)은 등교일이 아닙니다.`

- [ ] 미래 날짜로 출석을 수정하는 경우 예외 메시지를 출력한다.
    - `[ERROR] 미래의 날짜는 수정할 수 없습니다.`

- [ ] 등교 시간이 캠퍼스 운영 시간이 아닌 경우 예외메시지를 출력한다.
    - `[ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.`

- [ ] 시간의 형식이 잘못된 경우 예외메시지를 출력한다.
    - `[ERROR] 잘못된 형식을 입력하였습니다.`

- [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 출력해야 한다.

- **출석 수정 기능 작동 예시**:

```예시
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```

## 예외 처리

- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException 를 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
- Exception 이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.
- 사용자가 잘못된 값을 입력했을 때, 오류 메시지와 함께 상황에 맞는 안내를 출력한다.
